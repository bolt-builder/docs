桌面应用是相同的 Bolt 引擎，被包装在原生外壳中，并加上一些终端难以做到的能力。

## 内部功能

- **多窗口、多标签会话。** 跨项目并行运行多个代理，每个代理在自己的标签中。
- **提示词编辑器。** 富文本输入，支持文件附件和剪贴板粘贴图片——可直接将截图拖入提示。
- **集成终端 \+ 文件树。** 真正的 shell 和项目资源管理器与聊天并排。
- **命令面板。** `Cmd/Ctrl+K` 可在会话之间跳转、运行任意 Bolt 命令，或触发斜杠命令。
- **设置。** 键位、模型、提供商以及已配置的服务器，全部可在真正的设置 UI 中编辑。
- **原生通知。** 长时间运行的代理完成时由操作系统通知你。
- **深层链接。** `bolt://` URL 可从任何地方跳转到会话。
- **Windows 上的 WSL 集成。** 开箱即用，可对接你的 WSL 环境运行。
- **28 种 UI 语言。**
