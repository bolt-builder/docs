## 新功能

- **新增 11 种 UI 语言** — 桌面应用和 TUI 现已提供印地语、荷兰语、印尼语、越南语、意大利语、乌尔都语、旁遮普语、阿塞拜疆语、芬兰语、瑞典语和泰语的翻译，共支持 28 种语言。可在 **Settings → Appearance → Language** 中切换语言。详见 [Desktop features](/desktop/features) 和 [Install](/desktop/install#28-ui-languages)。
- **从右到左布局支持** — 导航、编辑器、对话框、控件以及文本渲染现在能正确镜像显示以适配阿拉伯语、希伯来语和乌尔都语等从右到左的语言，使整个界面在这些地区自然易读。
- **原生桌面翻译** — 操作系统级菜单、更新程序对话框、恢复流程、WSL 上手引导以及原生文件选择器现已与应用内 UI 一同本地化，让整个桌面体验遵循你的语言设置。
- **扩展的本地化覆盖** — 菜单、对话框、提示、帮助内容、错误信息和无障碍标签现已在所有支持的语言中完成翻译，弥补了此前字符串回退到英文的空缺。
- **Poolside 提供商** — Bolt 现在可以通过其 OpenAI 兼容 API 连接到 [Poolside](https://poolside.ai)。运行 `/connect`，选择 **Poolside**，然后粘贴来自 [platform.poolside.ai](https://platform.poolside.ai) 的 API 密钥。自托管的 Poolside 部署也可以配置为自定义提供商。详见 [Providers and models](/concepts/providers-and-models)。
- **区分语言的复数形式** — 计数、状态、文件和会话列表项现在会针对每种语言进行正确的复数处理，使时间线和状态文本在所有支持的地区都自然易读。
- **更丰富的 Markdown 渲染** — 助手消息现在拥有更好的 Markdown 格式、更流畅的流式更新、更好的语法高亮，以及对数学内容的支持，使长篇和技术性回复更易阅读。

## 更新

- **GPT-5 推理强度与模型版本匹配** — 推理强度分级（包括 `none` 和 `xhigh`）现在仅针对支持它们的 GPT-5 变体提供，因此 `--variant` 不再显示特定模型会拒绝的选项。详见 [Controlling reasoning effort](/concepts/providers-and-models#variant-controlling-reasoning-effort)。
- **差异注释优化** — 会话 UI 的差异视图对评论指示器、行号栏行为，以及浅色/深色语法配色做了收紧改进，可读性更好。
- **优化已有翻译** — 现有语言获得了更清晰的术语和扩展的 UI 标签，使整个应用体验更一致。

## 缺陷修复

- **会话动作计时** — 会话动作现在能更准确地记录和上报时间，因此时间线能反映工作真正开始和完成的时间。
- **更清晰的远程工作区错误** — 连接到远程工作区或在其中运行命令失败时，现在会显示更具描述性的错误信息，而不是通用错误。
- **工作区代理不再泄露工作目录** — 通过工作区代理路由的请求不再包含工作目录信息，将本地路径保留在本地。
- **地图填充空白区域** — 活动地图现在在没有记录活动的区域仍会保持可见，而不是塌陷为空白区域。
- **区域设置检测修复** — Bolt 现在能在启动时可靠地识别系统区域设置，因此界面能在更多平台上以正确的语言打开。
- **修复德语时间线翻译** — 德语中的时间线条目现在能以正确的字符串呈现，不再回退到英文或错误格式的文本。
- **可关闭文件选中状态** — 再次点击已选中的文件现在会清除选中状态，因此无需先选中另一个文件即可撤销选择。
- **更整洁的草稿评论交互** — 开始或忽略草稿评论现在会一致地清除底层选中状态，并且不再与悬停状态冲突。
- **恢复了推理头动画** — TUI 中的推理头在思考时再次显示动画旋转指示，展开时其渐变变暗，使折叠和展开状态更易区分。
- **主屏和错误屏上的 Bolt 字标** — New Session 水印以及旧版主屏和错误屏现在显示 Bolt 字标而非上游 logo，让品牌形象在每个界面上保持一致。
- **恢复后台进程和测试工具** — `bash_background`、`process_output`、`list_processes`、`kill_process` 和 `test_run` 在早前合并中被移除后，现已重新对代理可用。代理可以启动开发服务器和监视器等长时间运行的命令、读取其输出，并以结构化的通过/失败结果运行项目测试。详见 [Built-in tools](/concepts/tools#built-in-tools)。
