Bolt 将一支完整的 AI 工程团队直接放进你的终端。它以快速、以键盘为主的 TUI 和原生桌面应用形式提供，两者都由同一引擎驱动：十个专用代理、持久化的会话、支持 OAuth 的 MCP 服务器管理、插件系统，以及对所有主流 LLM 提供商的支持。

## Bolt 的能力

Bolt 能读取你的代码库、理解你在构建什么，并与你一起交付代码——无论是在终端还是桌面应用中。每个会话都是持久化的：可以分离、从另一台机器重新连接、从对话中派生分支、分享链接，或导出脱敏后的记录。

## 启动并运行

<Steps>
  <Step title="安装 Bolt">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash
    ```
    或通过 npm 安装：`npm i -g @bolt-builder/bolt-cli`
  </Step>
  <Step title="打开你的项目">
    进入任意项目目录并启动 TUI：
    ```bash
    cd my-project
    bolt
    ```
  </Step>
  <Step title="配置提供商">
    首次启动时，Bolt 会提示你添加 LLM 提供商。你也可以运行：
    ```bash
    bolt providers
    ```
  </Step>
  <Step title="开始与 AI 结对编程">
    在 TUI 底部输入你的提示，按下回车，让 Bolt 的代理开始工作。使用 `Tab` 切换代理。
  </Step>
</Steps>

<Tip>
  使用 `bolt run "explain this codebase"` 可在不打开完整 TUI 的情况下快速获得非交互式答复。
</Tip>
