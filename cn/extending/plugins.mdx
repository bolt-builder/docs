插件让你可以将 Bolt 扩展到其内置能力之外。插件是一个 Node 或 Bun 模块，导出一个 Bolt 插件清单；加载后，它可以注册新的 LLM 提供商、自定义认证方式、额外的工具和工作区适配器。插件可以为单个项目安装，也可以在所有工作中全局应用。

## 安装插件

使用 `bolt plugin install`（别名：`bolt plug`）从 npm 安装插件并自动在配置中注册：

```bash
bolt plugin install <module>
```

### 标志

| 标志 | 别名 | 说明 |
|------|-------|-------------|
| `--global` | `-g` | 安装到全局配置而非当前项目 |
| `--force` | `-f` | 替换同一模块的已有条目 |

### 作用域：项目 vs. 全局

默认情况下，`bolt plugin install` 会将插件添加到项目级的 `.bolt/bolt.jsonc`。传入 `--global` 可将其添加到用户级配置，使其在每个项目中都加载。

```bash
# 项目作用域（默认）
bolt plugin install @acme/bolt-plugin-jira

# 全局 — 每个项目中都会加载
bolt plugin install @acme/bolt-plugin-jira --global
```

<Note>
  运行 `bolt --pure`（或设置 `OPENCODE_PURE=1`）可在禁用所有外部插件的情况下启动 Bolt。这在无需卸载插件的情况下调试插件是否导致了预期外的行为时很有用。
</Note>

## 安装已发布的插件

<Steps>
  <Step title="查找插件包">
    在 npm 中搜索名字里包含 `bolt-plugin` 或 `opencode-plugin` 的包，或从提供商文档中跟随链接查找。
  </Step>

  <Step title="安装到你的项目">
    ```bash
    bolt plugin install @acme/bolt-plugin-jira
    ```

    Bolt 会安装该包，读取其清单以识别服务器和 TUI 目标，然后将条目写入 `.bolt/bolt.jsonc`。
  </Step>

  <Step title="核对配置">
    打开 `.bolt/bolt.jsonc` 确认插件条目已添加：

    ```jsonc
    {
      "plugin": [
        "@acme/bolt-plugin-jira"
      ]
    }
    ```
  </Step>

  <Step title="启动会话">
    ```bash
    bolt
    ```

    Bolt 在启动时加载插件。它注册的任何提供商或工具都会立即可用。
  </Step>
</Steps>

## 手动插件配置

你可以直接编辑 `.bolt/bolt.jsonc` 来注册插件。这对本地开发中的插件很有用：

```jsonc
{
  "plugin": [
    "./plugins/my-plugin.ts"
  ]
}
```

相对路径会从项目根目录解析。支持 TypeScript 和 JavaScript 入口。

## 构建插件

插件基于 `@opencode-ai/plugin` 包编写，该包提供了你的模块必须实现的 `Hooks` 接口。

```bash
npm install --save-dev @opencode-ai/plugin
```

一个最小插件导出一个函数，该函数接收 `PluginInput` 对象并返回一个 `Hooks` 对象：

```typescript
import type { Plugin } from "@opencode-ai/plugin"

const myPlugin: Plugin = async (input) => {
  return {
    // auth hook — register custom authentication methods
    auth: {
      methods: [
        {
          id: "my-provider-auth",
          name: "My Provider",
          // ... provider-specific fields
        },
      ],
    },
  }
}

export default myPlugin
```

### 可用的 hook 类型

| Hook | 用途 |
|------|---------|
| `auth` | 使用 `methods` 数组注册自定义认证提供商 |
| `event` | 对会话事件（消息、工具调用、完成）作出反应 |
| `config` | 在运行时响应配置变更 |
| `dispose` | 卸载插件时清理资源 |

`PluginInput` 对象暴露 `client`（类型化的 Bolt API 客户端）、`project`、`worktree`、`directory` 和 `serverUrl`，让你的插件可以与运行中的服务器交互。
