## Bolt nima qiladi

Bolt kodbazangizni o'qiydi, siz nima qurayotganingizni tushunadi va siz bilan birga kodni jo'natadi — terminalda yoki desktop ilova sifatida. Har bir sessiya barqaror: ajrating, boshqa mashinadan qayta biriktiring, suhbat filialini fork qiling, havolani bo'lishing yoki sanitizatsiya qilingan transkriptni eksport qiling.

## Ishga tushish

<Steps>
  <Step title="Bolt'ni o'rnating">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash
    ```
    Yoki npm orqali o'rnating: `npm i -g @bolt-builder/bolt-cli`
  </Step>
  <Step title="Loyihangizni oching">
    Har qanday loyiha katalogiga o'ting va TUI ni ishga tushiring:
    ```bash
    cd my-project
    bolt
    ```
  </Step>
  <Step title="Provayderni sozlang">
    Birinchi ishga tushirishda Bolt sizdan LLM provayderni qo'shishni so'raydi. Shuningdek ishga tushirishingiz mumkin:
    ```bash
    bolt providers
    ```
  </Step>
  <Step title="AI bilan kodlashni boshlang">
    TUI footerida promptingizni yozing, Enter'ni bosing va Bolt agentlariga ishlashga imkon bering. Agentlarni `Tab` bilan almashtiring.
  </Step>
</Steps>

<Tip>
  To'liq TUI ni ochmasdan tezkor interaktiv bo'lmagan javob uchun `bolt run "explain this codebase"` dan foydalaning.
</Tip>
