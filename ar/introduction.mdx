Bolt هو وكيل برمجة بالذكاء الاصطناعي مبني على [Effect](https://effect.website) و[OpenTUI](https://github.com/opentui/opentui) و[SolidJS](https://www.solidjs.com)، وموجّه للطرفية أولاً. وجّهه إلى أي مشروع فيلتقط السياق تلقائيًا: يستكشف الشيفرة، ويتبع اصطلاحاتك، وينفّذ أوامر الصدفة، ويعدّل الملفات، ويشغّل الاختبارات، ويسلّم التغييرات.

عشرة وكلاء مدمجين (`code`، `plan`، `ask`، `code-review`، `debug`، `refactor`، `docs`، `security`، `migrate`، `perf`) بالإضافة إلى الوكلاء الفرعيين `@general` و`@explore` يغطون كامل دورة الهندسة. الجلسات دائمة: يمكنك الانفصال وإعادة الاتصال (حتى بخادم بعيد) والتفريع والمشاركة والتصدير والاستيراد في أي وقت. تحفظ ذاكرة المشروع ما يتعلّمه الوكيل بين الجلسات. قابل للتوسيع عبر خوادم MCP (مع OAuth)، والإضافات، والوكلاء المخصّصين، والأدوات المخصّصة.

Bolt مفتوح المصدر بموجب رخصة PolyForm Noncommercial 1.0.0.

## لماذا Bolt؟

صُمّم Bolt وفق الطريقة التي يعمل بها المطورون فعليًا: في الطرفية، عبر جلسات متعدّدة، على قواعد شيفرة حقيقية. إليك ما يميّزه:

- **TUI موجّه للطرفية أولاً.** واجهة سريعة تعمل بلوحة المفاتيح، مبنية باستخدام [Effect](https://effect.website) و[OpenTUI](https://github.com/opentui/opentui) و[SolidJS](https://www.solidjs.com). تشعر بأنها أصلية لأنها كذلك.
- **فريق كامل من الوكلاء.** عشرة وكلاء متخصصون — `code`، `plan`، `ask`، `code-review`، `debug`، `refactor`، `docs`، `security`، `migrate`، و`perf` — بالإضافة إلى وكلاء فرعيين للبحث والتفويض متعدّد الخطوات. بدّل بينهم بـ `Tab`.
- **جلسات يمكنك تركها والعودة إليها.** انفصل عن جلسة وعُد إليها لاحقًا، حتى على خادم بعيد. فرّع وشارك وصدّر واستورد العمل في أي وقت. تُخزّن الجلسات في SQLite ويمكن فحصها بالكامل عبر `bolt db`.
- **قابل للتوسيع بالتصميم.** خوادم MCP بدعم كامل لـ OAuth، ونظام إضافات، وتكامل GitHub، وخادم API مدمج، وواجهة ويب.
- **تطبيق سطح مكتب.** نفس المحرك مغلّف بتجربة سطح مكتب متعدّدة النوافذ ومتعدّدة التبويبات — مع طرفية متكاملة، وشجرة ملفات، ولوحة أوامر، و28 لغة واجهة، وتحديثات تلقائية.

## الوكلاء المدمجون

يأتي Bolt مع عشرة وكلاء متخصصين. لكل وكيل مستوى محدّد من الوصول إلى نظام الملفات يتناسب مع غرضه.

| الوكيل | الوصول | الوصف |
| --- | --- | --- |
| `code` | كامل | الافتراضي: يقرأ ويكتب ويشغّل الشيفرة |
| `plan` | قراءة | يستكشف قاعدة الشيفرة وينتج خطة دون تعديل الملفات |
| `ask` | قراءة | أسئلة وبحث — بدون تعديل الملفات |
| `code-review` | قراءة | يراجع التغييرات بحثًا عن الصحة والأسلوب والأمان |
| `debug` | كامل | يصحّح الاختبارات الفاشلة والانهيارات وأخطاء المنطق |
| `refactor` | كامل | إعادة هيكلة آمنة مع التحقق من الاختبارات في كل خطوة |
| `docs` | تحرير | يكتب ويحدّث الوثائق والتعليقات |
| `security` | قراءة | مراجعة أمنية: ثغرات، أسرار، أنماط |
| `migrate` | كامل | ترقيات إطارات العمل وترحيل الاعتماديات |
| `perf` | كامل | تحليل الأداء والتحسين |

يمكنك أيضًا تعريف وكلاء خاصّين بك كملفات Markdown أو توليد وكيل باستخدام `bolt agent create`.

## تطبيق سطح المكتب

يأتي Bolt أيضًا كتطبيق سطح مكتب مستقل مع إدارة جلسات متعدّدة النوافذ ومتعدّدة التبويبات، ومحرّر موجّهات يدعم المرفقات ولصق الصور من الحافظة، وطرفية متكاملة وشجرة ملفات، ولوحة أوامر، وإعدادات كاملة لاختصارات لوحة المفاتيح والنماذج والمزوّدين والخوادم، وإشعارات نظام أصلية، وروابط عميقة، وتكامل WSL على ويندوز، وتحديثات تلقائية عبر قنوات dev وbeta وproduction.

نزّل تطبيق سطح المكتب من [صفحة الإصدارات](https://github.com/Bolt-builder/bolt-cli/releases)، أو ثبّته بسطر واحد على macOS دون المرور بـ Gatekeeper:

```bash
curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install-desktop | bash
```
