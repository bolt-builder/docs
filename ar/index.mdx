يضع Bolt فريقًا هندسيًا كاملاً مدعومًا بالذكاء الاصطناعي مباشرة داخل طرفيتك. يأتي كواجهة TUI سريعة تعمل بلوحة المفاتيح وتطبيق سطح مكتب أصلي، وكلاهما مدعوم بنفس المحرك: عشرة وكلاء متخصصون، جلسات دائمة قابلة للاستمرار، إدارة خوادم MCP مع OAuth، ونظام إضافات، ودعم لكل مزوّدي LLM الرئيسيين.

## ما الذي يفعله Bolt

يقرأ Bolt قاعدة الشيفرة الخاصة بك، ويفهم ما تبنيه، ويكتب الشيفرة معك — في الطرفية أو كتطبيق سطح مكتب. كل جلسة قابلة للاستمرار: يمكنك الانفصال وإعادة الاتصال من جهاز آخر، وتفريع فرع من المحادثة، ومشاركة رابط، أو تصدير نسخة نصية مُنقّاة.

## ابدأ الآن

<Steps>
  <Step title="ثبّت Bolt">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash
    ```
    أو ثبّت عبر npm: `npm i -g @bolt-builder/bolt-cli`
  </Step>
  <Step title="افتح مشروعك">
    انتقل إلى أي مجلد مشروع وشغّل الـ TUI:
    ```bash
    cd my-project
    bolt
    ```
  </Step>
  <Step title="اضبط مزوّدًا">
    عند التشغيل الأول يطلب منك Bolt إضافة مزوّد LLM. يمكنك أيضًا تشغيل:
    ```bash
    bolt providers
    ```
  </Step>
  <Step title="ابدأ البرمجة بالذكاء الاصطناعي">
    اكتب موجّهك في تذييل الـ TUI، اضغط Enter، ودع وكلاء Bolt يبدؤون العمل. بدّل بين الوكلاء بـ `Tab`.
  </Step>
</Steps>

<Tip>
  استخدم `bolt run "explain this codebase"` للحصول على إجابة سريعة غير تفاعلية دون فتح الـ TUI الكامل.
</Tip>
