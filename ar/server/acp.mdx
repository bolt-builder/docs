يطبّق Bolt بروتوكول عميل الوكيل (ACP)، وهو الطريقة التي تتحدّث بها محرّرات مثل Zed مع وكلاء الذكاء الاصطناعي. بمجرد ضبطه، يُطلق المحرّر `bolt acp` كعملية فرعية ويقوده مباشرة — تحصل على وكلاء Bolt وأدواته وجلساته ومجموعة مزوّديه دون مغادرة محرّرك.

## تفعيل ACP

في إعدادات الذكاء الاصطناعي بمحرّرك، أضف Bolt كوكيل متوافق مع ACP ووجّهه إلى:

```bash
bolt acp
```

سيدير المحرّر دورة حياة العملية. اضبط المزوّدين والنماذج وخوادم MCP كما تفعل عادة في `.bolt/bolt.jsonc` — إنها تنطبق هنا أيضًا.

## ما تحصل عليه

- كل وكيل Bolt، قابل للاستدعاء من لوحة الذكاء الاصطناعي بالمحرّر.
- جلسات مشتركة مع الـ TUI وواجهة الويب (عبر قاعدة البيانات المحلية).
- نفس مجموعة الأدوات ونموذج الأذونات وذاكرة المشروع مثل أي نقطة دخول Bolt أخرى.
