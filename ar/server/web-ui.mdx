يبدأ `bolt web` خادم Bolt ويقدّم واجهة متصفح أمامه. إنه نفس المحرّك مثل الـ TUI، فقط مُعرَض في تبويب متصفح.

## ابدأه

```bash
bolt web                                # localhost only
bolt web --hostname 0.0.0.0 --port 4096
```

ثم افتح عنوان URL المطبوع. عند العرض عبر شبكة، اضبط المصادقة الأساسية أولًا:

```bash
export BOLT_SERVER_USERNAME=teamname
export BOLT_SERVER_PASSWORD=$(openssl rand -hex 24)
bolt web --hostname 0.0.0.0 --port 4096
```

## متى تستخدم واجهة الويب

- تشغيل Bolt على جهاز بعيد قوي ولكن قيادته من حاسوب محمول.
- مشاركة جلسة حيّة مع زميل للتصحيح المزدوج.
- بيئات يكون فيها الـ TUI الكامل محرجًا (Chromebooks، الأجهزة اللوحية، أجهزة مساحات العمل المشتركة).
