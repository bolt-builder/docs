يقوم الوكلاء في Bolt بالعمل عبر استدعاء الأدوات. كل إجراء تراه في الـ TUI (قراءة ملف، تشغيل اختبارات، البحث في الويب) هو النموذج يختار أداة وBolt ينفّذها. لكل وكيل مستوى وصول معلن يحدّد الأدوات التي يمكنه استدعاؤها دون سؤالك أولًا (راجع [الأذونات](/concepts/permissions)).

## الأدوات المدمجة

| الأداة | ما تفعله |
| --- | --- |
| `read` | قراءة ملف من القرص. |
| `write` | إنشاء ملف جديد أو الكتابة فوق ملف موجود. |
| `edit` | تطبيق تعديل مستهدف (بحث/استبدال) على ملف. |
| `apply_patch` | تطبيق patch بنمط unified-diff عبر ملف واحد أو أكثر. |
| `glob` | سرد الملفات المطابقة لنمط glob. |
| `grep` | البحث في محتويات الملفات عبر regex/نص. |
| `bash` | تشغيل أمر صدفة. |
| `task` | تفويض مهمة فرعية إلى وكيل فرعي (`@general` أو `@explore` أو وكيل فرعي مخصّص). |
| `todowrite` | الحفاظ على قائمة مهام الوكيل المنظّمة للعمل متعدّد الخطوات. |
| `webfetch` | جلب عنوان URL وإرجاع محتوياته. |
| `websearch` | البحث في الويب. |
| `skill` | استدعاء مهارة مسمّاة (راجع [المهارات](/extending/skills)). |
| `memory_save` | حفظ حقيقة في [ذاكرة المشروع](/concepts/project-memory). |
| `memory_recall` | البحث عن ذاكرة محفوظة سابقًا. |
| `question` | طرح سؤال توضيحي عليك وانتظار الرد. |
| `bash_background` | بدء أمر صدفة كعملية خلفية مُدارة (خوادم التطوير، المراقبات، عمليات البناء الطويلة). |
| `process_output` | قراءة الإخراج المتراكم وحالة عملية خلفية، مع خيار الانتظار حتى انتهائها. |
| `list_processes` | سرد العمليات الخلفية مع معرّفها وحالتها والأمر. |
| `kill_process` | إنهاء عملية خلفية (وشجرة عملياتها) بالمعرّف. |
| `test_run` | اكتشاف وتشغيل اختبارات المشروع، وإعادة نتائج نجاح/فشل منظمة وتفاصيل الفشل. |

### تجريبية

| الأداة | ما تفعله |
| --- | --- |
| `lsp` | الاستعلام من خادم لغة لتعريفات ومراجع وتشخيصات. |
| `execute` | تشغيل شيفرة في صندوق رمل code-mode معزول. |
| `plan` | إنتاج خطة منظّمة قبل إجراء التغييرات. |

قد تتغيّر الأدوات التجريبية أو يُعاد تسميتها بين الإصدارات.

## توسيع مجموعة الأدوات

بعد الأدوات المدمجة، يمكن لـ Bolt استدعاء أدوات من ثلاثة مصادر:

- **الأدوات المخصّصة** في `.opencode/tool/` (أو `.opencode/tools/`) في جذر المشروع. راجع [الأدوات المخصّصة](/extending/custom-tools).
- **أدوات الإضافات** المُساهم بها من أي [إضافة](/extending/plugins) مثبّتة.
- **أدوات MCP** من أي [خادم MCP](/extending/mcp-servers) مضبوط للمشروع.

كل الثلاثة تبدو متطابقة من وجهة نظر الوكيل: تظهر في قائمة الأدوات، وتحترم مستوى وصول الوكيل، وتظهر في إخراج استدعاء الأدوات في الـ TUI.
