Bolt محايد للنموذج بالتصميم. تحت الغطاء يستخدم **Vercel AI SDK** للتحدّث مع المزوّدين، ما يعني أن أي مزوّد يدعمه الـ SDK — Anthropic، OpenAI، Google، Amazon Bedrock، OpenRouter، والمزيد — يعمل مباشرة. يُستمد كتالوج المزوّدين والنماذج من [models.dev](https://models.dev)، وهي قاعدة بيانات مجتمعية لبيانات المزوّدين والتسعير.

## إدارة بيانات اعتماد المزوّد

استخدم `bolt providers` (لقب: `bolt auth`) لإضافة بيانات اعتماد المزوّدين وسردها وإزالتها.

### إضافة أو تحديث بيانات الاعتماد

```bash
bolt providers login
# or equivalently:
bolt auth login
```

يطلق هذا موجّهًا تفاعليًا لاختيار مزوّد وإدخال بيانات الاعتماد. لتخطي التدفق التفاعلي، مرّر الخيارات مباشرة:

```bash
bolt providers login --provider anthropic
bolt providers login --provider openai --method "API key"
```

### سرد المزوّدين المضبوطين

```bash
bolt providers list
# or:
bolt auth list
```

يعرض جميع بيانات الاعتماد المخزّنة وأي مفاتيح API للمزوّدين تم اكتشافها من متغيرات البيئة.

### إزالة بيانات الاعتماد

```bash
bolt providers logout
bolt providers logout anthropic
```

### المصادقة عبر متغيرات البيئة

بالنسبة لأنابيب CI أو البيئات بدون واجهة، اضبط متغير بيئة مفتاح API للمزوّد مباشرة — دون الحاجة لتسجيل دخول تفاعلي. أمثلة شائعة:

```bash
export ANTHROPIC_API_KEY="sk-ant-..."
export OPENAI_API_KEY="sk-..."
export GOOGLE_GENERATIVE_AI_API_KEY="AIza..."
```

يقرأ Bolt هذه المتغيرات تلقائيًا عند بدء التشغيل. سيُظهر `bolt providers list` متغيرات البيئة التي اكتشفها.

## تصفّح النماذج المتاحة

`bolt models` يسرد كل نموذج متاح عبر المزوّدين المضبوطين.

```bash
# List all models
bolt models

# Filter to one provider
bolt models anthropic

# Show cost and capability metadata
bolt models --verbose

# Refresh the model catalog from models.dev
bolt models --refresh
```

<Tip>
  شغّل `bolt models --verbose` لرؤية تسعير رموز الإدخال/الإخراج لكل نموذج. يسهّل هذا مقارنة موازنات التكلفة قبل الالتزام بنموذج لمهمة طويلة الأمد.
</Tip>

### تنسيق معرّف النموذج

يُشار إلى النماذج دائمًا بتنسيق `provider/model`:

```
anthropic/claude-opus-4-5
openai/gpt-4o
google/gemini-2.5-pro
openrouter/anthropic/claude-opus-4-5
```

استخدم هذا التنسيق حيثما يقبل Bolt نموذجًا — خيارات CLI، ملفات الإعدادات، وتعريفات الوكلاء.

## اختيار نموذج عند وقت التشغيل

### خيار `--model` / `-m`

خيار `--model` متاح في `bolt run` و`bolt commit` و`bolt review`:

```bash
bolt run --model anthropic/claude-opus-4-5 "refactor the payment module"
bolt commit --model openai/gpt-4o
bolt review --model google/gemini-2.5-pro --staged
```

### `--variant` — التحكم في جهد الاستدلال

تدعم بعض النماذج مستويات جهد استدلال قابلة للضبط (مثل التفكير الموسّع من Anthropic ونماذج الاستدلال من OpenAI). استخدم `--variant` لاختيار مستوى الجهد:

```bash
bolt run --variant high "design a distributed rate limiter"
bolt run --variant minimal "rename this variable"
```

<Note>
  تعتمد قيم المتغيّرات المتاحة على المزوّد والنموذج. القيم الشائعة هي `minimal` و`low` و`medium` و`high` و`max`، لكن المجموعة الدقيقة تختلف. راجع وثائق مزوّدك أو استخدم `bolt models --verbose` لرؤية المتغيّرات المدعومة لنموذج معيّن.
</Note>

### `--thinking` — إظهار كتل الاستدلال

عند استخدام نموذج يدعم التفكير الموسّع، مرّر `--thinking` لإظهار سلسلة تفكير النموذج في الإخراج:

```bash
bolt run --model anthropic/claude-opus-4-5 --variant high --thinking \
  "why does the token refresh logic race in the auth service?"
```

## تشغيلات best-of-N المتوازية

`--best-of` يطلق نفس الموجّه على نماذج متعدّدة بشكل متوازٍ، ثم يستخدم نموذج حكم لتصنيف الردود والاحتفاظ بالأفضل:

```bash
bolt run --best-of "anthropic/claude-opus-4-5,openai/gpt-4o,google/gemini-2.5-pro" \
  "implement a binary search tree with full test coverage"
```

الحكم افتراضيًا هو النموذج المُمرّر عبر `--model`، أو أول إدخال في قائمة `--best-of` إذا لم يُضبط `--model`. يقبل الخيار قائمة معرّفات `provider/model` مفصولة بفواصل.

<Tip>
  best-of-N مفيد خصوصًا للمشاكل الخوارزمية المعقّدة أو قرارات البنية حيث قد تجلب نماذج مختلفة مقاربات مختلفة حقًا. اترك Bolt يشغّلها بالتوازي ويختار الفائز تلقائيًا.
</Tip>
