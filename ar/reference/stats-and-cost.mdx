يجمّع `bolt stats` أعداد الرموز والتكلفة عبر قاعدة بيانات الجلسات المحلية. لأن كل استدعاء أداة مسجّل (راجع [قاعدة البيانات المحلية](/reference/local-database))، فإن الأرقام دقيقة لاستدعاءات LLM التي قادها Bolt.

## الاستخدام الأساسي

```bash
bolt stats                       # summary for the current project
bolt stats --days 7              # last seven days
bolt stats --days 7 --models     # break down by model
```

## ما يعرضه

- إجمالي رموز الإدخال والإخراج والتخزين المؤقت.
- تكلفة تقديرية لكل مزوّد (باستخدام جداول تسعير المزوّد وقت التشغيل).
- تفاصيل لكل نموذج ولكل وكيل ولكل يوم بحسب الخيارات.

## تقليل التكلفة

- استخدم `--variant minimal` أو `--variant low` على النماذج ذات الاستدلال الثقيل. راجع [المزوّدون والنماذج](/concepts/providers-and-models).
- فضّل الوكيل `ask` أو `plan` للاستكشاف؛ فهما للقراءة فقط ويتجنّبان الحلقات الثقيلة بالأدوات.
- انتقل إلى نموذج أصغر عبر `bolt models` للمهام التي لا تحتاج قدرة أمامية.

## ذات صلة

- [استكشاف الأخطاء وإصلاحها](/reference/troubleshooting) — ما تفعله بشأن فاتورة مفاجئة.
