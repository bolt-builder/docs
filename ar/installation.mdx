يمكن تثبيت Bolt على macOS وLinux وWindows بالطريقة التي تناسب سير عملك — سكربت curl بسطر واحد، أو أي مدير حزم Node.js رئيسي، أو مدير حزم نظام مثل Homebrew أو Chocolatey أو Scoop.

## التثبيت السريع (macOS / Linux)

أسرع طريقة للبدء هي سكربت التثبيت الرسمي. يكتشف نظام التشغيل والمعمارية تلقائيًا، وينزّل الملف الثنائي الصحيح إلى `~/.bolt/bin`، ويضيفه إلى `$PATH`.

```bash
curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash
```

يُعدّ المثبّت أيضًا اعتماديات إدخال الصوت الاختيارية (sox وwhisper-cpp للنسخ دون اتصال). لتخطي ذلك، مرّر `--no-voice`:

```bash
curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash -s -- --no-voice
```

لتثبيت إصدار محدّد:

```bash
curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash -s -- --version 1.20.2
```

## مدراء الحزم

ثبّت Bolt عالميًا باستخدام مدير الحزم الذي تختاره:

<CodeGroup>

```bash npm
npm i -g @bolt-builder/bolt-cli
```

```bash bun
bun add -g @bolt-builder/bolt-cli
```

```bash pnpm
pnpm add -g @bolt-builder/bolt-cli
```

```bash yarn
yarn global add @bolt-builder/bolt-cli
```

</CodeGroup>

## التحقق من التثبيت

<Steps>
  <Step title="تحقق من الإصدار المثبّت">
    بعد التثبيت، أكّد أن `bolt` متاح على `$PATH`:

    ```bash
    bolt --version
    ```

    إذا لم يُعثر على الأمر، افتح جلسة طرفية جديدة (أو أعِد تحميل إعداد الصدفة) حتى يسري تحديث `$PATH`.
  </Step>
</Steps>

## الترقية

شغّل `bolt upgrade` للترقية إلى أحدث إصدار:

```bash
bolt upgrade
```

يكتشف Bolt طريقة التثبيت الأصلية تلقائيًا. يمكنك تجاوز ذلك بخيار `--method`:

```bash
bolt upgrade --method <method>
```

الطرق المدعومة هي: `curl`، `npm`، `pnpm`، `bun`، `brew`، `choco`، `scoop`.

يمكنك أيضًا الترقية إلى إصدار محدّد عبر تمرير رقم الإصدار كوسيط موضعي:

```bash
bolt upgrade 1.20.2
```

## إلغاء التثبيت

لإزالة Bolt من نظامك:

```bash
bolt uninstall
```

## متغيرات البيئة

| المتغير               | الوصف                                           |
| ---------------------- | ----------------------------------------------------- |
| `BOLT_LOG_LEVEL`       | مستوى تفصيل السجلات: `DEBUG` أو `INFO` أو `WARN` أو `ERROR` |
| `BOLT_PRINT_LOGS`      | طباعة السجلات إلى stderr                              |
| `BOLT_PURE`            | التشغيل دون تحميل أي إضافات خارجية                    |
| `BOLT_SERVER_PASSWORD` | كلمة مرور المصادقة الأساسية لخادم API بدون واجهة       |
| `BOLT_SERVER_USERNAME` | اسم مستخدم المصادقة الأساسية لخادم API بدون واجهة      |

<Tip>
  اضبط `BOLT_PURE=1` عندما تريد تشغيلًا نظيفًا دون أي إضافات طرف ثالث — مفيد لتصحيح الأخطاء أو بيئات CI المحكومة.
</Tip>

## تطبيق سطح المكتب

<Note>
  يأتي Bolt أيضًا كتطبيق سطح مكتب أصلي مع إدارة جلسات متعدّدة النوافذ، وطرفية متكاملة وشجرة ملفات، ولوحة أوامر، و28 لغة واجهة، وتحديثات تلقائية. نزّل أحدث إصدار من [صفحة الإصدارات](https://github.com/Bolt-builder/bolt-cli/releases).

  على macOS يمكنك تثبيته بسطر واحد دون المرور بـ Gatekeeper:

  ```bash
  curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install-desktop | bash
  ```
</Note>
