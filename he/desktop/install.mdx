יישום שולחן העבודה של Bolt עוטף את אותו מנוע כמו ה-CLI בקליפת Electron מלאה. כל תכונה הזמינה במסוף — סוכנים, שרתי MCP, תוספים, סשנים מרוחקים, סשנים שתוכל לפצל ולשתף — עובדת באופן זהה ביישום שולחן העבודה, עם תוספת של חוויית ריבוי חלונות וריבוי לשוניות, ממשק הגדרות גרפי, התראות מקוריות ועדכונים אוטומטיים. אם אתה כבר משתמש ב-CLI, יישום שולחן העבודה הוא השלמה משתלבת, לא החלפה.

---

## התקנה

### macOS

<Steps>
  <Step title="התקן עם שורה אחת (מומלץ)">
    פתח מסוף והרץ:

    ```bash
    curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install-desktop | bash
    ```

    הסקריפט מוריד את השחרור האחרון, מאמת אותו, וממקם את היישום ב-`/Applications`. אין חלון קופץ של Gatekeeper.
  </Step>

  <Step title="השק את היישום">
    פתח את **Bolt** מ-`/Applications` או מ-Spotlight. בהשקה הראשונה, Bolt מבקש ממך לבחור ספק LLM ברירת מחדל ויוצר קובץ תצורה גלובלי.
  </Step>
</Steps>

<Tip>
  השורה האחת מתקינה את היישום בדרך שעוקפת את דו-שיח "מפתח לא מזוהה" של Gatekeeper ב-macOS, כך שתגיע ישירות לקידוד ללא הנחיות אבטחה נוספות.
</Tip>

### כל הפלטפורמות — הורדה מהשחרורים

הורד את המתקין האחרון עבור הפלטפורמה שלך מ-[עמוד השחרורים של Bolt](https://github.com/Bolt-builder/bolt-cli/releases).

| פלטפורמה | סוג מתקין |
|----------|---------------|
| macOS (Apple Silicon) | `.dmg` |
| macOS (Intel) | `.dmg` |
| Windows | מתקין `.exe` |
| Linux | `.AppImage` / `.deb` |

<Note>
  ב-Windows, Bolt כולל אינטגרציית WSL (Windows Subsystem for Linux). כאשר WSL זמין, Bolt יכול לפתוח סשנים ישירות בתוך הפצת ה-WSL שלך — נותן לך סביבת סוכן ילידית ל-Linux עם ממשק ילידי של Windows סביבו.
</Note>

## תכונות

### ניהול סשנים בריבוי חלונות וריבוי לשוניות

פתח כמה חלונות שאתה רוצה, כל אחד עם קבוצת לשוניות משלו. לשוניות ממופות ישירות לסשני Bolt, כך שתוכל להריץ סוכן על ריפקטור בלשונית אחת, לשאול שאלה באחרת, ולהריץ job רקע בשלישית — הכל בו זמנית.

### מלחין הנחיות

מלחין ההנחיות תומך בקלט עשיר: הדבק טקסט, גרור קבצים כקבצים מצורפים, או הדבק תמונה ישירות מהלוח. Bolt מקודד את התמונה ושולח אותה לכל מודל בעל יכולת ראייה אוטומטית.

### מסוף משולב ועץ קבצים

פריסת חלונית מפוצלת נותנת לך את שיחת הסוכן בצד אחד ומסוף חי ועץ קבצי פרויקט בצד השני. תוכל להריץ פקודות, לבדוק פלט ולהזין את התוצאות בחזרה לסוכן ללא החלפת יישומים.

### לוח פקודות

לחץ `Cmd/Ctrl+K` כדי לפתוח את לוח הפקודות. מכאן תוכל להחליף סשנים, לשנות סוכנים, לפתוח הגדרות או להפעיל כל פעולה מבלי להזדקק לעכבר.

### ממשק הגדרות מלא

פאנל ההגדרות מכסה כל אפשרות שחיה ב-`.bolt/bolt.jsonc` — קיצורי מקלדת, בחירת מודל, ספקי LLM, שרתי MCP ואימות — עם רשימות נפתחות, מתגים ואימות inline. אתה נדרש לעתים רחוקות לערוך את קובץ התצורה ביד.

### התראות מקוריות

Bolt יורה התראה מקורית של מערכת ההפעלה כשמשימה ממושכת מסתיימת. לחץ על ההתראה כדי לקפוץ ישירות לסשן.

### קישורים עמוקים

פתח סשן ספציפי על ידי ניווט לכתובת `bolt://`. שימושי לשיתוף קישורי סשנים עם עמיתים לצוות או ליצירת סימנייה לעבודה בתהליך.

### עדכונים אוטומטיים

יישום שולחן העבודה מעדכן את עצמו על פני שלושה ערוצים:

| ערוץ | תיאור |
|---------|-------------|
| `prod` | שחרורים יציבים, מתעדכנים בכל תג production |
| `beta` | build של טרום-שחרור לגישה מוקדמת לתכונות חדשות |
| `dev` | build לילי מענף `dev` |

החלף ערוצים ב-**Settings → About**.

### 28 שפות ממשק

ממשק Bolt מתורגם ל-28 שפות. שנה את שפת התצוגה ב-**Settings → Appearance → Language**.
