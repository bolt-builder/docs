Bolt TUI מעוצב להיות מופעל מקצה לקצה מהמקלדת. עמוד זה מפרט את קיצורי הדרך שתזדקק להם לעתים קרובות. לרשימה מלאה, הרץ `bolt` ופתח את העזרה בתוך היישום.

## חיוניים

| מקשים | פעולה |
| --- | --- |
| `Tab` | עבור לסוכן הבא (`code`, `plan`, `ask`, ...). הסוכן הנוכחי מוצג בשורת הסטטוס. |
| `Shift+Tab` | עבור לסוכן הקודם. |
| `Enter` | שלח את ההודעה הנוכחית. |
| `Esc` | בטל את הסבב בטיסה. |
| `Ctrl+C` | הפרע לקריאת הכלי הנוכחית. |
| `Ctrl+D` | נתק מהסשן (משאיר אותו רץ בשרת). |

## מצבים

### מצב `--mini`

הפעל את Bolt עם פריסת split-footer קומפקטית שתופסת פחות מקום במסוף, נהדר לחלוניות מפוצלות:

```bash
bolt --mini
bolt attach --mini <url>
```

### קול push-to-talk

החזק את מקש ה-push-to-talk המוגדר כדי להכתיב הנחיה באמצעות דיבור-לטקסט, ואז שחרר לשליחה. הגדר את המקש ואת ספק ה-STT ב-`.bolt/bolt.jsonc`.
