פקודות סלאש מוקלדות להנחיית ה-TUI ומשנות כיצד הסשן הנוכחי מתנהג. הן לא שולחות שום דבר למודל; הן רצות מקומית כנגד Bolt עצמו.

## הפניה

| פקודה | מה היא עושה |
| --- | --- |
| `/memory` | הצג סטטוס זיכרון פרויקט עבור סשן זה. |
| \`/memory use on | off\` | האם הסשן הזה קורא מ-[זיכרון פרויקט](/concepts/project-memory). |
| \`/memory contribute on | off\` | האם הסשן הזה כותב בחזרה לזיכרון פרויקט כשהסבב נסגר. |
| `/plan` | העבר את הסשן הנוכחי למצב תכנון (קריאה בלבד, מייצר תוכנית). |
| `/todos` | הצג את רשימת המשימות המובנית הנוכחית של הסוכן. |
| `/btw` | הזרק הערה חוץ-פסית ("דרך אגב...") שהסוכן יראה בסבב הבא שלו מבלי להפעיל תגובה מלאה. |

<Tip>
  פקודות סלאש מוגבלות לסשן. כדי להפוך העדפה לעמידה, הגדר אותה ב-`.bolt/bolt.jsonc` במקום. ראה [תצורה](/concepts/configuration).
</Tip>

## הוספת שלך

פקודות סלאש מותאמות אישית יכולות להיתרם על ידי [תוספים](/extending/plugins) ועל ידי קבצים ב-`.opencode/command/`. כל פקודה היא קובץ Markdown שה-frontmatter שלו מתאר את הטריגר וההתנהגות.
