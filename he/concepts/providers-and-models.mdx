Bolt הוא בלתי תלוי במודל בעיצוב. מתחת למכסה המנוע הוא משתמש ב-**Vercel AI SDK** כדי לדבר עם ספקים, מה שאומר שכל ספק ש-SDK תומך בו — Anthropic, OpenAI, Google, Amazon Bedrock, OpenRouter ועוד — עובד מהקופסה. קטלוג הספקים והמודלים נלקח מ-[models.dev](https://models.dev), מסד נתונים שנתמך על ידי הקהילה של מטא-נתונים ותמחור של ספקים.

## ניהול אישורי ספקים

השתמש ב-`bolt providers` (כינוי: `bolt auth`) כדי להוסיף, להציג ולהסיר אישורי ספקים.

### הוסף או עדכן אישורים

```bash
bolt providers login
# or equivalently:
bolt auth login
```

זה משיק הנחיה אינטראקטיבית לבחירת ספק והזנת אישורים. כדי לדלג על הזרימה האינטראקטיבית, העבר דגלים ישירות:

```bash
bolt providers login --provider anthropic
bolt providers login --provider openai --method "API key"
```

### הצג ספקים מוגדרים

```bash
bolt providers list
# or:
bolt auth list
```

מציג את כל האישורים המאוחסנים וכל מפתחות ה-API של ספקים שזוהו ממשתני סביבה.

### הסר אישורים

```bash
bolt providers logout
bolt providers logout anthropic
```

### אימות באמצעות משתני סביבה

עבור צינורות CI או סביבות ללא ראש, הגדר ישירות את משתנה הסביבה של מפתח ה-API של הספק — אין צורך בכניסה אינטראקטיבית. דוגמאות נפוצות:

```bash
export ANTHROPIC_API_KEY="sk-ant-..."
export OPENAI_API_KEY="sk-..."
export GOOGLE_GENERATIVE_AI_API_KEY="AIza..."
```

Bolt קורא משתנים אלה אוטומטית בהפעלה. `bolt providers list` יציג אילו משתני סביבה זוהו.

## דפדוף במודלים זמינים

`bolt models` מציג כל מודל זמין בכל הספקים המוגדרים שלך.

```bash
# List all models
bolt models

# Filter to one provider
bolt models anthropic

# Show cost and capability metadata
bolt models --verbose

# Refresh the model catalog from models.dev
bolt models --refresh
```

<Tip>
  הרץ `bolt models --verbose` כדי לראות תמחור טוקנים לקלט/פלט לכל מודל. זה מקל להשוות שיקולי עלות לפני התחייבות למודל למשימה ממושכת.
</Tip>

### פורמט מזהה מודל

מודלים תמיד מוזכרים בפורמט `provider/model`:

```
anthropic/claude-opus-4-5
openai/gpt-4o
google/gemini-2.5-pro
openrouter/anthropic/claude-opus-4-5
```

השתמש בפורמט הזה בכל מקום ש-Bolt מקבל מודל — דגלי CLI, קבצי תצורה והגדרות סוכן.

## בחירת מודל בזמן ריצה

### דגל `--model` / `-m`

הדגל `--model` זמין ב-`bolt run`, `bolt commit` ו-`bolt review`:

```bash
bolt run --model anthropic/claude-opus-4-5 "refactor the payment module"
bolt commit --model openai/gpt-4o
bolt review --model google/gemini-2.5-pro --staged
```

### `--variant` — שליטה במאמץ היגיון

מודלים מסוימים תומכים ברמות מאמץ היגיון הניתנות להגדרה (למשל, חשיבה מורחבת של Anthropic, מודלי היגיון של OpenAI). השתמש ב-`--variant` כדי לבחור את שכבת המאמץ:

```bash
bolt run --variant high "design a distributed rate limiter"
bolt run --variant minimal "rename this variable"
```

<Note>
  ערכי הווריאנט הזמינים תלויים בספק ובמודל. ערכים נפוצים הם `minimal`, `low`, `medium`, `high` ו-`max`, אך הסט המדויק משתנה. בדוק את תיעוד הספק שלך או השתמש ב-`bolt models --verbose` כדי לראות ווריאנטים נתמכים למודל נתון.
</Note>

### `--thinking` — הצג בלוקי היגיון

בעת שימוש במודל התומך בחשיבה מורחבת, העבר `--thinking` כדי להציג את שרשרת המחשבה של המודל בפלט:

```bash
bolt run --model anthropic/claude-opus-4-5 --variant high --thinking \
  "why does the token refresh logic race in the auth service?"
```

## הרצות מקבילות best-of-N

`--best-of` יורה את אותה הנחיה למספר מודלים במקביל, ואז משתמש במודל שופט כדי לדרג את התגובות ולשמור את הטובה ביותר:

```bash
bolt run --best-of "anthropic/claude-opus-4-5,openai/gpt-4o,google/gemini-2.5-pro" \
  "implement a binary search tree with full test coverage"
```

השופט מוגדר כברירת מחדל למודל שהועבר דרך `--model`, או לרשומה הראשונה ברשימת `--best-of` אם `--model` לא מוגדר. הדגל מקבל רשימה מופרדת בפסיקים של מזהי `provider/model`.

<Tip>
  Best-of-N שימושי במיוחד לבעיות אלגוריתמיות מורכבות או החלטות ארכיטקטורה שבהן מודלים שונים עשויים להביא גישות שונות באמת. תן ל-Bolt להריץ אותם במקביל ולבחור את הזוכה אוטומטית.
</Tip>
