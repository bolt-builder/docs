סוכני Bolt יכולים לקרוא קבצים, לכתוב קבצים ולהריץ פקודות מעטפת. הכוח הזה מוגבל דרך שתי שכבות: רמת גישה לכל סוכן, והנחיות הרשאה אינטראקטיביות שתוכל לאשר, לדחות או להגדיר מראש.

## רמות גישה של סוכן

לכל סוכן מובנה יש רמת גישה מוצהרת:

| רמת גישה | קריאת קבצים | כתיבת קבצים | הרצת פקודות מעטפת |
| --- | --- | --- | --- |
| **Full** | ✓ | ✓ | ✓ |
| **Edit** | ✓ | ✓ | ✗ |
| **Read** | ✓ | ✗ | ✗ |

מיפויים מובנים:

- **Full** — `code`, `debug`, `refactor`, `migrate`, `perf`
- **Edit** — `docs`
- **Read** — `plan`, `ask`, `code-review`, `security`

החלף סוכנים עם `Tab` ב-TUI, או העבר `--agent <name>` ל-`bolt run`.

## הנחיות אינטראקטיביות

בתוך רמת הגישה של סוכן, פעולות הרסניות פוטנציאלית עדיין מבקשות אישור. תוכל לאשר פעם אחת, לאשר לסשן, או לדחות. קריאות שנדחו מחזירות שגיאה לסוכן והוא ממשיך הלאה.

## אישור לא-אינטראקטיבי

עבור CI, סקריפטים או זרימות עבודה מקומיות מהימנות, `bolt run` תומך בדגלים שדילגים על הנחיות:

```bash
bolt run --auto "tidy up imports"                   # auto-approve anything not explicitly denied
bolt run --yolo "tidy up imports"                   # alias for --auto
bolt run --dangerously-skip-permissions "..."       # bypass every prompt
```

<Warning>
  `--auto`, `--yolo` ו-`--dangerously-skip-permissions` מאפשרים לסוכן לקרוא, לכתוב ולהריץ מבלי לשאול. השתמש בהם רק בסביבות מהימנות.
</Warning>

## כללים ברמת התצורה

תוכל לדחות מראש (או לאשר מראש) כלים ספציפיים לכל הפרויקט על ידי הוספת בלוק `permission` ל-`.bolt/bolt.jsonc`. זה חל על כל סשן בפרויקט, כולל קריאות `bolt run` לא-אינטראקטיביות. ראה [תצורה](/concepts/configuration) לסכמה.
