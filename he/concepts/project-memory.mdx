זיכרון פרויקט הוא מה שגורם ל-Bolt להרגיש כאילו הוא כבר מכיר את הפרויקט שלך. כאשר סשן מסיים סבב, Bolt מזקק את מה שהיה שימושי וכותב אותו למאגר זיכרון פר-פרויקט. כאשר אתה פותח סשן חדש, Bolt מזריק אינדקס זיכרון בתוספת התקציר האחרון של הסשן להנחיית המערכת, כך שהסוכן מתחיל עם הקשר אמיתי במקום לוח ריק.

## איך הקליטה עובדת

בסוף כל סבב שיחה, Bolt מבקש מהמודל לסכם עובדות עמידות שיהיו שימושיות בפעם הבאה: מוסכמות, הערות ארכיטקטורה, מבנה קבצים, פקודות build/test, מלכודות ותהליכים פתוחים. אלה נכתבים לדיסק תחת ספריית הזיכרון של הפרויקט, לצד תקציר מתגלגל של הסשן האחרון.

הזיכרון הוא פר-פרויקט. שני checkout של אותו מאגר על אותה מכונה חולקים זיכרון; פרויקטים לא קשורים אף פעם לא רואים זה את הזיכרון של זה.

## כלים מפורשים

סוכנים יכולים גם לקרוא ולכתוב זיכרון ישירות במהלך סשן:

- `memory_save` — רשום עובדה ספציפית שהסוכן צריך לזכור בפעם הבאה.
- `memory_recall` — חפש משהו שהסוכן (או אתה) קלטת קודם.

תוכל לבקש מהסוכן "לזכור שאנחנו משתמשים ב-pnpm, לא ב-npm" והוא יקרא ל-`memory_save` בשבילך.

## בקרות לכל סשן

בתוך ה-TUI תוכל להחליף את התנהגות הזיכרון לסשן הנוכחי עם פקודות סלאש:

```text
/memory use on|off         # whether this session reads project memory
/memory contribute on|off  # whether this session writes back to memory
```

זה שימושי כאשר אתה רוצה סשן חקירה חד-פעמי שלא מזהם את הזיכרון שלך, או סשן לקריאה בלבד שעדיין נהנה מהקשר קודם.

## בדיקה ועריכה של הזיכרון

```bash
bolt memory           # inspect the memory store for the current project
```

הזיכרון מאוחסן כקבצים רגילים בדיסק תחת ספריית הנתונים של Bolt של הפרויקט, כך שתוכל לבצע grep, לערוך או למחוק ערכים ישירות. כדי למצוא את הנתיב המדויק במחשב שלך, הרץ `bolt debug paths`.
