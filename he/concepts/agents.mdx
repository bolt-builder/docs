Bolt מתייחס לכל פרסונת AI כאל **סוכן** בעל שם: הנחיית מערכת המשולבת עם קבוצה מדויקת של הרשאות כלים. במקום להריץ מודל כללי אחד לכל משימה, אתה בוחר את הסוכן שהגישה והמיקוד שלו מתאימים למה שאתה צריך — בין אם זה ביקורת אבטחה, כתיבת תיעוד או חיבור מיגרציה מלאה של פריימוורק.

## רמות גישה

לכל סוכן מובנה מוקצית אחת משלוש שכבות גישה שקובעות אילו כלים הוא יכול להפעיל:

| רמה | הרשאות שניתנות | שימוש טיפוסי |
|-------|---------------------|-------------|
| **Full** | קריאת קבצים, כתיבה/עריכת קבצים, הרצת פקודות מעטפת | קידוד פעיל, ניפוי שגיאות, ריפקטורינג, מיגרציות |
| **Edit** | קריאת קבצים, כתיבה/עריכת קבצים — ללא מעטפת | תיעוד, עדכוני הערות, עריכות פרוזה בטוחות |
| **Read** | קריאת קבצים בלבד — ללא כתיבה, ללא מעטפת | תכנון, מחקר, סקירת קוד, ביקורות |

## סוכנים מובנים

Bolt מגיע עם עשרה סוכנים מתמחים מהקופסה. החלף ביניהם ב-TUI על ידי לחיצה על <kbd>Tab</kbd>.

| סוכן | גישה | תיאור |
|-------|--------|-------------|
| `code` | Full | ברירת מחדל: קורא, כותב ומריץ קוד |
| `plan` | Read | חוקר את בסיס הקוד ומייצר תוכנית ללא שינוי קוד |
| `ask` | Read | שאלות ומחקר — ללא עריכות קבצים |
| `code-review` | Read | סוקר שינויים לנכונות, סגנון ואבטחה |
| `debug` | Full | מנפה בדיקות כושלות, קריסות ושגיאות לוגיקה |
| `refactor` | Full | ריפקטורינג בטוח עם אימות בדיקות בכל שלב |
| `docs` | Edit | כותב ומעדכן תיעוד והערות |
| `security` | Read | ביקורת אבטחה: פגיעויות, סודות ודפוסים מסוכנים |
| `migrate` | Full | שדרוגי פריימוורק ומיגרציות תלויות |
| `perf` | Full | ניתוח ביצועים ואופטימיזציה |

## תת-סוכנים

בנוסף לעשרת הסוכנים הראשיים, Bolt חושף שני **תת-סוכנים** מובנים שסוכנים ראשיים יכולים להאציל אליהם עבודה במהלך סשן. אתה אף פעם לא בוחר תת-סוכן ידנית — הם נשלחים אוטומטית כשסוכן ראשי מחליט להפעיל אחד.

| תת-סוכן | תפקיד |
|----------|------|
| `@general` | האצלה של משימות רב-שלביות מורכבות הדורשות יכולות רחבות |
| `@explore` | מחקר מהיר לקריאה בלבד של בסיס הקוד — עובר על קבצים ללא תופעות לוואי |

<Tip>
  כאשר אתה צריך להבין במהירות בסיס קוד לא מוכר, התחל עם הסוכן `ask` או `plan`. מאחורי הקלעים הם יכולים לשלוח את תת-הסוכן `@explore` כדי לאנדקס את הפרויקט שלך במהירות גבוהה לפני שהוא מייצר תשובה — מבלי לגעת בקובץ אחד.
</Tip>

## החלפת סוכנים

**ב-TUI** — לחץ <kbd>Tab</kbd> כדי לעבור בין רשימת הסוכנים הזמינים בכל עת במהלך סשן. הסוכן הפעיל מוצג בכותרת התחתונה של הסשן.

**באופן לא-אינטראקטיבי** — העבר `--agent <name>` ל-`bolt run` כדי לנעול סוכן ספציפי למשך אותה הרצה:

```bash
bolt run --agent ask "what does the authentication flow do?"
bolt run --agent security "audit the API layer for injection vulnerabilities"
bolt run --agent docs "add JSDoc comments to every exported function in src/utils"
```

## הצגת רשימת סוכנים

כדי לראות את כל הסוכנים הזמינים — הן מובנים והן מותאמים אישית — עם המצבים והגדרת ההרשאות שלהם:

```bash
bolt agent list
```

## סוכנים מותאמים אישית

תוכל ליצור סוכנים משלך בשתי דרכים.

### יצירה עם `bolt agent create`

האשף האינטראקטיבי מייצר קובץ סוכן באמצעות LLM וכותב אותו לדיסק:

```bash
bolt agent create
```

כל הדגלים אופציונליים. ספק אותם כדי להריץ באופן לא-אינטראקטיבי:

```bash
bolt agent create \
  --description "Audit GraphQL resolvers for N+1 problems and suggest DataLoader fixes" \
  --path .bolt/agents \
  --mode primary \
  --permissions read,grep,glob \
  --model anthropic/claude-opus-4-5
```

| דגל | תיאור |
|------|-------------|
| `--description` | מה הסוכן צריך לעשות (משמש כהנחיית LLM ליצירה) |
| `--path` | ספרייה שבה יש לכתוב את קובץ הסוכן שנוצר |
| `--mode` | `all` (ברירת מחדל), `primary`, או `subagent` |
| `--permissions` | רשימה מופרדת בפסיקים של הרשאות לאפשר. השמט לכולן. |
| `--model` / `-m` | מודל לשימוש בפורמט `provider/model` |

### כתיבת קובץ markdown ידנית

סוכן הוא פשוט קובץ markdown עם frontmatter של YAML. הצב אותו ב-`.bolt/agents/` בתוך הפרויקט שלך או בספריית הסוכנים הגלובלית:

```markdown
---
description: "Audit GraphQL resolvers for N+1 problems"
mode: primary
permission:
  bash: deny
  edit: deny
---

You are a GraphQL performance specialist. Your job is to identify N+1 query
patterns in resolver code and recommend DataLoader-based solutions...
```

שם הקובץ (ללא `.md`) הופך למזהה הסוכן.

### הרשאות זמינות

הרשאות הן שערי הכלים הפרטניים שאתה שולט בהם בעת יצירת סוכן מותאם אישית:

| הרשאה | שולט על |
|------------|----------|
| `bash` | הרצת פקודות מעטפת |
| `read` | קריאת קבצים |
| `edit` | כתיבה ועריכת קבצים (גם שולט על `write` ו-`apply_patch`) |
| `glob` | רשימת קבצים/ספריות עם glob |
| `grep` | חיפוש קבצים באמצעות ripgrep |
| `webfetch` | שליפת HTTP מהאינטרנט |
| `task` | הפעלת משימות תת-סוכן |
| `todowrite` | יצירה ועדכון פריטי מטלה |
| `websearch` | שאילתות חיפוש באינטרנט |
| `lsp` | פעולות פרוטוקול שרת שפה |
| `skill` | גישה למיומנויות הפרויקט |
