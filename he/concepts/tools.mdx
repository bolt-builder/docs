סוכנים ב-Bolt עושים עבודה על ידי קריאה לכלים. כל פעולה שאתה רואה ב-TUI (קריאת קובץ, הרצת בדיקות, חיפוש באינטרנט) היא המודל בוחר כלי ו-Bolt מבצע אותו. לכל סוכן יש רמת גישה מוצהרת שקובעת אילו כלים הוא יכול לקרוא מבלי לשאול אותך תחילה (ראה [הרשאות](/concepts/permissions)).

## כלים מובנים

| כלי | מה הוא עושה |
| --- | --- |
| `read` | קריאת קובץ מהדיסק. |
| `write` | יצירת קובץ חדש או דריסה של קיים. |
| `edit` | החלת עריכה ממוקדת (find/replace) על קובץ. |
| `apply_patch` | החלת טלאי בסגנון unified-diff על קובץ אחד או יותר. |
| `glob` | רשימת קבצים התואמים תבנית glob. |
| `grep` | חיפוש בתוכן קבצים לפי regex/טקסט. |
| `bash` | הרצת פקודת מעטפת. |
| `task` | האצלת תת-משימה לתת-סוכן (`@general`, `@explore`, או תת-סוכן מותאם אישית). |
| `todowrite` | תחזוקת רשימת המשימות המובנית של הסוכן לעבודה רב-שלבית. |
| `webfetch` | שליפת URL והחזרת תוכנו. |
| `websearch` | חיפוש באינטרנט. |
| `skill` | הפעלת מיומנות בעלת שם (ראה [מיומנויות](/extending/skills)). |
| `memory_save` | שמירת עובדה ל-[זיכרון פרויקט](/concepts/project-memory). |
| `memory_recall` | חיפוש זיכרון שנשמר בעבר. |
| `question` | שאל אותך שאלת הבהרה והמתן לתשובה. |
| `bash_background` | הפעלת פקודת מעטפת כתהליך רקע מנוהל (שרתי פיתוח, צופים, builds ארוכים). |
| `process_output` | קריאת פלט מצטבר וסטטוס עבור תהליך רקע, בהמתנה לסיום אופציונלית. |
| `list_processes` | רשימת תהליכי רקע עם המזהה, הסטטוס והפקודה שלהם. |
| `kill_process` | סיום תהליך רקע (ועץ התהליכים שלו) לפי מזהה. |
| `test_run` | זיהוי והרצת בדיקות הפרויקט, מחזיר תוצאות מובנות של הצלחה/כישלון ופרטי כישלון. |

### ניסיוני

| כלי | מה הוא עושה |
| --- | --- |
| `lsp` | תשאל שרת שפה עבור הגדרות, הפניות ואבחונים. |
| `execute` | הרץ קוד ב-sandbox של code-mode מבודד. |
| `plan` | הפק תוכנית מובנית לפני ביצוע שינויים. |

כלים ניסיוניים עשויים להשתנות או להיקרא מחדש בין גרסאות.

## הרחבת ערכת הכלים

מעבר למובנים, Bolt יכול לקרוא לכלים משלושה מקורות:

- **כלים מותאמים אישית** ב-`.opencode/tool/` (או `.opencode/tools/`) בשורש הפרויקט. ראה [כלים מותאמים אישית](/extending/custom-tools).
- **כלי תוספים** שנתרמו על ידי כל [תוסף](/extending/plugins) מותקן.
- **כלי MCP** מכל [שרת MCP](/extending/mcp-servers) שהוגדר לפרויקט.
 
שלושתם מרגישים זהים מנקודת המבט של הסוכן: הם מופיעים ברשימת הכלים, מכבדים את רמת הגישה של הסוכן, ומופיעים בפלט קריאת הכלים של ה-TUI.
