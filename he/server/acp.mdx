Bolt מיישם את ה-Agent Client Protocol (ACP), שהוא כיצד עורכים כמו Zed מדברים עם סוכני AI. לאחר ההגדרה, העורך מפעיל את `bolt acp` כתהליך משנה ומפעיל אותו ישירות — אתה מקבל את הסוכנים, הכלים, הסשנים ומחסנית הספקים של Bolt מבלי לעזוב את העורך שלך.

## אפשר ACP

בהגדרות ה-AI של העורך שלך, הוסף את Bolt כסוכן תואם ACP והצבע עליו ל:

```bash
bolt acp
```

העורך ינהל את מחזור החיים של התהליך. הגדר ספקים, מודלים ושרתי MCP כפי שאתה עושה בדרך כלל ב-`.bolt/bolt.jsonc` — הם חלים גם כאן.

## מה אתה מקבל

- כל סוכן של Bolt, ניתן לקריאה מפאנל ה-AI של העורך.
- סשנים משותפים עם ה-TUI וממשק הווב (דרך מסד הנתונים המקומי).
- אותה ערכת כלים, מודל הרשאות וזיכרון פרויקט כמו כל נקודת כניסה אחרת של Bolt.
