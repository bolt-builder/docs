## מה Bolt עושה

Bolt קורא את בסיס הקוד שלך, מבין מה אתה בונה, ומשחרר קוד איתך—במסוף או כיישום שולחן עבודה. כל סשן הוא עמיד: נתק, חבר מחדש ממכונה אחרת, פצל ענף של השיחה, שתף קישור, או ייצא תמליל מנוקה.

## התחל לרוץ

<Steps>
  <Step title="התקן את Bolt">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash
    ```
    או התקן דרך npm: `npm i -g @bolt-builder/bolt-cli`
  </Step>
  <Step title="פתח את הפרויקט שלך">
    נווט לכל ספריית פרויקט והשק את ה-TUI:
    ```bash
    cd my-project
    bolt
    ```
  </Step>
  <Step title="הגדר ספק">
    בהשקה הראשונה Bolt מבקש ממך להוסיף ספק LLM. תוכל גם להריץ:
    ```bash
    bolt providers
    ```
  </Step>
  <Step title="התחל לקודד עם AI">
    הקלד את ההנחיה שלך בכותרת התחתונה של ה-TUI, לחץ Enter, ותן לסוכני Bolt להתחיל לעבוד. החלף סוכנים עם `Tab`.
  </Step>
</Steps>

<Tip>
  השתמש ב-`bolt run "explain this codebase"` לתשובה לא-אינטראקטיבית מהירה מבלי לפתוח את ה-TUI המלא.
</Tip>
