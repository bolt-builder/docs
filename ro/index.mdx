Bolt îți pune o echipă completă de inginerie AI direct în terminal. Este livrat ca un TUI rapid, controlat de la tastatură, și ca o aplicație desktop nativă, ambele susținute de același motor: zece agenți specializați, sesiuni persistente durabile, gestionarea serverelor MCP cu OAuth, un sistem de plugin-uri și suport pentru fiecare furnizor LLM major.

## Ce face Bolt

Bolt îți citește baza de cod, înțelege ce construiești și livrează cod împreună cu tine — în terminal sau ca aplicație desktop. Fiecare sesiune este durabilă: te poți detașa, te poți reataca de pe altă mașină, poți crea o ramură a conversației, poți partaja un link sau exporta o transcriere curățată.

## Pune totul în funcțiune

<Steps>
  <Step title="Instalează Bolt">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash
    ```
    Sau instalează prin npm: `npm i -g @bolt-builder/bolt-cli`
  </Step>
  <Step title="Deschide-ți proiectul">
    Navighează în orice director de proiect și lansează TUI-ul:
    ```bash
    cd my-project
    bolt
    ```
  </Step>
  <Step title="Configurează un furnizor">
    La prima lansare, Bolt îți cere să adaugi un furnizor LLM. Poți rula și:
    ```bash
    bolt providers
    ```
  </Step>
  <Step title="Începe să codezi cu AI">
    Scrie promptul în subsolul TUI-ului, apasă Enter și lasă agenții Bolt să se apuce de treabă. Schimbă agenții cu `Tab`.
  </Step>
</Steps>

<Tip>
  Folosește `bolt run "explain this codebase"` pentru un răspuns rapid, neinteractiv, fără a deschide întregul TUI.
</Tip>
