Bolt este un agent AI de codare axat pe terminal, construit pe [Effect](https://effect.website), [OpenTUI](https://github.com/opentui/opentui) și [SolidJS](https://www.solidjs.com). Îndreaptă-l către orice proiect și își preia contextul automat: îți explorează codul, îți respectă convențiile, execută comenzi shell, editează fișiere, rulează teste și livrează modificări.

Zece agenți încorporați (`code`, `plan`, `ask`, `code-review`, `debug`, `refactor`, `docs`, `security`, `migrate`, `perf`) plus subagenții `@general` și `@explore` acoperă întreaga buclă de inginerie. Sesiunile sunt durabile: te poți detașa, reatasa (chiar și la un server la distanță), ramifica, partaja, exporta și importa oricând. Memoria proiectului persistă ceea ce învață agentul între sesiuni. Extensibil prin servere MCP (cu OAuth), plugin-uri, agenți personalizați și instrumente personalizate.

Bolt este open-source sub licența PolyForm Noncommercial 1.0.0.

## De ce Bolt?

Bolt este proiectat în jurul modului în care dezvoltatorii lucrează efectiv: în terminal, pe mai multe sesiuni, pe baze de cod reale. Iată ce îl face să se remarce:

- **TUI axat pe terminal.** O interfață rapidă, controlată de la tastatură, construită cu [Effect](https://effect.website), [OpenTUI](https://github.com/opentui/opentui) și [SolidJS](https://www.solidjs.com). Pare nativă pentru că este.
- **O echipă întreagă de agenți.** Zece agenți specializați — `code`, `plan`, `ask`, `code-review`, `debug`, `refactor`, `docs`, `security`, `migrate` și `perf` — plus subagenți pentru cercetare și delegare în mai mulți pași. Comută între ei cu `Tab`.
- **Sesiuni pe care le poți părăsi și relua.** Detașează-te de o sesiune și reataca-te mai târziu, chiar și pe un server la distanță. Ramifică, partajează, exportă și importă lucrul oricând. Sesiunile sunt stocate în SQLite și complet inspectabile cu `bolt db`.
- **Extensibil prin design.** Servere MCP cu suport OAuth complet, un sistem de plugin-uri, integrare GitHub, un server API încorporat și un UI web.
- **Aplicație desktop.** Același motor învelit într-o experiență desktop multi-fereastră, multi-tab — cu terminal integrat, arbore de fișiere, paletă de comenzi, 28 de limbi de interfață și actualizări automate.

## Agenți încorporați

Bolt este livrat cu zece agenți specializați. Fiecare agent are un nivel definit de acces la sistemul de fișiere pentru a se potrivi cu scopul său.

| Agent | Acces | Descriere |
| --- | --- | --- |
| `code` | Full | Implicit: citește, scrie și rulează cod |
| `plan` | Read | Explorează baza de cod și produce un plan fără a modifica fișierele |
| `ask` | Read | Întrebări și cercetare — fără editări de fișiere |
| `code-review` | Read | Revizuiește modificările pentru corectitudine, stil și securitate |
| `debug` | Full | Depanează teste eșuate, blocări și erori de logică |
| `refactor` | Full | Refactorizare sigură cu verificare a testelor la fiecare pas |
| `docs` | Edit | Scrie și actualizează documentația și comentariile |
| `security` | Read | Audit de securitate: vulnerabilități, secrete, tipare |
| `migrate` | Full | Actualizări de framework și migrări de dependențe |
| `perf` | Full | Analiză și optimizare a performanței |

Îți poți defini și proprii agenți ca fișiere Markdown sau poți genera unul cu `bolt agent create`.

## Aplicația desktop

Bolt este livrat și ca aplicație desktop de sine stătătoare, cu gestionare de sesiuni multi-fereastră și multi-tab, un compunător de prompturi cu suport pentru atașamente și lipire de imagini din clipboard, un terminal integrat și un arbore de fișiere, o paletă de comenzi, setări complete pentru combinații de taste, modele, furnizori și servere, notificări native, link-uri profunde, integrare WSL pe Windows și actualizări automate pe canalele dev, beta și de producție.

Descarcă aplicația desktop de pe [pagina de lansări](https://github.com/Bolt-builder/bolt-cli/releases) sau instalează-o într-o singură linie pe macOS fără ocol prin Gatekeeper:

```bash
curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install-desktop | bash
```
