Bolt met une équipe d'ingénierie IA complète directement dans votre terminal. Il est livré sous forme de TUI rapide piloté au clavier et d'application de bureau native, tous deux animés par le même moteur : dix agents spécialisés, des sessions persistantes durables, la gestion de serveurs MCP avec OAuth, un système de plugins et la prise en charge de tous les grands fournisseurs LLM.

## Ce que fait Bolt

Bolt lit votre base de code, comprend ce que vous construisez et livre du code avec vous — dans le terminal ou en tant qu'application de bureau. Chaque session est durable : détachez-vous, rattachez-vous depuis une autre machine, créez une branche de la conversation, partagez un lien ou exportez une transcription épurée.

## Se lancer

<Steps>
  <Step title="Installer Bolt">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash
    ```
    Ou installez via npm : `npm i -g @bolt-builder/bolt-cli`
  </Step>
  <Step title="Ouvrir votre projet">
    Rendez-vous dans n'importe quel répertoire de projet et lancez le TUI :
    ```bash
    cd my-project
    bolt
    ```
  </Step>
  <Step title="Configurer un fournisseur">
    Au premier lancement, Bolt vous invite à ajouter un fournisseur LLM. Vous pouvez aussi exécuter :
    ```bash
    bolt providers
    ```
  </Step>
  <Step title="Commencer à coder avec l'IA">
    Saisissez votre prompt dans le pied de page du TUI, appuyez sur Entrée et laissez les agents de Bolt travailler. Changez d'agent avec `Tab`.
  </Step>
</Steps>

<Tip>
  Utilisez `bolt run "explain this codebase"` pour obtenir une réponse rapide non interactive sans ouvrir le TUI complet.
</Tip>
