L'application de bureau, c'est le même moteur Bolt intégré dans une coque native, avec quelques éléments qu'un terminal ne peut pas faire facilement.

## Ce qui est inclus

- **Sessions multi-fenêtres, multi-onglets.** Exécutez plusieurs agents en parallèle sur différents projets, chacun dans son propre onglet.
- **Compositeur de prompts.** Saisie enrichie avec pièces jointes de fichiers et collage d'images depuis le presse-papiers — déposez des captures d'écran directement dans le prompt.
- **Terminal intégré \+ arborescence de fichiers.** Un vrai shell et un explorateur de projet à côté du chat.
- **Palette de commandes.** `Cmd/Ctrl+K` pour naviguer entre les sessions, exécuter n'importe quelle commande Bolt ou déclencher un slash command.
- **Paramètres.** Raccourcis clavier, modèles, fournisseurs et serveurs configurés, tous modifiables dans une véritable interface de paramètres.
- **Notifications natives.** Le système d'exploitation vous prévient quand un agent long à s'exécuter a terminé.
- **Liens profonds.** URL `bolt://` pour accéder aux sessions depuis n'importe où.
- **Intégration WSL sur Windows.** Fonctionne avec votre environnement WSL par défaut.
- **28 langues d'interface.**
