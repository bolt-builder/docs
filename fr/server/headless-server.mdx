`bolt serve` exécute un serveur Bolt sans interface qui expose le moteur complet via HTTP : sessions, agents, outils, accès aux fournisseurs, MCP et événements en streaming. Tout ce que Bolt peut faire de manière interactive, il peut le faire via l'API.

## Démarrer un serveur

```bash
bolt serve                              # localhost uniquement, port aléatoire
bolt serve --hostname 0.0.0.0 --port 4096
bolt serve --mdns                       # annoncer sur le réseau local
```

<Warning>
  Écouter sur `0.0.0.0` expose Bolt sur votre réseau. Définissez toujours `BOLT_SERVER_USERNAME` et `BOLT_SERVER_PASSWORD` au préalable.
</Warning>

## Rattacher un TUI

Depuis n'importe quelle machine capable d'atteindre le serveur :

```bash
bolt attach http://server:4096
bolt attach --mini http://server:4096
```

Ou exécuter un prompt ponctuel contre un serveur distant :

```bash
bolt run --attach http://server:4096 --dir /projects/api "what tests are failing?"
```

## Basic auth

Définissez les informations d'identification via des variables d'environnement (voir [Variables d'env](/reference/environment-variables)) :

```bash
export BOLT_SERVER_USERNAME=teamname
export BOLT_SERVER_PASSWORD=$(openssl rand -hex 24)
bolt serve --hostname 0.0.0.0 --port 4096
```

Tous les clients doivent envoyer des informations d'identification correspondantes.
