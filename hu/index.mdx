A Bolt egy teljes MI-mérnökcsapatot helyez közvetlenül a terminálodba. Gyors, billentyűzet-vezérelt TUI és natív asztali alkalmazás formájában érkezik, mindkettőt ugyanaz a motor hajtja: tíz szakosított ügynök, tartós, megbízható munkamenetek, MCP-szerverkezelés OAuth-tal, plugin-rendszer és minden fontosabb LLM-szolgáltató támogatása.

## Mit csinál a Bolt

A Bolt olvassa a kódbázisodat, megérti, mit építesz, és veled együtt szállítja a kódot — a terminálban vagy asztali alkalmazásként. Minden munkamenet tartós: bármikor leválaszthatod, újracsatlakozhatsz egy másik gépről, elágaztathatod a beszélgetést, megoszthatsz egy linket vagy exportálhatsz egy megtisztított átiratot.

## Vágj bele

<Steps>
  <Step title="Telepítsd a Bolt-ot">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash
    ```
    Vagy telepítsd npm-en keresztül: `npm i -g @bolt-builder/bolt-cli`
  </Step>
  <Step title="Nyisd meg a projekted">
    Lépj be egy tetszőleges projektkönyvtárba, és indítsd el a TUI-t:
    ```bash
    cd my-project
    bolt
    ```
  </Step>
  <Step title="Állíts be egy szolgáltatót">
    Első indításkor a Bolt felajánlja egy LLM-szolgáltató hozzáadását. Bármikor futtathatod is:
    ```bash
    bolt providers
    ```
  </Step>
  <Step title="Kezdj el kódolni MI-vel">
    Írd be a promptot a TUI láblécében, nyomj Enter-t, és hagyd, hogy a Bolt ügynökei dolgozzanak. Váltogass ügynökök között a `Tab` billentyűvel.
  </Step>
</Steps>

<Tip>
  Használd a `bolt run "explain this codebase"` parancsot egy gyors, nem interaktív válaszért anélkül, hogy megnyitnád a teljes TUI-t.
</Tip>
