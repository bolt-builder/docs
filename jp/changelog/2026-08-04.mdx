## 新機能

- **11 の新しい UI 言語** — デスクトップアプリと TUI に、ヒンディー語、オランダ語、インドネシア語、ベトナム語、イタリア語、ウルドゥー語、パンジャブ語、アゼルバイジャン語、フィンランド語、スウェーデン語、タイ語の翻訳が追加され、サポート言語は合計 28 言語になりました。**Settings → Appearance → Language** で言語を切り替えられます。[Desktop features](/desktop/features) および [Install](/desktop/install#28-ui-languages) を参照してください。
- **右から左レイアウトのサポート** — アラビア語、ヘブライ語、ウルドゥー語などの右から左に読む言語について、ナビゲーション、エディタ、ダイアログ、コントロール、テキストレンダリングが正しくミラーリングされ、インターフェイス全体がそれらのロケールで自然に読めるようになりました。
- **ネイティブデスクトップ翻訳** — OS レベルのメニュー、アップデータダイアログ、リカバリフロー、WSL オンボーディング、ネイティブファイルピッカーが、アプリ内 UI と共にローカライズされ、デスクトップ体験全体が言語設定に従うようになりました。
- **ローカライズカバレッジの拡張** — メニュー、ダイアログ、プロンプト、ヘルプコンテンツ、エラーメッセージ、アクセシビリティラベルが、サポートされているすべての言語で翻訳され、以前は英語にフォールバックしていた箇所が埋められました。
- **Poolside プロバイダ** — Bolt が OpenAI 互換 API を介して [Poolside](https://poolside.ai) に接続できるようになりました。`/connect` を実行し、**Poolside** を選択して、[platform.poolside.ai](https://platform.poolside.ai) から API キーを貼り付けてください。セルフホスト型の Poolside デプロイもカスタムプロバイダとして構成できます。[Providers and models](/concepts/providers-and-models) を参照してください。
- **ロケール対応の複数形処理** — カウント、ステータス、ファイル、セッションリスト項目が言語ごとに正しく複数形化され、タイムラインとステータステキストがすべてのサポート対象ロケールで自然に読めるようになりました。
- **より豊かな Markdown レンダリング** — アシスタントメッセージの Markdown 書式が改善され、ストリーミング更新がよりスムーズになり、シンタックスハイライトが向上し、数式コンテンツもサポートされ、長文および技術的な応答が読みやすくなりました。

## アップデート

- **GPT-5 の推論エフォートがモデルバージョンと一致** — 推論エフォート層 (`none` および `xhigh` を含む) が、それらをサポートする GPT-5 バリアントに対してのみ提供されるようになり、`--variant` が特定のモデルで拒否されるオプションを表示しなくなりました。[Controlling reasoning effort](/concepts/providers-and-models#variant-controlling-reasoning-effort) を参照してください。
- **diff アノテーションの改良** — セッション UI の diff ビューで、コメントインジケータ、ガター動作、ライト/ダークのシンタックスカラーが調整され、可読性が向上しました。
- **既存の翻訳の洗練** — 既存の言語で用語がより明確になり、UI ラベルが拡張され、アプリ全体で一貫した体験を提供します。

## バグ修正

- **セッションアクションのタイミング** — セッションアクションのタイミングがより正確に記録・報告されるようになり、実際に作業が開始・終了した時点をタイムラインが反映するようになりました。
- **リモートワークスペースのエラー表示が明確に** — リモートワークスペースへの接続やコマンド実行の失敗時に、汎用的なメッセージではなく、より説明的なエラーメッセージが表示されるようになりました。
- **ワークスペースプロキシが作業ディレクトリをリークしない** — ワークスペースプロキシ経由でルーティングされたリクエストに作業ディレクトリの詳細が含まれなくなり、ローカルパスがネットワークに流出しなくなりました。
- **マップが空の領域を埋める** — アクティビティマップが、記録されたアクティビティのない領域でも空白領域に折りたたまれず、表示されたままになりました。
- **ロケール検出の修正** — Bolt が起動時にシステムロケールを確実に取得するようになり、より多くのプラットフォームで正しい言語のインターフェイスが開きます。
- **ドイツ語のタイムライン翻訳の修正** — ドイツ語のタイムラインエントリが、英語へのフォールバックや不正な形式ではなく、正しい文字列で表示されるようになりました。
- **ファイル選択のトグルオフ** — ファイル選択をもう一度クリックするとクリアされるようになり、別の選択を選ばなくても選択を取り消せるようになりました。
- **ドラフトコメントのインタラクションがよりクリーンに** — ドラフトコメントの開始または破棄が、下にある選択を一貫してクリアし、ホバー状態と競合しなくなりました。
- **推論ヘッダーのアニメーション復元** — TUI の推論ヘッダーは思考中に再びアニメーションスピナーを表示し、展開時にはグラデーションが薄暗くなるため、折りたたみ状態と開いた状態を区別しやすくなりました。
- **ホーム画面とエラー画面の Bolt ワードマーク** — New Session の透かし、および従来のホーム画面とエラー画面が、アップストリームのロゴではなく Bolt のワードマークを表示するようになり、あらゆる画面でブランディングの一貫性が保たれます。
- **バックグラウンドプロセスとテストツールの復元** — `bash_background`、`process_output`、`list_processes`、`kill_process`、`test_run` が、以前のマージで削除されていたのがエージェントで再び利用可能になりました。エージェントは開発サーバやウォッチャなどの長時間実行コマンドを開始し、その出力を読み、プロジェクトのテストを構造化された合否結果と共に実行できます。[Built-in tools](/concepts/tools#built-in-tools) を参照してください。
