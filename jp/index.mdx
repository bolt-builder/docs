Bolt は完全な AI エンジニアリングチームをターミナルに直接組み込みます。高速でキーボード駆動の TUI とネイティブデスクトップアプリとして提供され、どちらも同じエンジンを使用しています。10 の専門エージェント、永続的で耐久性のあるセッション、OAuth 付き MCP サーバ管理、プラグインシステム、そしてすべての主要 LLM プロバイダのサポートです。

## Bolt ができること

Bolt はコードベースを読み、何を作ろうとしているかを理解して、あなたと一緒にコードを出荷します — ターミナル内でもデスクトップアプリでも。各セッションは耐久性があります。デタッチ、別のマシンからの再アタッチ、会話ブランチのフォーク、リンクの共有、サニタイズされたトランスクリプトのエクスポートが可能です。

## 立ち上げて実行する

<Steps>
  <Step title="Bolt をインストール">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash
    ```
    または npm 経由でインストール: `npm i -g @bolt-builder/bolt-cli`
  </Step>
  <Step title="プロジェクトを開く">
    任意のプロジェクトディレクトリに移動して TUI を起動します。
    ```bash
    cd my-project
    bolt
    ```
  </Step>
  <Step title="プロバイダを設定">
    初回起動時、Bolt は LLM プロバイダの追加を求めます。次のコマンドも実行できます。
    ```bash
    bolt providers
    ```
  </Step>
  <Step title="AI でコーディングを始める">
    TUI フッターにプロンプトを入力し、Enter を押して、Bolt のエージェントに仕事を任せましょう。`Tab` でエージェントを切り替えます。
  </Step>
</Steps>

<Tip>
  完全な TUI を開かず、素早く非対話的な回答が欲しいときは `bolt run "explain this codebase"` を使ってください。
</Tip>
