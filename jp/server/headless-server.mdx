`bolt serve` はヘッドレスな Bolt サーバを実行し、エンジン全体を HTTP 経由で公開します。セッション、エージェント、ツール、プロバイダアクセス、MCP、ストリーミングイベントすべてです。Bolt がインタラクティブに実行できることは何でも、API 経由で実行できます。

## サーバを起動する

```bash
bolt serve                              # localhost のみ、ランダムポート
bolt serve --hostname 0.0.0.0 --port 4096
bolt serve --mdns                       # ローカルネットワーク上でアドバタイズ
```

<Warning>
  `0.0.0.0` にバインドすると、Bolt がネットワーク上に公開されます。必ず事前に `BOLT_SERVER_USERNAME` と `BOLT_SERVER_PASSWORD` を設定してください。
</Warning>

## TUI を接続する

サーバに到達可能な任意のマシンから、次を実行します。

```bash
bolt attach http://server:4096
bolt attach --mini http://server:4096
```

または、リモートサーバに対して一度きりのプロンプトを実行します。

```bash
bolt run --attach http://server:4096 --dir /projects/api "what tests are failing?"
```

## ベーシック認証

環境変数で認証情報を設定します ([Env Variables](/reference/environment-variables) を参照)。

```bash
export BOLT_SERVER_USERNAME=teamname
export BOLT_SERVER_PASSWORD=$(openssl rand -hex 24)
bolt serve --hostname 0.0.0.0 --port 4096
```

すべてのクライアントは一致する認証情報を送信する必要があります。
