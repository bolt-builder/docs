`bolt web` は Bolt サーバを起動し、その前面にブラウザ UI を提供します。エンジンは TUI と同じで、ブラウザタブでレンダリングされるだけです。

## 起動する

```bash
bolt web                                # localhost のみ
bolt web --hostname 0.0.0.0 --port 4096
```

続いて、表示された URL を開きます。ネットワーク越しに公開する場合は、事前にベーシック認証を設定してください。

```bash
export BOLT_SERVER_USERNAME=teamname
export BOLT_SERVER_PASSWORD=$(openssl rand -hex 24)
bolt web --hostname 0.0.0.0 --port 4096
```

## Web UI を使う場面

- 強力なリモートマシンで Bolt を実行し、ラップトップから操作する。
- ペアデバッグのためにチームメイトとライブセッションを共有する。
- 完全な TUI が扱いにくい環境 (Chromebook、タブレット、コワーキングマシン)。
