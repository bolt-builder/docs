デスクトップアプリは同じ Bolt エンジンをネイティブシェルで包んだもので、ターミナルでは簡単にはできないいくつかの機能が備わっています。

## 中身

- **マルチウィンドウ、マルチタブセッション。** プロジェクトを横断して複数のエージェントを並行実行でき、それぞれ独自のタブを持ちます。
- **プロンプトコンポーザ。** ファイル添付とクリップボード画像貼り付けをサポートする豊かな入力 — スクリーンショットをプロンプトに直接ドロップできます。
- **統合ターミナル \+ ファイルツリー。** チャットの隣に実際のシェルとプロジェクトエクスプローラ。
- **コマンドパレット。** `Cmd/Ctrl+K` でセッション間を移動、任意の Bolt コマンドの実行、スラッシュコマンドのトリガーができます。
- **設定。** キーバインド、モデル、プロバイダ、設定済みサーバがすべて、実際の設定 UI で編集可能です。
- **ネイティブ通知。** 長時間実行エージェントが終了すると OS が通知します。
- **ディープリンク。** `bolt://` URL でどこからでもセッションにジャンプできます。
- **Windows での WSL 統合。** WSL 環境に対して標準で動作します。
- **28 の UI 言語。**
