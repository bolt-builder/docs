Bolt デスクトップアプリは、CLI と同じエンジンを完全な Electron シェルで包んだものです。ターミナルで利用可能なあらゆる機能 — エージェント、MCP サーバ、プラグイン、リモートセッション、フォークして共有可能なセッション — がデスクトップアプリでも同じように動作し、それに加えてマルチウィンドウ・マルチタブ体験、グラフィカルな設定 UI、ネイティブ通知、自動更新が追加されます。すでに CLI を使用している場合、デスクトップアプリはドロップイン補完であり、置き換えではありません。

---

## インストール

### macOS

<Steps>
  <Step title="ワンライナーでインストール (推奨)">
    ターミナルを開いて実行してください。

    ```bash
    curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install-desktop | bash
    ```

    スクリプトは最新リリースをダウンロードし、検証してから `/Applications` に配置します。Gatekeeper のポップアップはありません。
  </Step>

  <Step title="アプリを起動">
    `/Applications` または Spotlight から **Bolt** を開きます。初回起動時、Bolt はデフォルトの LLM プロバイダを選ぶよう求め、グローバル設定ファイルを作成します。
  </Step>
</Steps>

<Tip>
  ワンライナーは macOS Gatekeeper の「開発元が未確認」ダイアログをバイパスする方法でアプリをインストールするので、追加のセキュリティプロンプトなしですぐにコーディングを始められます。
</Tip>

### すべてのプラットフォーム — リリースからダウンロード

プラットフォーム向けの最新インストーラを [Bolt リリースページ](https://github.com/Bolt-builder/bolt-cli/releases) からダウンロードしてください。

| プラットフォーム | インストーラ形式 |
|----------|---------------|
| macOS (Apple Silicon) | `.dmg` |
| macOS (Intel) | `.dmg` |
| Windows | `.exe` インストーラ |
| Linux | `.AppImage` / `.deb` |

<Note>
  Windows では、Bolt に WSL (Windows Subsystem for Linux) の統合が含まれます。WSL が利用可能な場合、Bolt は WSL ディストリビューション内で直接セッションを開けます — ネイティブ Windows UI に囲まれた Linux ネイティブなエージェント環境を得られます。
</Note>

## 機能

### マルチウィンドウ・マルチタブのセッション管理

好きなだけウィンドウを開けます。各ウィンドウには独自のタブセットがあります。タブは Bolt セッションに直接マッピングされるので、あるタブでリファクタリングのエージェントを走らせ、別のタブで質問し、さらに別のタブでバックグラウンドジョブを実行する — これらすべてを同時に行えます。

### プロンプトコンポーザ

プロンプトコンポーザは豊かな入力をサポートします。テキストを貼り付けたり、ファイルを添付としてドラッグしたり、クリップボードから画像を直接貼り付けたりできます。Bolt は画像をエンコードし、視覚対応の任意のモデルに自動的に送信します。

### 統合ターミナルとファイルツリー

分割ペインレイアウトにより、片側にエージェント会話、もう一方にライブターミナルとプロジェクトファイルツリーが表示されます。アプリを切り替えることなくコマンドを実行し、出力を検査して、結果をエージェントにフィードバックできます。

### コマンドパレット

`Cmd/Ctrl+K` を押してコマンドパレットを開きます。ここからマウスに手を伸ばすことなく、セッションを切り替えたり、エージェントを変更したり、設定を開いたり、任意のアクションをトリガーしたりできます。

### 完全な設定 UI

設定パネルは `.bolt/bolt.jsonc` にあるすべてのオプション — キーバインド、モデル選択、LLM プロバイダ、MCP サーバ、認証 — をドロップダウン、トグル、インライン検証と共にカバーします。設定ファイルを手で編集する必要はほとんどありません。

### ネイティブ通知

長時間実行タスクが終了すると、Bolt はネイティブ OS 通知を発します。通知をクリックすると、そのセッションに直接ジャンプできます。

### ディープリンク

`bolt://` URL に移動することで、特定のセッションを開けます。チームメイトとのセッションリンク共有や作業中セッションのブックマークに便利です。

### 自動更新

デスクトップアプリは 3 つのチャネルを通じて自身を更新します。

| チャネル | 説明 |
|---------|-------------|
| `prod` | 安定版リリース。各本番タグで更新 |
| `beta` | 新機能への早期アクセス用のプレリリースビルド |
| `dev` | `dev` ブランチからのナイトリービルド |

**Settings → About** でチャネルを切り替えます。

### 28 の UI 言語

Bolt のインターフェイスは 28 言語にローカライズされています。**Settings → Appearance → Language** で表示言語を変更してください。
