Bolt TUI は、キーボードだけで最初から最後まで操作できるように設計されています。このページでは、最もよく使うショートカットを一覧にしています。網羅的な一覧については、`bolt` を実行してアプリ内のヘルプを開いてください。

## 必須

| Keys | Action |
| --- | --- |
| `Tab` | 次のエージェント (`code`、`plan`、`ask` …) に切り替えます。現在のエージェントはステータスバーに表示されます。 |
| `Shift+Tab` | 前のエージェントに切り替えます。 |
| `Enter` | 現在のメッセージを送信します。 |
| `Esc` | 実行中のターンをキャンセルします。 |
| `Ctrl+C` | 現在のツール呼び出しを中断します。 |
| `Ctrl+D` | セッションからデタッチします (サーバ上で実行し続けます)。 |

## モード

### `--mini` モード

分割ペインに最適な、ターミナル領域を節約するコンパクトな分割フッターレイアウトで Bolt を起動します。

```bash
bolt --mini
bolt attach --mini <url>
```

### プッシュ・ツー・トークの音声入力

設定したプッシュ・ツー・トークキーを押し続けると、音声認識でプロンプトを口述でき、放すと送信されます。キーと STT プロバイダは `.bolt/bolt.jsonc` で設定します。
