L'app desktop è lo stesso motore Bolt racchiuso in una shell nativa con alcune cose che un terminale non può fare facilmente.

## Cosa c'è dentro

- **Sessioni multi-finestra e multi-tab.** Esegui più agenti in parallelo su progetti diversi, ciascuno nella propria scheda.
- **Compositore di prompt.** Input avanzato con allegati di file e incolla di immagini dagli appunti — trascina gli screenshot direttamente nel prompt.
- **Terminale integrato \+ albero dei file.** Shell reale ed esploratore del progetto accanto alla chat.
- **Tavolozza dei comandi.** `Cmd/Ctrl+K` per saltare tra sessioni, eseguire qualsiasi comando Bolt o attivare un comando slash.
- **Impostazioni.** Combinazioni di tasti, modelli, provider e server configurati, tutti modificabili in una vera interfaccia di impostazioni.
- **Notifiche native.** Il sistema operativo ti notifica quando termina un agente a lunga esecuzione.
- **Deep link.** URL `bolt://` per saltare alle sessioni da qualsiasi luogo.
- **Integrazione WSL su Windows.** Funziona con il tuo ambiente WSL immediatamente.
- **28 lingue dell'interfaccia.**
