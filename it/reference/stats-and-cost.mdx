`bolt stats` aggrega conteggi di token e costi nel database locale delle sessioni. Poiché ogni chiamata di strumento viene registrata (vedi [Database locale](/reference/local-database)), i numeri sono esatti per le chiamate LLM che Bolt ha guidato.

## Utilizzo base

```bash
bolt stats                       # summary for the current project
bolt stats --days 7              # last seven days
bolt stats --days 7 --models     # break down by model
```

## Cosa mostra

- Token totali di input, output e cache.
- Costo stimato per provider (utilizzando le tabelle di prezzi del provider al momento dell'esecuzione).
- Suddivisioni per modello, per agente e per giorno a seconda dei flag.

## Ridurre i costi

- Usa `--variant minimal` o `--variant low` su modelli pesanti nel ragionamento. Vedi [Provider e modelli](/concepts/providers-and-models).
- Preferisci l'agente `ask` o `plan` per l'esplorazione; sono in sola lettura ed evitano cicli pesanti di strumenti.
- Passa a un modello più piccolo con `bolt models` per attività che non hanno bisogno di capacità di frontiera.
