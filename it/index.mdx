Bolt mette un intero team di ingegneria AI direttamente nel tuo terminale. Viene fornito come TUI veloce, guidato da tastiera, e come app desktop nativa, entrambi supportati dallo stesso motore: dieci agenti specializzati, sessioni durature persistenti, gestione di server MCP con OAuth, un sistema di plugin e supporto per ogni principale provider LLM.

## Cosa fa Bolt

Bolt legge il tuo codebase, comprende cosa stai costruendo e rilascia codice con te—nel terminale o come app desktop. Ogni sessione è durevole: staccati, riconnettiti da un'altra macchina, biforca un ramo della conversazione, condividi un link o esporta una trascrizione sanificata.

## Avvia in un attimo

<Steps>
  <Step title="Installa Bolt">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash
    ```
    O installa via npm: `npm i -g @bolt-builder/bolt-cli`
  </Step>
  <Step title="Apri il tuo progetto">
    Naviga in qualsiasi directory di progetto e avvia il TUI:
    ```bash
    cd my-project
    bolt
    ```
  </Step>
  <Step title="Configura un provider">
    Al primo avvio Bolt ti chiederà di aggiungere un provider LLM. Puoi anche eseguire:
    ```bash
    bolt providers
    ```
  </Step>
  <Step title="Inizia a programmare con l'AI">
    Digita il tuo prompt nel piè di pagina del TUI, premi Invio e lascia che gli agenti di Bolt si mettano al lavoro. Cambia agente con `Tab`.
  </Step>
</Steps>

<Tip>
  Usa `bolt run "explain this codebase"` per una risposta non interattiva rapida senza aprire il TUI completo.
</Tip>
