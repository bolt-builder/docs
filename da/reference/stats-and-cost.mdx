`bolt stats` aggregerer token-antal og omkostninger på tværs af den lokale sessionsdatabase. Fordi hvert værktøjskald registreres (se [Lokal database](/reference/local-database)), er tallene præcise for de LLM-kald, Bolt drev.

## Grundlæggende brug

```bash
bolt stats                       # summary for the current project
bolt stats --days 7              # last seven days
bolt stats --days 7 --models     # break down by model
```

## Hvad det viser

- Samlede input-, output- og cache-tokens.
- Estimerede omkostninger pr. udbyder (baseret på udbyder-pris-tabeller på tidspunktet for kørslen).
- Opdelinger pr. model, pr. agent og pr. dag afhængigt af flag.

## Reduktion af omkostninger

- Brug `--variant minimal` eller `--variant low` på reasoning-tunge modeller. Se [Udbydere og modeller](/concepts/providers-and-models).
- Foretræk `ask`- eller `plan`-agenten til udforskning; de er read-only og undgår værktøjstunge løkker.
- Skift til en mindre model med `bolt models` til opgaver, der ikke kræver frontkapabilitet.
