Bolt kan installeres på macOS, Linux og Windows via den metode, der passer til dit workflow — et one-line curl-script, enhver større Node.js-pakkehåndtering eller en systempakkehåndtering som Homebrew, Chocolatey eller Scoop.

## Hurtig installation (macOS / Linux)

Den hurtigste måde at komme i gang er det officielle installationsscript. Det registrerer automatisk dit OS og din arkitektur, downloader den korrekte binær til `~/.bolt/bin` og tilføjer den til din `$PATH`.

```bash
curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash
```

Installationsprogrammet opsætter også valgfri afhængigheder til stemmeinput (sox og whisper-cpp til offline transskription). For at springe det over kan du bruge `--no-voice`:

```bash
curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash -s -- --no-voice
```

For at fastlåse en specifik version:

```bash
curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash -s -- --version 1.20.2
```

## Pakkehåndteringer

Installér Bolt globalt med den pakkehåndtering, du foretrækker:

<CodeGroup>

```bash npm
npm i -g @bolt-builder/bolt-cli
```

```bash bun
bun add -g @bolt-builder/bolt-cli
```

```bash pnpm
pnpm add -g @bolt-builder/bolt-cli
```

```bash yarn
yarn global add @bolt-builder/bolt-cli
```

</CodeGroup>

## Verificér installationen

<Steps>
  <Step title="Tjek den installerede version">
    Efter installationen kan du bekræfte, at `bolt` er tilgængelig i din `$PATH`:

    ```bash
    bolt --version
    ```

    Hvis kommandoen ikke findes, så åbn en ny terminalsession (eller genindlæs din shell-konfiguration), så den opdaterede `$PATH` træder i kraft.
  </Step>
</Steps>

## Opgradering

Kør `bolt upgrade` for at opdatere til den nyeste udgivelse:

```bash
bolt upgrade
```

Bolt registrerer automatisk din oprindelige installationsmetode. Du kan tilsidesætte den med flaget `--method`:

```bash
bolt upgrade --method <method>
```

Understøttede metoder er: `curl`, `npm`, `pnpm`, `bun`, `brew`, `choco`, `scoop`.

Du kan også opgradere til en specifik version ved at angive versionen som et positional-argument:

```bash
bolt upgrade 1.20.2
```

## Afinstallation

For at fjerne Bolt fra dit system:

```bash
bolt uninstall
```

## Miljøvariabler

| Variabel               | Beskrivelse                                           |
| ---------------------- | ----------------------------------------------------- |
| `BOLT_LOG_LEVEL`       | Log-detaljeringsgrad: `DEBUG`, `INFO`, `WARN` eller `ERROR` |
| `BOLT_PRINT_LOGS`      | Udskriv logs til stderr                               |
| `BOLT_PURE`            | Kør uden at indlæse eksterne plugins                  |
| `BOLT_SERVER_PASSWORD` | Basic auth-adgangskode til headless API-serveren      |
| `BOLT_SERVER_USERNAME` | Basic auth-brugernavn til headless API-serveren       |

<Tip>
  Sæt `BOLT_PURE=1`, når du vil have en ren kørsel uden nogen tredjepartsplugins — nyttigt til debugging eller kontrollerede CI-miljøer.
</Tip>

## Desktop-app

<Note>
  Bolt leveres også som en native desktop-applikation med fler-vinduet sessionsstyring, en integreret terminal og filtræ, en kommandopalet, 28 UI-sprog og automatiske opdateringer. Download den nyeste udgivelse fra [releases-siden](https://github.com/Bolt-builder/bolt-cli/releases).

  På macOS kan du installere den på én linje uden Gatekeeper-omvej:

  ```bash
  curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install-desktop | bash
  ```
</Note>
