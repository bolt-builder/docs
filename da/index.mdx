Bolt placerer et komplet AI-ingeniørteam direkte i din terminal. Den leveres som en hurtig, tastaturdrevet TUI og en native desktop-app, begge understøttet af den samme motor: ti specialiserede agenter, vedvarende og robuste sessioner, MCP-serveradministration med OAuth, et plugin-system og understøttelse af alle større LLM-udbydere.

## Hvad Bolt gør

Bolt læser din kodebase, forstår hvad du bygger, og leverer kode sammen med dig – i terminalen eller som en desktop-app. Hver session er vedvarende: du kan koble fra, koble på igen fra en anden maskine, forgrene en gren af samtalen, dele et link eller eksportere et anonymiseret transkript.

## Kom i gang

<Steps>
  <Step title="Installér Bolt">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash
    ```
    Eller installér via npm: `npm i -g @bolt-builder/bolt-cli`
  </Step>
  <Step title="Åbn dit projekt">
    Naviger til en projektmappe og start TUI'en:
    ```bash
    cd my-project
    bolt
    ```
  </Step>
  <Step title="Konfigurér en udbyder">
    Ved første opstart beder Bolt dig om at tilføje en LLM-udbyder. Du kan også køre:
    ```bash
    bolt providers
    ```
  </Step>
  <Step title="Begynd at kode med AI">
    Indtast din prompt i TUI-fodbjælken, tryk Enter, og lad Bolts agenter gå i gang. Skift agent med `Tab`.
  </Step>
</Steps>

<Tip>
  Brug `bolt run "explain this codebase"` for et hurtigt, ikke-interaktivt svar uden at åbne den fulde TUI.
</Tip>
