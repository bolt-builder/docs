O Bolt coloca uma equipe completa de engenharia com IA diretamente no seu terminal. Ele é distribuído como um TUI rápido e orientado por teclado e um app desktop nativo, ambos apoiados pelo mesmo motor: dez agentes especializados, sessões duráveis persistentes, gerenciamento de servidores MCP com OAuth, um sistema de plugins e suporte para todos os principais provedores de LLM.

## O que o Bolt faz

O Bolt lê sua base de código, entende o que você está construindo e envia código com você — no terminal ou como um app desktop. Cada sessão é durável: você pode desanexar, reanexar de outra máquina, criar um branch da conversa, compartilhar um link ou exportar um transcript sanitizado.

## Coloque em funcionamento

<Steps>
  <Step title="Instale o Bolt">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash
    ```
    Ou instale via npm: `npm i -g @bolt-builder/bolt-cli`
  </Step>
  <Step title="Abra seu projeto">
    Navegue até qualquer diretório de projeto e inicie o TUI:
    ```bash
    cd my-project
    bolt
    ```
  </Step>
  <Step title="Configure um provedor">
    Na primeira execução, o Bolt solicita que você adicione um provedor de LLM. Você também pode executar:
    ```bash
    bolt providers
    ```
  </Step>
  <Step title="Comece a programar com IA">
    Digite seu prompt no rodapé do TUI, pressione Enter e deixe os agentes do Bolt trabalharem. Alterne agentes com `Tab`.
  </Step>
</Steps>

<Tip>
  Use `bolt run "explain this codebase"` para uma resposta rápida não interativa sem abrir o TUI completo.
</Tip>
