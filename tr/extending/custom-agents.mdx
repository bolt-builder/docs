On yerleşik ajanın ötesinde kendi ajanlarınızı tanımlayabilirsiniz. Özel ajanlar, ajanın modelini, erişim düzeyini ve kullanılabilir araçlarını tanımlayan bir ön veri bloğu ve sistem komutu olarak işlev gören bir gövde içeren Markdown dosyalarıdır.

## Ajan oluşturma

En hızlı yol, birkaç soru sorup dosyayı sizin için yazan yerleşik oluşturucudur:

```bash
bolt agent create
```

Ajanlar projede `.opencode/agent/` altında (veya kişisel ajanlar için global yapılandırma dizininizde) yaşar. Her ajan, dosya adı ajanın adına dönüşen tek bir `.md` dosyasıdır.

## Bir ajan dosyasının anatomisi

```md
---
name: "e2e-writer"
description: "Writes and updates Playwright end-to-end tests"
model: "anthropic/claude-opus-4-5"
access: "edit"
tools:
  - read
  - edit
  - write
  - grep
  - bash
---

You are an expert Playwright end-to-end test author. When asked to add tests:

1. Read existing tests in `e2e/` first to match style.
2. Prefer role-based selectors.
3. Always run `pnpm e2e -- --reporter=list` after editing.
```

Yaygın ön veri alanları:

| Alan | Amaç |
| --- | --- |
| `name` | `--agent` ile kullanılan ajan adı. |
| `description` | Listelerde gösterilen tek satırlık özet. |
| `model` | `provider/model` formatında varsayılan model. |
| `access` | `full`, `edit` veya `read` ([İzinler](/concepts/permissions) bölümüne bakın). |
| `tools` | Ajanın çağırabileceği [araçları](/concepts/tools) kısıtlayan isteğe bağlı bir izin listesi. |

## Özel bir ajan kullanma

```bash
bolt run --agent e2e-writer "add a signup flow test"
```

TUI'de ajanlar arasında geçiş yapmak için `Tab` tuşuna basın; özel ajanlar yerleşiklerin yanında görünür.

## Alt ajanlar

Ajanlar, `task` aracı aracılığıyla alt ajanlara iş devredebilir. Bolt, `@general` ve `@explore` ile gelir; ve dosyası `.opencode/agent/` altında yaşayan herhangi bir özel ajan da ada göre alt ajan olarak çağrılabilir.
