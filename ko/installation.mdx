Bolt는 워크플로에 맞는 방법으로 macOS, Linux, Windows에 설치할 수 있습니다 — 한 줄짜리 curl 스크립트, 주요 Node.js 패키지 관리자, Homebrew, Chocolatey, Scoop 같은 시스템 패키지 관리자.

## 빠른 설치 (macOS / Linux)

가장 빠른 시작 방법은 공식 설치 스크립트입니다. OS와 아키텍처를 자동 감지하고, 올바른 바이너리를 `~/.bolt/bin`에 다운로드하고, `$PATH`에 추가합니다.

```bash
curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash
```

설치 프로그램은 선택적 음성 입력 종속성(오프라인 전사를 위한 sox와 whisper-cpp)도 설정합니다. 이를 건너뛰려면 `--no-voice`를 전달하세요:

```bash
curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash -s -- --no-voice
```

특정 버전을 고정하려면:

```bash
curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash -s -- --version 1.20.2
```

## 패키지 관리자

선호하는 패키지 관리자로 Bolt를 전역 설치하세요:

<CodeGroup>

```bash npm
npm i -g @bolt-builder/bolt-cli
```

```bash bun
bun add -g @bolt-builder/bolt-cli
```

```bash pnpm
pnpm add -g @bolt-builder/bolt-cli
```

```bash yarn
yarn global add @bolt-builder/bolt-cli
```

</CodeGroup>

## 설치 확인

<Steps>
  <Step title="설치된 버전 확인">
    설치 후, `bolt`가 `$PATH`에서 사용 가능한지 확인하세요:

    ```bash
    bolt --version
    ```

    명령을 찾을 수 없으면, 업데이트된 `$PATH`가 적용되도록 새 터미널 세션을 열거나 셸 설정을 다시 소스하세요.
  </Step>
</Steps>

## 업그레이드

최신 릴리스로 업데이트하려면 `bolt upgrade`를 실행하세요:

```bash
bolt upgrade
```

Bolt는 원래 설치 방법을 자동으로 감지합니다. `--method` 플래그로 재정의할 수 있습니다:

```bash
bolt upgrade --method <method>
```

지원되는 방법: `curl`, `npm`, `pnpm`, `bun`, `brew`, `choco`, `scoop`.

버전을 위치 인수로 전달하여 특정 버전으로 업그레이드할 수도 있습니다:

```bash
bolt upgrade 1.20.2
```

## 제거

시스템에서 Bolt를 제거하려면:

```bash
bolt uninstall
```

## 환경 변수

| Variable               | Description                                           |
| ---------------------- | ----------------------------------------------------- |
| `BOLT_LOG_LEVEL`       | 로그 상세도: `DEBUG`, `INFO`, `WARN`, `ERROR`         |
| `BOLT_PRINT_LOGS`      | stderr에 로그 출력                                    |
| `BOLT_PURE`            | 외부 플러그인을 로드하지 않고 실행                    |
| `BOLT_SERVER_PASSWORD` | 헤드리스 API 서버용 basic auth 비밀번호               |
| `BOLT_SERVER_USERNAME` | 헤드리스 API 서버용 basic auth 사용자 이름            |

<Tip>
  제3자 플러그인 없이 깨끗하게 실행하고 싶을 때 `BOLT_PURE=1`을 설정하세요 — 디버깅이나 통제된 CI 환경에 유용합니다.
</Tip>

## 데스크톱 앱

<Note>
  Bolt는 다중 창 세션 관리, 통합 터미널과 파일 트리, 명령 팔레트, 28개 UI 언어, 자동 업데이트를 갖춘 네이티브 데스크톱 애플리케이션으로도 제공됩니다. 최신 릴리스는 [릴리스 페이지](https://github.com/Bolt-builder/bolt-cli/releases)에서 다운로드하세요.

  macOS에서는 Gatekeeper 우회 없이 한 줄로 설치할 수 있습니다:

  ```bash
  curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install-desktop | bash
  ```
</Note>
