`bolt stats`는 로컬 세션 데이터베이스 전반에 걸쳐 토큰 수와 비용을 집계합니다. 모든 도구 호출이 기록되므로([Local Database](/reference/local-database) 참조), 숫자는 Bolt가 구동한 LLM 호출에 대해 정확합니다.

## 기본 사용법

```bash
bolt stats                       # summary for the current project
bolt stats --days 7              # last seven days
bolt stats --days 7 --models     # break down by model
```

## 무엇을 표시하나요

- 총 입력, 출력, 캐시 토큰.
- 프로바이더당 예상 비용 (실행 시점의 프로바이더 가격표 사용).
- 플래그에 따른 모델별, 에이전트별, 일별 분석.

## 비용 줄이기

- 추론이 많은 모델에 `--variant minimal` 또는 `--variant low`를 사용하세요. [Providers & Models](/concepts/providers-and-models) 참조.
- 탐색용으로는 `ask`나 `plan` 에이전트를 선호하세요. 읽기 전용이며 도구 중심 루프를 피합니다.
- 프론티어 능력이 필요 없는 작업에는 `bolt models`로 더 작은 모델로 전환하세요.
