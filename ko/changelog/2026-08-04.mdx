## 새 기능

- **11개의 새 UI 언어** — 데스크톱 앱과 TUI가 이제 힌디어, 네덜란드어, 인도네시아어, 베트남어, 이탈리아어, 우르두어, 펀자브어, 아제르바이잔어, 핀란드어, 스웨덴어, 태국어 번역을 제공하여 지원 언어 수가 총 28개로 늘어났습니다. **Settings → Appearance → Language**에서 언어를 전환할 수 있습니다. [Desktop features](/desktop/features) 및 [Install](/desktop/install#28-ui-languages)을 참조하세요.
- **오른쪽에서 왼쪽 레이아웃 지원** — 이제 내비게이션, 편집기, 대화 상자, 컨트롤, 텍스트 렌더링이 아랍어, 히브리어, 우르두어 같은 오른쪽에서 왼쪽 언어에 맞게 올바르게 반전되어, 해당 로케일에서 인터페이스 전체가 자연스럽게 읽힙니다.
- **네이티브 데스크톱 번역** — OS 수준의 메뉴, 업데이터 대화 상자, 복구 흐름, WSL 온보딩, 네이티브 파일 선택기가 이제 앱 내 UI와 함께 로컬라이즈되어, 데스크톱 경험 전체가 언어 설정을 따릅니다.
- **로컬라이제이션 커버리지 확대** — 메뉴, 대화 상자, 프롬프트, 도움말 콘텐츠, 오류 메시지, 접근성 레이블이 이제 지원되는 모든 언어로 번역되어, 이전에 문자열이 영어로 폴백되던 격차가 해소되었습니다.
- **Poolside 프로바이더** — 이제 Bolt가 OpenAI 호환 API를 통해 [Poolside](https://poolside.ai)에 연결됩니다. `/connect`를 실행하고 **Poolside**를 선택한 다음 [platform.poolside.ai](https://platform.poolside.ai)에서 발급받은 API 키를 붙여넣으면 됩니다. 자체 호스팅 Poolside 배포도 커스텀 프로바이더로 구성할 수 있습니다. [Providers and models](/concepts/providers-and-models)를 참조하세요.
- **로케일 인식 복수형 처리** — 카운트, 상태, 파일, 세션 목록 항목이 이제 언어별로 올바르게 복수형 처리되어, 모든 지원 로케일에서 타임라인과 상태 텍스트가 자연스럽게 읽힙니다.
- **더 풍부한 Markdown 렌더링** — 어시스턴트 메시지가 개선된 Markdown 서식, 더 부드러운 스트리밍 업데이트, 더 나은 구문 강조, 수학 콘텐츠 지원을 얻어 장문 및 기술적 답변을 더 쉽게 읽을 수 있게 되었습니다.

## 업데이트

- **GPT-5 추론 효율이 모델 버전과 일치** — 추론 효율 계층(`none` 및 `xhigh` 포함)은 이제 이를 지원하는 GPT-5 변형에서만 제공되므로, `--variant`가 특정 모델이 거부할 옵션을 더 이상 노출하지 않습니다. [Controlling reasoning effort](/concepts/providers-and-models#variant-controlling-reasoning-effort)를 참조하세요.
- **Diff 주석 다듬기** — 세션 UI diff 뷰가 주석 표시기, 여백 동작, 라이트/다크 구문 색상을 다듬어 가독성이 향상되었습니다.
- **기존 번역 개선** — 기존 언어의 용어가 더 명확해지고 UI 레이블이 확장되어 앱 전반에 걸쳐 더 일관된 경험을 제공합니다.

## 버그 수정

- **세션 작업 타이밍** — 이제 세션 작업이 타이밍을 더 정확하게 기록하고 보고하므로, 타임라인이 작업이 실제로 시작되고 완료된 시점을 반영합니다.
- **더 명확한 원격 워크스페이스 오류** — 원격 워크스페이스에 연결하거나 명령을 실행할 때 발생하는 실패가 이제 일반적인 오류 대신 더 설명적인 오류 메시지를 노출합니다.
- **워크스페이스 프록시가 더 이상 작업 디렉터리를 유출하지 않음** — 워크스페이스 프록시를 통해 라우팅되는 요청에 더 이상 작업 디렉터리 세부 정보가 포함되지 않아, 로컬 경로가 네트워크에 노출되지 않습니다.
- **맵이 빈 영역을 채움** — 이제 활동 맵이 기록된 활동이 없는 영역에서 빈 영역으로 축소되지 않고 계속 표시됩니다.
- **로케일 감지 수정** — 이제 Bolt가 시작 시 시스템 로케일을 안정적으로 인식하므로, 더 많은 플랫폼에서 인터페이스가 올바른 언어로 열립니다.
- **독일어 타임라인 번역 수정** — 이제 독일어 타임라인 항목이 영어로 폴백되거나 잘못 서식이 지정된 텍스트 대신 올바른 문자열로 렌더링됩니다.
- **파일 선택 해제 토글** — 이제 파일 선택을 다시 클릭하면 선택이 해제되므로, 다른 항목을 먼저 선택하지 않고도 선택을 취소할 수 있습니다.
- **더 깔끔한 임시 주석 상호 작용** — 이제 임시 주석을 시작하거나 해제하면 기본 선택이 일관되게 해제되며, 호버 상태와 더 이상 충돌하지 않습니다.
- **애니메이션 추론 헤더 복원** — TUI의 추론 헤더가 사고 중에 다시 애니메이션 스피너를 표시하며, 확장 시 그래디언트가 흐려져 접힘/열림 상태를 구분하기 쉬워졌습니다.
- **백그라운드 프로세스 및 테스트 도구 복원** — 이전 병합에서 제거되었던 `bash_background`, `process_output`, `list_processes`, `kill_process`, `test_run`이 다시 에이전트에 사용 가능해졌습니다. 에이전트는 개발 서버 및 감시자 같은 장기 실행 명령을 시작하고, 출력을 읽고, 프로젝트의 테스트를 구조화된 통과/실패 결과와 함께 실행할 수 있습니다. [Built-in tools](/concepts/tools#built-in-tools)를 참조하세요.
