Bolt는 완전한 AI 엔지니어링 팀을 여러분의 터미널에 직접 배치합니다. 빠르고 키보드 중심의 TUI와 네이티브 데스크톱 앱으로 배포되며, 둘 다 동일한 엔진으로 백업됩니다: 10개의 전문 에이전트, 지속적이고 내구성 있는 세션, OAuth를 갖춘 MCP 서버 관리, 플러그인 시스템, 모든 주요 LLM 프로바이더 지원.

## Bolt가 하는 일

Bolt는 여러분의 코드베이스를 읽고, 여러분이 무엇을 구축하고 있는지 이해하고, 여러분과 함께 코드를 배포합니다 — 터미널이든 데스크톱 앱이든. 각 세션은 내구성이 있습니다: 분리하고, 다른 머신에서 다시 연결하고, 대화 브랜치를 포크하고, 링크를 공유하거나, 마스킹된 기록을 내보낼 수 있습니다.

## 시작하기

<Steps>
  <Step title="Bolt 설치">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash
    ```
    또는 npm으로 설치: `npm i -g @bolt-builder/bolt-cli`
  </Step>
  <Step title="프로젝트 열기">
    아무 프로젝트 디렉터리로 이동해 TUI를 시작하세요:
    ```bash
    cd my-project
    bolt
    ```
  </Step>
  <Step title="프로바이더 구성">
    첫 실행 시 Bolt는 LLM 프로바이더를 추가하도록 요청합니다. 다음을 실행할 수도 있습니다:
    ```bash
    bolt providers
    ```
  </Step>
  <Step title="AI와 코딩 시작">
    TUI 푸터에 프롬프트를 입력하고 Enter를 누르면 Bolt의 에이전트가 작업을 시작합니다. `Tab`으로 에이전트를 전환하세요.
  </Step>
</Steps>

<Tip>
  전체 TUI를 열지 않고 빠른 비대화형 답변을 얻으려면 `bolt run "explain this codebase"`를 사용하세요.
</Tip>
