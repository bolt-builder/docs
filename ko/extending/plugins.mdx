플러그인을 사용하면 Bolt를 내장 기능 이상으로 확장할 수 있습니다. 플러그인은 Bolt 플러그인 매니페스트를 내보내는 Node 또는 Bun 모듈입니다. 로드되면 새 LLM 프로바이더, 커스텀 인증 방법, 추가 도구, 워크스페이스 어댑터를 등록할 수 있습니다. 플러그인은 단일 프로젝트에 설치되거나 여러분의 모든 작업에 전역적으로 적용될 수 있습니다.

## 플러그인 설치

`bolt plugin install`(별칭: `bolt plug`)을 사용해 npm에서 플러그인을 설치하고 자동으로 설정에 등록하세요:

```bash
bolt plugin install <module>
```

### 플래그

| Flag | Alias | Description |
|------|-------|-------------|
| `--global` | `-g` | 현재 프로젝트가 아닌 전역 설정에 설치 |
| `--force` | `-f` | 동일 모듈에 대한 기존 항목 교체 |

### 범위: 프로젝트 vs 전역

기본적으로 `bolt plugin install`은 프로젝트 수준의 `.bolt/bolt.jsonc`에 플러그인을 추가합니다. 모든 프로젝트에서 로드되도록 사용자 전역 설정에 추가하려면 `--global`을 전달하세요.

```bash
# 프로젝트 범위 (기본값)
bolt plugin install @acme/bolt-plugin-jira

# 전역 — 모든 프로젝트에서 로드됨
bolt plugin install @acme/bolt-plugin-jira --global
```

<Note>
  모든 외부 플러그인을 비활성화한 상태로 Bolt를 시작하려면 `bolt --pure`를 실행하세요(또는 `OPENCODE_PURE=1`을 설정하세요). 플러그인이 예상치 못한 동작을 유발하는지 제거하지 않고 디버깅하는 데 유용합니다.
</Note>

## 게시된 플러그인 설치

<Steps>
  <Step title="플러그인 패키지 찾기">
    이름에 `bolt-plugin` 또는 `opencode-plugin`이 있는 패키지를 npm에서 검색하거나, 프로바이더 문서의 링크를 따르세요.
  </Step>

  <Step title="프로젝트에 설치">
    ```bash
    bolt plugin install @acme/bolt-plugin-jira
    ```

    Bolt는 패키지를 설치하고, 매니페스트를 읽어 서버 및 TUI 타겟을 감지한 다음 `.bolt/bolt.jsonc`에 항목을 씁니다.
  </Step>

  <Step title="설정 확인">
    `.bolt/bolt.jsonc`를 열어 플러그인 항목이 추가되었는지 확인하세요:

    ```jsonc
    {
      "plugin": [
        "@acme/bolt-plugin-jira"
      ]
    }
    ```
  </Step>

  <Step title="세션 시작">
    ```bash
    bolt
    ```

    Bolt는 시작 시 플러그인을 로드합니다. 등록하는 프로바이더나 도구는 즉시 사용할 수 있습니다.
  </Step>
</Steps>

## 수동 플러그인 구성

`.bolt/bolt.jsonc`를 직접 편집하여 플러그인을 등록할 수 있습니다. 이는 개발 중인 로컬 플러그인에 유용합니다:

```jsonc
{
  "plugin": [
    "./plugins/my-plugin.ts"
  ]
}
```

상대 경로는 프로젝트 루트에서 확인됩니다. TypeScript와 JavaScript 진입점 모두 지원됩니다.

## 플러그인 빌드

플러그인은 `@opencode-ai/plugin` 패키지에 대해 작성되며, 이 패키지는 모듈이 만족해야 하는 `Hooks` 인터페이스를 제공합니다.

```bash
npm install --save-dev @opencode-ai/plugin
```

최소한의 플러그인은 `PluginInput` 객체를 받고 `Hooks` 객체를 반환하는 함수를 내보냅니다:

```typescript
import type { Plugin } from "@opencode-ai/plugin"

const myPlugin: Plugin = async (input) => {
  return {
    // auth hook — register custom authentication methods
    auth: {
      methods: [
        {
          id: "my-provider-auth",
          name: "My Provider",
          // ... provider-specific fields
        },
      ],
    },
  }
}

export default myPlugin
```

### 사용 가능한 훅 타입

| Hook | Purpose |
|------|---------|
| `auth` | `methods` 배열로 커스텀 인증 프로바이더 등록 |
| `event` | 세션 이벤트(메시지, 도구 호출, 완료)에 반응 |
| `config` | 런타임의 설정 변경에 응답 |
| `dispose` | 플러그인이 언로드될 때 리소스 정리 |

`PluginInput` 객체는 `client`(타입이 지정된 Bolt API 클라이언트), `project`, `worktree`, `directory`, `serverUrl`을 노출하므로 플러그인이 실행 중인 서버와 상호 작용할 수 있습니다.
