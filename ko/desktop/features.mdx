데스크톱 앱은 터미널에서는 쉽게 할 수 없는 몇 가지 기능이 포함된 네이티브 셸로 감싼 동일한 Bolt 엔진입니다.

## 포함된 기능

- **다중 창, 다중 탭 세션.** 프로젝트 간에 여러 에이전트를 병렬로 실행하며, 각각은 자체 탭에서 실행됩니다.
- **프롬프트 컴포저.** 파일 첨부 및 클립보드 이미지 붙여넣기를 지원하는 풍부한 입력 — 스크린샷을 곧바로 프롬프트에 놓으세요.
- **통합 터미널 \+ 파일 트리.** 채팅 옆에 실제 셸과 프로젝트 탐색기가 있습니다.
- **명령 팔레트.** `Cmd/Ctrl+K`로 세션 간 이동, Bolt 명령 실행, 슬래시 명령 트리거를 할 수 있습니다.
- **설정.** 키바인딩, 모델, 프로바이더, 구성된 서버 모두가 실제 설정 UI에서 편집 가능합니다.
- **네이티브 알림.** 장기 실행 에이전트가 완료되면 OS가 알려줍니다.
- **딥 링크.** 어디서든 세션으로 이동할 수 있는 `bolt://` URL.
- **Windows에서 WSL 통합.** WSL 환경에 대해 기본으로 실행됩니다.
- **28개 UI 언어.**
