Bolt 데스크톱 앱은 CLI와 동일한 엔진을 완전한 Electron 셸로 감쌉니다. 터미널에서 사용할 수 있는 모든 기능 — 에이전트, MCP 서버, 플러그인, 원격 세션, 포크 및 공유 가능한 세션 — 이 데스크톱 앱에서도 동일하게 작동하며, 여기에 다중 창 및 다중 탭 경험, 그래픽 설정 UI, 네이티브 알림, 자동 업데이트가 추가됩니다. 이미 CLI를 사용 중이라면 데스크톱 앱은 대체가 아니라 즉시 사용 가능한 보완재입니다.

---

## 설치

### macOS

<Steps>
  <Step title="원 라이너로 설치 (권장)">
    터미널을 열고 다음을 실행하세요:

    ```bash
    curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install-desktop | bash
    ```

    스크립트는 최신 릴리스를 다운로드하고, 검증하고, 앱을 `/Applications`에 배치합니다. Gatekeeper 팝업이 없습니다.
  </Step>

  <Step title="앱 실행">
    `/Applications` 또는 Spotlight에서 **Bolt**를 여세요. 첫 실행 시 Bolt는 기본 LLM 프로바이더를 선택하도록 요청하고 전역 설정 파일을 생성합니다.
  </Step>
</Steps>

<Tip>
  원 라이너는 macOS Gatekeeper의 "확인되지 않은 개발자" 대화 상자를 우회하는 방식으로 앱을 설치하므로, 추가 보안 프롬프트 없이 곧바로 코딩에 들어갈 수 있습니다.
</Tip>

### 모든 플랫폼 — 릴리스에서 다운로드

플랫폼에 맞는 최신 설치 프로그램을 [Bolt 릴리스 페이지](https://github.com/Bolt-builder/bolt-cli/releases)에서 다운로드하세요.

| Platform | Installer type |
|----------|---------------|
| macOS (Apple Silicon) | `.dmg` |
| macOS (Intel) | `.dmg` |
| Windows | `.exe` installer |
| Linux | `.AppImage` / `.deb` |

<Note>
  Windows에서 Bolt에는 WSL(Windows Subsystem for Linux) 통합이 포함되어 있습니다. WSL을 사용할 수 있으면 Bolt는 WSL 배포판 내부에서 직접 세션을 열 수 있습니다 — 네이티브 Windows UI를 감싼 Linux 네이티브 에이전트 환경을 제공합니다.
</Note>

## 기능

### 다중 창 및 다중 탭 세션 관리

원하는 만큼 창을 열고, 각 창마다 자체 탭 세트를 가지세요. 탭은 Bolt 세션에 직접 매핑되므로 한 탭에서 리팩터링 에이전트를 실행하고, 다른 탭에서 질문을 하고, 세 번째 탭에서 백그라운드 작업을 실행할 수 있습니다 — 모두 동시에 말이죠.

### 프롬프트 컴포저

프롬프트 컴포저는 풍부한 입력을 지원합니다: 텍스트 붙여넣기, 파일을 첨부로 드래그, 또는 클립보드에서 직접 이미지 붙여넣기. Bolt는 이미지를 인코딩하고 자동으로 시각 기능이 있는 모델에 전송합니다.

### 통합 터미널 및 파일 트리

분할 창 레이아웃은 한쪽에서 에이전트 대화를, 다른 쪽에서 라이브 터미널과 프로젝트 파일 트리를 제공합니다. 명령을 실행하고, 출력을 검사하고, 결과를 에이전트에 다시 전달할 수 있습니다 — 앱 전환 없이 말이죠.

### 명령 팔레트

`Cmd/Ctrl+K`를 눌러 명령 팔레트를 여세요. 여기서 세션 전환, 에이전트 변경, 설정 열기, 마우스에 손대지 않고 모든 작업을 트리거할 수 있습니다.

### 완전한 설정 UI

설정 패널은 `.bolt/bolt.jsonc`에 있는 모든 옵션 — 키바인딩, 모델 선택, LLM 프로바이더, MCP 서버, 인증 — 을 드롭다운, 토글, 인라인 유효성 검사와 함께 다룹니다. 설정 파일을 수동으로 편집해야 하는 경우는 거의 없습니다.

### 네이티브 알림

Bolt는 장기 실행 작업이 완료되면 네이티브 OS 알림을 발사합니다. 알림을 클릭하면 세션으로 바로 이동합니다.

### 딥 링크

`bolt://` URL로 이동하여 특정 세션을 여세요. 팀원과 세션 링크를 공유하거나 진행 중인 작업을 북마크하는 데 유용합니다.

### 자동 업데이트

데스크톱 앱은 세 개의 채널에서 스스로 업데이트됩니다:

| Channel | Description |
|---------|-------------|
| `prod` | 안정 릴리스, 프로덕션 태그마다 업데이트됨 |
| `beta` | 새 기능에 대한 조기 접근용 사전 릴리스 빌드 |
| `dev` | `dev` 브랜치의 야간 빌드 |

**Settings → About**에서 채널을 전환하세요.

### 28개 UI 언어

Bolt의 인터페이스는 28개 언어로 로컬라이즈되어 있습니다. **Settings → Appearance → Language**에서 표시 언어를 변경할 수 있습니다.
