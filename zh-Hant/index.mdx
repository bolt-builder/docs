Bolt 將一支完整的 AI 工程團隊直接放進你的終端機。它以快速、鍵盤驅動的 TUI 與原生桌面應用的形式發佈,兩者背後是同一個引擎:十個專業化代理、持久耐用的工作階段、支援 OAuth 的 MCP 伺服器管理、外掛系統,以及對所有主流 LLM 供應商的支援。

## Bolt 能做什麼

Bolt 讀取你的程式碼庫,理解你正在建構的內容,並與你一起交付程式碼 — 在終端機或桌面應用中。每個工作階段都是持久的:可卸離、從另一台機器重新連接、分叉出對話的分支、分享連結,或匯出一份脫敏的記錄。

## 上手運行

<Steps>
  <Step title="安裝 Bolt">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash
    ```
    或透過 npm 安裝:`npm i -g @bolt-builder/bolt-cli`
  </Step>
  <Step title="開啟你的專案">
    進入任一專案目錄並啟動 TUI:
    ```bash
    cd my-project
    bolt
    ```
  </Step>
  <Step title="設定供應商">
    首次啟動時 Bolt 會提示你新增 LLM 供應商。你也可以執行:
    ```bash
    bolt providers
    ```
  </Step>
  <Step title="開始與 AI 一同編寫程式碼">
    在 TUI 頁尾輸入你的提示,按 Enter,讓 Bolt 的代理開始工作。使用 `Tab` 切換代理。
  </Step>
</Steps>

<Tip>
  使用 `bolt run "explain this codebase"` 無需開啟完整 TUI 就能快速取得非互動式答案。
</Tip>
