Bolt TUI 的設計是可以完全用鍵盤驅動。此頁列出你最常用的快捷鍵。若需完整清單,請執行 `bolt` 並開啟應用內說明。

## 必備

| 按鍵 | 動作 |
| --- | --- |
| `Tab` | 循環切換到下一個代理(`code`、`plan`、`ask`、...)。目前的代理會顯示在狀態列。 |
| `Shift+Tab` | 循環切換到上一個代理。 |
| `Enter` | 送出目前的訊息。 |
| `Esc` | 取消進行中的回合。 |
| `Ctrl+C` | 中斷目前的工具呼叫。 |
| `Ctrl+D` | 從工作階段卸離(讓它在伺服器上繼續執行)。 |

## 模式

### `--mini` 模式

以佔用較少終端機空間的精簡分割頁尾配置啟動 Bolt,適合分割窗格:

```bash
bolt --mini
bolt attach --mini <url>
```

### 按住即說語音

按住設定的按住即說按鍵,用語音轉文字口述提示,然後放開送出。在 `.bolt/bolt.jsonc` 中設定按鍵與 STT 供應商。
