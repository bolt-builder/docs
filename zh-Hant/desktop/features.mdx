桌面應用是相同的 Bolt 引擎,以原生殼包裝並提供終端機不易做到的功能。

## 內容包含

- **多視窗、多分頁工作階段。** 跨專案平行執行多個代理,每個各有其分頁。
- **提示編輯器。** 豐富輸入,支援檔案附件與從剪貼簿貼上圖片 — 可將截圖直接放進提示中。
- **整合終端機 \+ 檔案樹。** 真正的 shell 與位於對話旁邊的專案瀏覽器。
- **命令面板。** `Cmd/Ctrl+K` 可跳到不同工作階段、執行任何 Bolt 命令或觸發斜線命令。
- **設定。** 快捷鍵、模型、供應商與設定的伺服器,全部可在真正的設定 UI 中編輯。
- **原生通知。** 長時間執行的代理完成時,OS 會通知你。
- **深層連結。** `bolt://` URL 可從任何地方跳到工作階段。
- **Windows 上的 WSL 整合。** 開箱即用地針對你的 WSL 環境執行。
- **28 種介面語言。**
