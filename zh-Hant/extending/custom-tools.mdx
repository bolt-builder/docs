自訂工具讓你可以將任何能撰寫指令碼的東西(shell 指令碼、Node/Bun/Python 程式、小型二進位檔)公開為代理可依名稱呼叫的工具。這是讓 Bolt 存取專案自身建置、部署或資料工作流程最簡單的方式。

## 放在哪裡

將檔案放入以下其中之一:

- `.opencode/tool/` — 專案範圍,隨儲存庫一起提交。
- `.opencode/tools/` — 接受為上述目錄的別名。

每個檔案會成為以檔案命名的工具(去除副檔名)。Bolt 下次啟動時會自動接收工具。

## 工具的結構

自訂工具在標頭中宣告其名稱、描述與輸入 schema,然後實作行為。確切形式取決於你選擇的執行環境(shell 指令碼、TypeScript 等),但每個工具都必須:

1. 宣告輸入的 JSON Schema,讓模型知道如何呼叫。
2. 回傳 Bolt 能在 TUI 中呈現並回饋給模型的值(或錯誤)。

載入後,該工具會出現在代理的工具清單中,與內建工具如 `bash` 和 `grep` 並列,並受相同的 [權限](/concepts/permissions) 系統控管。

## 何時使用自訂工具 vs. MCP 伺服器

- **自訂工具** — 小型、專案特定、不需跨專案重用。撰寫快速。
- **MCP 伺服器** — 跨專案共用,或包裝需要驗證的真實外部服務。請見 [MCP 伺服器](/extending/mcp-servers)。
- **外掛工具** — 作為 npm 套件與其他擴充點一同散布。請見 [外掛](/extending/plugins)。
