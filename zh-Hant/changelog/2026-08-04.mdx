## 新功能

- **11 種新的介面語言** — 桌面應用與 TUI 現在提供印地文、荷蘭文、印尼文、越南文、義大利文、烏爾都文、旁遮普文、亞塞拜然文、芬蘭文、瑞典文與泰文的翻譯，讓支援的語言總數達到 28 種。可在 **Settings → Appearance → Language** 切換語言。請參閱 [桌面功能](/desktop/features) 與 [安裝](/desktop/install#28-ui-languages)。
- **支援從右至左版面配置** — 導覽、編輯器、對話框、控制項與文字渲染現在會正確鏡像顯示阿拉伯文、希伯來文、烏爾都文等從右至左的語言,讓整個介面在這些地區設定下都能自然閱讀。
- **原生桌面翻譯** — OS 層級的選單、更新程式對話框、復原流程、WSL 上手引導與原生檔案選擇器現在都與應用內 UI 一同在地化,讓整個桌面體驗都遵循你的語言設定。
- **擴展的在地化涵蓋範圍** — 選單、對話框、提示、說明內容、錯誤訊息與無障礙標籤現在在所有支援的語言中都已翻譯,補上先前字串會退回英文的缺口。
- **Poolside 供應商** — Bolt 現在透過其相容 OpenAI 的 API 連接到 [Poolside](https://poolside.ai)。執行 `/connect`,選擇 **Poolside**,並貼上你在 [platform.poolside.ai](https://platform.poolside.ai) 取得的 API 金鑰。自架 Poolside 部署也可設定為自訂供應商。請參閱 [供應商與模型](/concepts/providers-and-models)。
- **語系感知的複數形** — 計數、狀態、檔案與工作階段清單項目現在會依語言正確使用複數形式,讓時間軸與狀態文字在所有支援的地區設定下都能自然閱讀。
- **更豐富的 Markdown 渲染** — 助理訊息獲得改進的 Markdown 格式、更順暢的串流更新、更佳的語法高亮以及對數學內容的支援,讓長篇與技術性回覆更易閱讀。

## 更新

- **GPT-5 推理強度符合模型版本** — 推理強度層級(包含 `none` 與 `xhigh`)現在只會為支援它們的 GPT-5 變體提供,`--variant` 不再顯示某個模型會拒絕的選項。請參閱 [控制推理強度](/concepts/providers-and-models#variant-controlling-reasoning-effort)。
- **差異註解打磨** — 工作階段 UI 差異檢視強化了註解指標、行號欄行為與明亮/深色語法配色,提升可讀性。
- **既有翻譯精修** — 既有語言獲得更清楚的術語與更豐富的 UI 標籤,提供整個應用更一致的體驗。

## 錯誤修正

- **工作階段動作時序** — 工作階段動作現在會更準確地記錄與回報其時序,讓時間軸真實反映工作實際開始與結束的時間。
- **更清楚的遠端工作區錯誤** — 連接到遠端工作區或在其中執行命令時的失敗現在會顯示更具描述性的錯誤訊息,而不是通用的錯誤。
- **工作區代理不再洩漏工作目錄** — 透過工作區代理路由的請求不再包含工作目錄詳情,讓本機路徑不會出現在網路上。
- **地圖填滿空白區域** — 活動地圖現在在沒有記錄活動的區域仍會保持可見,而不是塌陷為空白區域。
- **修正語系偵測** — Bolt 現在會在啟動時可靠地擷取你的系統語系,讓介面在更多平台上以正確的語言開啟。
- **修正德文時間軸翻譯** — 德文時間軸項目現在會以正確的字串呈現,而不是退回英文或格式錯誤的文字。
- **關閉檔案選取** — 再次點擊檔案選取現在會清除該選取,讓你不必先選其他項目就能取消選取。
- **更乾淨的草稿註解互動** — 開始或取消草稿註解現在會一致地清除底層選取,不再與滑鼠懸停狀態衝突。
- **恢復動畫化的推理標頭** — TUI 中的推理標頭在思考時會再次顯示動畫旋轉圖示,展開時漸層會變暗,讓收合與展開狀態更容易分辨。
- **恢復背景程序與測試工具** — `bash_background`、`process_output`、`list_processes`、`kill_process` 與 `test_run` 在先前一次合併中被移除後,再次可供代理使用。代理可以啟動長時間執行的命令(如開發伺服器與監看程式)、讀取其輸出,並執行專案的測試並取得結構化的通過/失敗結果。請參閱 [內建工具](/concepts/tools#built-in-tools)。
