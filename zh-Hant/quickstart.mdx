本指南會引導你完成安裝 Bolt、在專案中啟動它、連接 AI 供應商並執行第一個提示。整個流程在一分鐘內完成。

<Steps>
  <Step title="安裝 Bolt">
    最快的路徑是官方安裝指令碼,適用於 macOS 與 Linux:

    ```bash
    curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash
    ```

    偏好套件管理工具?使用 npm、bun、pnpm 或 yarn 全域安裝:

    ```bash
    npm i -g @bolt-builder/bolt-cli
    ```

    macOS 上的桌面應用(不必繞過 Gatekeeper):

    ```bash
    curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install-desktop | bash
    ```

    請參閱 [安裝指南](/installation) 了解所有方式,包括 Homebrew、Chocolatey、Scoop 與 Windows 特有的注意事項。
  </Step>
  <Step title="開啟你的專案">
    進入任一專案目錄並啟動互動式 TUI:

    ```bash
    cd my-project
    bolt
    ```

    Bolt 會自動接收你的專案上下文 — 讀取你的檔案樹、理解技術棧,並從開啟的那一刻就讓每個代理都能使用。
  </Step>
  <Step title="設定 AI 供應商">
    首次啟動時,若未設定任何供應商,Bolt 會提示你設定一個。你也可以隨時執行:

    ```bash
    bolt providers
    ```

    這會開啟供應商管理流程,你可以在其中新增 OpenAI、Anthropic 與其他支援的 LLM 供應商的 API 金鑰。設定會儲存在專案根目錄的 `.bolt/bolt.jsonc` 中。

    ```jsonc
    {
      "$schema": "https://opencode.ai/config.json",
      "provider": {
        // Provider config goes here
      }
    }
    ```
  </Step>
  <Step title="輸入提示並探索代理">
    進入 TUI 後,輸入你的提示並按 Enter。使用 **Tab** 隨時在 Bolt 的十個內建代理之間切換 — 目前的代理會顯示在狀態列。

    你也可以直接從命令列執行提示,而不必開啟 TUI:

    ```bash
    # Non-interactive prompt using the default agent
    bolt run "explain this codebase"
    
    # Use a specific agent
    bolt run --agent ask "what does this project do?"
    
    # Attach the TUI to a running server (local or remote)
    bolt attach <url>
    ```
  </Step>
</Steps>

## 內建代理

在 TUI 中按 `Tab` 切換代理,或將 `--agent <name>` 傳給 `bolt run`。每個代理都有定義的存取層級以符合其用途。

| 代理 | 存取 | 描述 |
| --- | --- | --- |
| `code` | Full | 預設:讀取、寫入並執行程式碼 |
| `plan` | Read | 探索程式碼庫並產生計畫,而不變更檔案 |
| `ask` | Read | 問題與研究 — 不編輯檔案 |
| `code-review` | Read | 審查變更的正確性、風格與安全性 |
| `debug` | Full | 為失敗的測試、當機與邏輯錯誤除錯 |
| `refactor` | Full | 安全的重構,每步都經過測試驗證 |
| `docs` | Edit | 撰寫並更新文件與註解 |
| `security` | Read | 安全稽核:漏洞、機密、模式 |
| `migrate` | Full | 框架升級與相依套件遷移 |
| `perf` | Full | 效能分析與優化 |

另外還有兩個內建子代理用於委派:`@general` 用於複雜的多步驟任務,`@explore` 用於快速的唯讀程式碼庫研究。你可以將自己的代理定義為 Markdown 檔案,或使用 `bolt agent create` 產生。

## 接下來可以嘗試的常見命令

```bash
# Review staged changes with a pass/fail exit code
bolt review --staged

# Generate a commit message for staged changes
bolt commit

# List and manage sessions
bolt session list

# View token usage and cost statistics
bolt stats

# Query the local session database
bolt db
```

<Tip>
  將 `--mini` 傳給 `bolt` 或 `bolt attach` 可獲得佔用較少終端機空間的精簡 UI — 適合較小的視窗或分割窗格佈局。

  ```bash
  bolt --mini
  bolt attach --mini <url>
  ```
</Tip>

<Warning>
  `bolt run` 接受 `--auto`、`--yolo` 與 `--dangerously-skip-permissions` 旗標,會在不詢問的情況下自動核准所有權限提示。僅在受信任的環境中使用 — 它們讓代理可以在未確認的情況下讀取、寫入與執行。

  ```bash
  bolt run --auto "refactor this module"
  bolt run --yolo "refactor this module"
  bolt run --dangerously-skip-permissions "refactor this module"
  ```
</Warning>

<Note>
  Bolt 支援 bash、zsh、fish 與其他 shell 的 shell 自動完成。使用以下命令產生並安裝自動完成:

  ```bash
  bolt completion
  ```

  依照列印的指示在 shell 設定中 source 自動完成指令碼。
</Note>
