Poza dziesięcioma wbudowanymi agentami możesz definiować własnych. Niestandardowi agenci to pliki Markdown z blokiem frontmatteru opisującym model agenta, poziom dostępu i dostępne narzędzia, plus ciałem, które działa jako jego prompt systemowy.

## Tworzenie agenta

Najszybsza ścieżka to wbudowany generator, który zadaje kilka pytań i tworzy plik za Ciebie:

```bash
bolt agent create
```

Agenci żyją w `.opencode/agent/` w projekcie (lub w Twoim globalnym katalogu konfiguracyjnym dla osobistych agentów). Każdy agent to pojedynczy plik `.md`, którego nazwa staje się nazwą agenta.

## Anatomia pliku agenta

```md
---
name: "e2e-writer"
description: "Writes and updates Playwright end-to-end tests"
model: "anthropic/claude-opus-4-5"
access: "edit"
tools:
  - read
  - edit
  - write
  - grep
  - bash
---

You are an expert Playwright end-to-end test author. When asked to add tests:

1. Read existing tests in `e2e/` first to match style.
2. Prefer role-based selectors.
3. Always run `pnpm e2e -- --reporter=list` after editing.
```

Częste pola frontmatteru:

| Pole | Cel |
| --- | --- |
| `name` | Nazwa agenta używana z `--agent`. |
| `description` | Jednolinijkowe podsumowanie widoczne na listach. |
| `model` | Domyślny model w formacie `provider/model`. |
| `access` | `full`, `edit` lub `read` (zobacz [Uprawnienia](/concepts/permissions)). |
| `tools` | Opcjonalna biała lista ograniczająca [narzędzia](/concepts/tools), które agent może wywoływać. |

## Używanie niestandardowego agenta

```bash
bolt run --agent e2e-writer "add a signup flow test"
```

W TUI naciśnij `Tab`, aby cyklicznie przechodzić przez agentów; niestandardowi agenci pojawiają się obok wbudowanych.

## Subagenci

Agenci mogą delegować do subagentów przez narzędzie `task`. Bolt dostarczany jest z `@general` i `@explore`, a dowolny niestandardowy agent, którego plik znajduje się w `.opencode/agent/`, może być również wywołany jako subagent po nazwie.
