`bolt serve` uruchamia headless serwer Bolta, który wystawia pełny silnik przez HTTP: sesje, agentów, narzędzia, dostęp do dostawców, MCP i strumieniowanie zdarzeń. Wszystko, co Bolt może robić interaktywnie, może też robić przez API.

## Uruchamianie serwera

```bash
bolt serve                              # localhost only, random port
bolt serve --hostname 0.0.0.0 --port 4096
bolt serve --mdns                       # advertise on the local network
```

<Warning>
  Bindowanie do `0.0.0.0` wystawia Bolta w Twojej sieci. Zawsze ustawiaj `BOLT_SERVER_USERNAME` i `BOLT_SERVER_PASSWORD` przed zrobieniem tego.
</Warning>

## Podłącz TUI

Z dowolnej maszyny, która może dotrzeć do serwera:

```bash
bolt attach http://server:4096
bolt attach --mini http://server:4096
```

Lub uruchom jednorazowy prompt względem zdalnego serwera:

```bash
bolt run --attach http://server:4096 --dir /projects/api "what tests are failing?"
```

## Basic auth

Ustaw dane uwierzytelniające przez zmienne środowiskowe (zobacz [Zmienne środowiskowe](/reference/environment-variables)):

```bash
export BOLT_SERVER_USERNAME=teamname
export BOLT_SERVER_PASSWORD=$(openssl rand -hex 24)
bolt serve --hostname 0.0.0.0 --port 4096
```

Wszyscy klienci muszą wysyłać zgodne dane uwierzytelniające.
