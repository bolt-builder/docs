`bolt web` uruchamia serwer Bolta i serwuje UI przeglądarkowe przed nim. To ten sam silnik co TUI, po prostu wyrenderowany w karcie przeglądarki.

## Uruchamianie

```bash
bolt web                                # localhost only
bolt web --hostname 0.0.0.0 --port 4096
```

Następnie otwórz wypisany URL. Gdy wystawiasz przez sieć, najpierw ustaw basic auth:

```bash
export BOLT_SERVER_USERNAME=teamname
export BOLT_SERVER_PASSWORD=$(openssl rand -hex 24)
bolt web --hostname 0.0.0.0 --port 4096
```

## Kiedy używać UI webowego

- Uruchamianie Bolta na potężnej zdalnej maszynie, ale sterowanie nim z laptopa.
- Dzielenie się żywą sesją z kolegą z zespołu do pair-debuggingu.
- Środowiska, gdzie pełne TUI jest niewygodne (Chromebooki, tablety, maszyny w coworkingu).
