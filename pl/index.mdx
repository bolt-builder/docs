Bolt umieszcza cały zespół inżynierski AI bezpośrednio w Twoim terminalu. Jest dostarczany jako szybki, sterowany klawiaturą TUI oraz natywna aplikacja desktopowa — oba oparte na tym samym silniku: dziesięciu wyspecjalizowanych agentach, trwałych sesjach, zarządzaniu serwerami MCP z OAuth, systemie wtyczek i wsparciu dla wszystkich głównych dostawców LLM.

## Co robi Bolt

Bolt czyta Twoją bazę kodu, rozumie nad czym pracujesz i dostarcza kod razem z Tobą — w terminalu lub jako aplikacja desktopowa. Każda sesja jest trwała: możesz się odłączyć, ponownie podłączyć z innej maszyny, rozgałęzić rozmowę, udostępnić link lub wyeksportować oczyszczoną transkrypcję.

## Zacznij działać

<Steps>
  <Step title="Zainstaluj Bolta">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash
    ```
    Lub zainstaluj przez npm: `npm i -g @bolt-builder/bolt-cli`
  </Step>
  <Step title="Otwórz swój projekt">
    Przejdź do dowolnego katalogu projektu i uruchom TUI:
    ```bash
    cd my-project
    bolt
    ```
  </Step>
  <Step title="Skonfiguruj dostawcę">
    Przy pierwszym uruchomieniu Bolt zapyta Cię o dodanie dostawcy LLM. Możesz też uruchomić:
    ```bash
    bolt providers
    ```
  </Step>
  <Step title="Zacznij kodować z AI">
    Wpisz swój prompt w stopce TUI, naciśnij Enter i pozwól agentom Bolta wziąć się do pracy. Przełączaj agentów za pomocą `Tab`.
  </Step>
</Steps>

<Tip>
  Użyj `bolt run "explain this codebase"`, aby uzyskać szybką, nieinteraktywną odpowiedź bez otwierania pełnego TUI.
</Tip>
