Bolt tuo täyden AI-insinööritiimin suoraan terminaaliisi. Se toimitetaan nopeana, näppäimistövetoisena TUI:na ja natiivina työpöytäsovelluksena, joita molempia tukee sama moottori: kymmenen erikoistunutta agenttia, pysyvät kestävät istunnot, MCP-palvelimien hallinta OAuthilla, laajennusjärjestelmä ja tuki jokaiselle suurelle LLM-tarjoajalle.

## Mitä Bolt tekee

Bolt lukee koodikantasi, ymmärtää mitä olet rakentamassa ja toimittaa koodia kanssasi — terminaalissa tai työpöytäsovelluksena. Jokainen istunto on kestävä: irrottaudu, liity takaisin toiselta koneelta, haaraudu keskustelun haaraan, jaa linkki tai vie siivottu transkripti.

## Käyttöönotto

<Steps>
  <Step title="Asenna Bolt">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash
    ```
    Tai asenna npm:n kautta: `npm i -g @bolt-builder/bolt-cli`
  </Step>
  <Step title="Avaa projektisi">
    Siirry mihin tahansa projektihakemistoon ja käynnistä TUI:
    ```bash
    cd my-project
    bolt
    ```
  </Step>
  <Step title="Määritä tarjoaja">
    Ensimmäisellä käynnistyksellä Bolt kehottaa sinua lisäämään LLM-tarjoajan. Voit myös suorittaa:
    ```bash
    bolt providers
    ```
  </Step>
  <Step title="Aloita koodaus AI:n kanssa">
    Kirjoita kehotteesi TUI:n alatunnisteessa, paina Enter ja anna Boltin agenttien ryhtyä töihin. Vaihda agentteja `Tab`illa.
  </Step>
</Steps>

<Tip>
  Käytä `bolt run "explain this codebase"` nopeaan ei-interaktiiviseen vastaukseen ilman koko TUI:n avaamista.
</Tip>
