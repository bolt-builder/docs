Kymmenen sisäänrakennetun agentin lisäksi voit määrittää omia. Mukautetut agentit ovat Markdown-tiedostoja, joissa on frontmatter-lohko, joka kuvaa agentin mallin, käyttöoikeustason ja käytettävissä olevat työkalut sekä runko, joka toimii sen järjestelmäkehotteena.

## Agentin luominen

Nopein tapa on sisäänrakennettu generaattori, joka esittää muutaman kysymyksen ja kirjoittaa tiedoston puolestasi:

```bash
bolt agent create
```

Agentit sijaitsevat hakemistossa `.opencode/agent/` projektissa (tai globaalissa konfigurointihakemistossasi henkilökohtaisia agentteja varten). Jokainen agentti on yksi `.md`-tiedosto, jonka tiedostonimi on agentin nimi.

## Agenttitiedoston anatomia

```md
---
name: "e2e-writer"
description: "Writes and updates Playwright end-to-end tests"
model: "anthropic/claude-opus-4-5"
access: "edit"
tools:
  - read
  - edit
  - write
  - grep
  - bash
---

You are an expert Playwright end-to-end test author. When asked to add tests:

1. Read existing tests in `e2e/` first to match style.
2. Prefer role-based selectors.
3. Always run `pnpm e2e -- --reporter=list` after editing.
```

Yleiset frontmatter-kentät:

| Kenttä | Tarkoitus |
| --- | --- |
| `name` | Agentin nimi, jota käytetään `--agent`in kanssa. |
| `description` | Yhden rivin tiivistelmä, joka näytetään luetteloissa. |
| `model` | Oletusmalli muodossa `provider/model`. |
| `access` | `full`, `edit` tai `read` (katso [Oikeudet](/concepts/permissions)). |
| `tools` | Valinnainen sallitulista, joka rajoittaa, mitä [työkaluja](/concepts/tools) agentti voi kutsua. |

## Mukautetun agentin käyttö

```bash
bolt run --agent e2e-writer "add a signup flow test"
```

TUI:ssa paina `Tab` selataksesi agentteja; mukautetut agentit näkyvät sisäänrakennettujen rinnalla.

## Aliagentit

Agentit voivat delegoida aliagenteille `task`-työkalun kautta. Bolt sisältää `@general`in ja `@explore`n, ja mikä tahansa mukautettu agentti, jonka tiedosto sijaitsee hakemistossa `.opencode/agent/`, voidaan myös kutsua aliagenttina nimen perusteella.
