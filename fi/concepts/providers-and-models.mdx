Bolt on suunniteltu malli-agnostiseksi. Konepellin alla se käyttää **Vercel AI SDK:ta** puhuakseen tarjoajille, mikä tarkoittaa, että mikä tahansa SDK:n tukema tarjoaja — Anthropic, OpenAI, Google, Amazon Bedrock, OpenRouter ja muut — toimii heti valmiiksi. Tarjoaja- ja malliluettelo saadaan sivustolta [models.dev](https://models.dev), yhteisöllisesti ylläpidetystä tarjoajien metatietojen ja hinnoittelun tietokannasta.

## Tarjoajien tunnistetietojen hallinta

Käytä komentoa `bolt providers` (aliaksena `bolt auth`) lisätäksesi, listataksesi ja poistaaksesi tarjoajien tunnistetietoja.

### Lisää tai päivitä tunnistetietoja

```bash
bolt providers login
# or equivalently:
bolt auth login
```

Tämä käynnistää interaktiivisen kehotteen tarjoajan valitsemiseksi ja tunnistetietojen antamiseksi. Ohittaaksesi interaktiivisen virran anna liput suoraan:

```bash
bolt providers login --provider anthropic
bolt providers login --provider openai --method "API key"
```

### Listaa määritetyt tarjoajat

```bash
bolt providers list
# or:
bolt auth list
```

Näyttää kaikki tallennetut tunnistetiedot ja kaikki ympäristömuuttujista havaitut tarjoajien API-avaimet.

### Poista tunnistetietoja

```bash
bolt providers logout
bolt providers logout anthropic
```

### Ympäristömuuttujatodennus

CI-putkia tai päätöntä ympäristöä varten aseta tarjoajan API-avaimen ympäristömuuttuja suoraan — interaktiivista kirjautumista ei tarvita. Yleisiä esimerkkejä:

```bash
export ANTHROPIC_API_KEY="sk-ant-..."
export OPENAI_API_KEY="sk-..."
export GOOGLE_GENERATIVE_AI_API_KEY="AIza..."
```

Bolt lukee nämä muuttujat automaattisesti käynnistyksessä. `bolt providers list` tuo esiin, mitkä ympäristömuuttujat se havaitsi.

## Käytettävissä olevien mallien selaus

`bolt models` listaa jokaisen mallin, joka on käytettävissä määritettyjen tarjoajien kautta.

```bash
# List all models
bolt models

# Filter to one provider
bolt models anthropic

# Show cost and capability metadata
bolt models --verbose

# Refresh the model catalog from models.dev
bolt models --refresh
```

<Tip>
  Suorita `bolt models --verbose` nähdäksesi jokaisen mallin syöte-/tulostetokenin hinnat. Tämä tekee kustannuskompromissien vertailun helpoksi ennen kuin sitoudut malliin pitkäkestoisessa tehtävässä.
</Tip>

### Mallin tunnisteen muoto

Malleihin viitataan aina muodossa `provider/model`:

```
anthropic/claude-opus-4-5
openai/gpt-4o
google/gemini-2.5-pro
openrouter/anthropic/claude-opus-4-5
```

Käytä tätä muotoa missä tahansa Bolt hyväksyy mallin — CLI-lipuissa, konfigurointitiedostoissa ja agenttimääritelmissä.

## Mallin valitseminen ajoaikaisesti

### `--model` / `-m` -lippu

`--model`-lippu on käytettävissä komennoilla `bolt run`, `bolt commit` ja `bolt review`:

```bash
bolt run --model anthropic/claude-opus-4-5 "refactor the payment module"
bolt commit --model openai/gpt-4o
bolt review --model google/gemini-2.5-pro --staged
```

### `--variant` — päättelytason säätäminen

Jotkin mallit tukevat säädettäviä päättelytason tasoja (esim. Anthropicin extended thinking, OpenAI:n päättelymallit). Käytä `--variant`ia valitaksesi tason:

```bash
bolt run --variant high "design a distributed rate limiter"
bolt run --variant minimal "rename this variable"
```

<Note>
  Käytettävissä olevat variant-arvot riippuvat tarjoajasta ja mallista. Yleisiä arvoja ovat `minimal`, `low`, `medium`, `high` ja `max`, mutta tarkka joukko vaihtelee. Tarkista tarjoajasi dokumentaatio tai käytä komentoa `bolt models --verbose` nähdäksesi tietylle mallille tuetut variantit.
</Note>

### `--thinking` — näytä päättelylohkot

Kun käytät mallia, joka tukee extended thinking -toimintoa, anna `--thinking` tuodaksesi mallin ajatteluketjun tulosteeseen:

```bash
bolt run --model anthropic/claude-opus-4-5 --variant high --thinking \
  "why does the token refresh logic race in the auth service?"
```

## Parhaan-N rinnakkaisajot

`--best-of` laukaisee saman kehotteen useille malleille rinnakkain ja käyttää sitten tuomarimallia arvioimaan vastaukset ja pitämään parhaan:

```bash
bolt run --best-of "anthropic/claude-opus-4-5,openai/gpt-4o,google/gemini-2.5-pro" \
  "implement a binary search tree with full test coverage"
```

Tuomari on oletuksena `--model`-lipun kautta annettu malli tai `--best-of`-luettelon ensimmäinen merkintä, jos `--model`ia ei ole asetettu. Lippu hyväksyy pilkulla erotetun luettelon `provider/model`-tunnisteista.

<Tip>
  Paras-N on erityisen hyödyllinen monimutkaisissa algoritmisissa ongelmissa tai arkkitehtuuripäätöksissä, joissa eri mallit voivat tuoda aidosti erilaisia lähestymistapoja. Anna Boltin ajaa ne rinnakkain ja poimia voittaja automaattisesti.
</Tip>
