## 新功能

- **11 种新的 UI 语言** — 桌面应用和 TUI 现在提供印地语、荷兰语、印尼语、越南语、意大利语、乌尔都语、旁遮普语、阿塞拜疆语、芬兰语、瑞典语和泰语的翻译，支持的语言总数达到 28 种。在 **Settings → Appearance → Language** 中切换语言。参见[桌面功能](/desktop/features)和[安装](/desktop/install#28-ui-languages)。
- **从右至左布局支持** — 导航、编辑器、对话框、控件和文本渲染现在能够正确地镜像显示阿拉伯语、希伯来语和乌尔都语等从右至左的语言，因此在这些区域设置下整个界面阅读起来自然流畅。
- **原生桌面翻译** — 操作系统级菜单、更新程序对话框、恢复流程、WSL 引导以及原生文件选择器现在与应用内 UI 一起进行了本地化，因此整个桌面体验都遵循你的语言设置。
- **扩展的本地化覆盖** — 菜单、对话框、提示、帮助内容、错误消息和无障碍标签现已在所有支持的语言中进行了翻译,弥补了之前字符串回退到英文的空白。
- **Poolside 提供商** — Bolt 现在通过 [Poolside](https://poolside.ai) 的 OpenAI 兼容 API 连接到 Poolside。运行 `/connect`，选择 **Poolside**，并粘贴从 [platform.poolside.ai](https://platform.poolside.ai) 获取的 API 密钥。自托管的 Poolside 部署也可以配置为自定义提供商。参见[提供商与模型](/concepts/providers-and-models)。
- **区域感知的复数处理** — 计数、状态、文件和会话列表项目现在按语言正确地进行复数处理，因此时间线和状态文本在所有支持的区域设置下都能自然地阅读。
- **更丰富的 Markdown 渲染** — 助手消息获得改进的 Markdown 格式、更流畅的流式更新、更好的语法高亮以及对数学内容的支持，使长格式和技术回复更易于阅读。

## 更新

- **GPT-5 推理强度与模型版本匹配** — 推理强度层级（包括 `none` 和 `xhigh`）现在仅为支持它们的 GPT-5 变体提供，因此 `--variant` 不再显示给定模型会拒绝的选项。参见[控制推理强度](/concepts/providers-and-models#variant-controlling-reasoning-effort)。
- **Diff 注解优化** — 会话 UI diff 视图收紧了评论指示器、栏槽行为以及浅色/深色语法颜色，以提升可读性。
- **精炼现有翻译** — 现有语言获得了更清晰的术语和扩展的 UI 标签，在整个应用中获得更一致的体验。

## Bug 修复

- **会话操作时间** — 会话操作现在更准确地记录和报告其时间，因此时间线反映了工作实际开始和完成的时间。
- **更清晰的远程工作区错误** — 连接到远程工作区或在其中运行命令时的失败现在会显示更具描述性的错误消息，而不是通用消息。
- **工作区代理不再泄漏工作目录** — 通过工作区代理路由的请求不再包含工作目录详情，本地路径不会出现在传输中。
- **地图填充空白区域** — 活动地图现在在没有记录活动的区域中保持可见，而不是折叠为空白区域。
- **区域检测已修复** — Bolt 现在在启动时可靠地识别你的系统区域设置，因此界面在更多平台上以正确的语言打开。
- **德语时间线翻译已修复** — 德语的时间线条目现在使用正确的字符串渲染，而不是回退到英文或错误格式的文本。
- **切换文件选择关闭** — 再次点击文件选择现在会清除它，因此你可以在不必先选择其他文件的情况下撤销选择。
- **更清晰的草稿评论交互** — 开始或消除草稿评论现在会一致地清除底层选择，不再与悬停状态竞争。
- **推理头动画已恢复** — TUI 中的推理头在思考时再次显示动画旋转器，其渐变在展开时变暗，因此更容易区分折叠和打开状态。
- **主屏幕和错误屏幕上的 Bolt 字标** — New Session 水印以及旧版主屏幕和错误屏幕现在显示 Bolt 字标而不是上游 logo，因此品牌在每个屏幕上都保持一致。
- **后台进程和测试工具已恢复** — `bash_background`、`process_output`、`list_processes`、`kill_process` 和 `test_run` 在早期合并中被删除后再次可用于代理。代理可以启动长时间运行的命令（如开发服务器和监视器）、读取其输出，并使用结构化的通过/失败结果运行项目的测试。参见[内置工具](/concepts/tools#built-in-tools)。
