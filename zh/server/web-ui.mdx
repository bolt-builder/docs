`bolt web` 启动 Bolt 服务器并在其前面提供浏览器 UI。它与 TUI 是同一个引擎,只是在浏览器标签中渲染。

## 启动它

```bash
bolt web                                # localhost only
bolt web --hostname 0.0.0.0 --port 4096
```

然后打开打印的 URL。通过网络暴露时,先设置基本认证：

```bash
export BOLT_SERVER_USERNAME=teamname
export BOLT_SERVER_PASSWORD=$(openssl rand -hex 24)
bolt web --hostname 0.0.0.0 --port 4096
```

## 何时使用 Web UI

- 在强大的远程机器上运行 Bolt,但从笔记本电脑驱动它。
- 与队友共享实时会话进行结对调试。
- 完整 TUI 尴尬的环境（Chromebooks、平板电脑、协作机器）。
