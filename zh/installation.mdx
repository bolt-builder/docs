Bolt 可以在 macOS、Linux 和 Windows 上使用适合你工作流程的方法进行安装 — 一行 curl 脚本、任何主要的 Node.js 包管理器，或 Homebrew、Chocolatey 或 Scoop 等系统包管理器。

## 快速安装（macOS / Linux）

最快的入门方式是官方安装脚本。它会自动检测你的操作系统和架构，将正确的二进制文件下载到 `~/.bolt/bin`，并将其添加到你的 `$PATH`。

```bash
curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash
```

安装程序还会设置可选的语音输入依赖项（sox 和 whisper-cpp 用于离线转录）。要跳过它，传递 `--no-voice`：

```bash
curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash -s -- --no-voice
```

要锁定特定版本：

```bash
curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash -s -- --version 1.20.2
```

## 包管理器

使用你选择的包管理器全局安装 Bolt：

<CodeGroup>

```bash npm
npm i -g @bolt-builder/bolt-cli
```

```bash bun
bun add -g @bolt-builder/bolt-cli
```

```bash pnpm
pnpm add -g @bolt-builder/bolt-cli
```

```bash yarn
yarn global add @bolt-builder/bolt-cli
```

</CodeGroup>

## 验证安装

<Steps>
  <Step title="检查已安装的版本">
    安装后，确认 `bolt` 在你的 `$PATH` 上可用：

    ```bash
    bolt --version
    ```

    如果找不到该命令，请打开新的终端会话（或重新加载你的 shell 配置），以便更新后的 `$PATH` 生效。
  </Step>
</Steps>

## 升级

运行 `bolt upgrade` 以更新到最新版本：

```bash
bolt upgrade
```

Bolt 会自动检测你最初的安装方法。你可以使用 `--method` 标志覆盖它：

```bash
bolt upgrade --method <method>
```

支持的方法包括：`curl`、`npm`、`pnpm`、`bun`、`brew`、`choco`、`scoop`。

你也可以通过将版本作为位置参数传递来升级到特定版本：

```bash
bolt upgrade 1.20.2
```

## 卸载

从系统中移除 Bolt：

```bash
bolt uninstall
```

## 环境变量

| 变量                     | 描述                                                    |
| ---------------------- | ----------------------------------------------------- |
| `BOLT_LOG_LEVEL`       | 日志详细级别：`DEBUG`、`INFO`、`WARN` 或 `ERROR`               |
| `BOLT_PRINT_LOGS`      | 将日志打印到 stderr                                          |
| `BOLT_PURE`            | 不加载外部插件运行                                            |
| `BOLT_SERVER_PASSWORD` | 无头 API 服务器的基本认证密码                                    |
| `BOLT_SERVER_USERNAME` | 无头 API 服务器的基本认证用户名                                    |

<Tip>
  当你想在没有任何第三方插件的情况下进行干净的运行时,设置 `BOLT_PURE=1` — 对于调试或受控 CI 环境非常有用。
</Tip>

## 桌面应用

<Note>
  Bolt 也作为原生桌面应用发布，具备多窗口会话管理、集成终端和文件树、命令面板、28 种 UI 语言和自动更新。从[发布页面](https://github.com/Bolt-builder/bolt-cli/releases)下载最新版本。

  在 macOS 上你可以一行命令安装，无需 Gatekeeper 绕行：

  ```bash
  curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install-desktop | bash
  ```
</Note>
