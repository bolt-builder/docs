Bolt помещает полноценную AI-команду инженеров прямо в ваш терминал. Он поставляется как быстрый, управляемый с клавиатуры TUI и как нативное настольное приложение — оба построены на одном движке: десять специализированных агентов, устойчивые долгоживущие сессии, управление MCP-серверами с OAuth, система плагинов и поддержка всех крупных LLM-провайдеров.

## Что делает Bolt

Bolt читает вашу кодовую базу, понимает, что вы создаёте, и пишет код вместе с вами — в терминале или в настольном приложении. Каждая сессия долговечна: отсоединяйтесь, подключайтесь заново с другой машины, разветвляйте разговор, делитесь ссылкой или экспортируйте очищенную стенограмму.

## Запуск и работа

<Steps>
  <Step title="Установите Bolt">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash
    ```
    Или установите через npm: `npm i -g @bolt-builder/bolt-cli`
  </Step>
  <Step title="Откройте свой проект">
    Перейдите в каталог любого проекта и запустите TUI:
    ```bash
    cd my-project
    bolt
    ```
  </Step>
  <Step title="Настройте провайдера">
    При первом запуске Bolt предложит добавить LLM-провайдера. Также можно выполнить:
    ```bash
    bolt providers
    ```
  </Step>
  <Step title="Начните программировать с AI">
    Введите промпт в подвале TUI, нажмите Enter и дайте агентам Bolt приступить к работе. Переключайте агентов клавишей `Tab`.
  </Step>
</Steps>

<Tip>
  Используйте `bolt run "explain this codebase"` для быстрого неинтерактивного ответа без запуска полного TUI.
</Tip>
