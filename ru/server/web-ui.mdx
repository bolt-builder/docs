`bolt web` запускает сервер Bolt и обслуживает браузерный UI перед ним. Это тот же движок, что и в TUI, только отрисованный во вкладке браузера.

## Запуск

```bash
bolt web                                # только localhost
bolt web --hostname 0.0.0.0 --port 4096
```

Затем откройте выведенный URL. При выставлении в сеть сначала задайте Basic Auth:

```bash
export BOLT_SERVER_USERNAME=teamname
export BOLT_SERVER_PASSWORD=$(openssl rand -hex 24)
bolt web --hostname 0.0.0.0 --port 4096
```

## Когда использовать веб-UI

- Bolt работает на мощной удалённой машине, а управляете вы с ноутбука.
- Совместное использование живой сессии с товарищем по команде для парной отладки.
- Окружения, где полный TUI неудобен (Chromebook'и, планшеты, машины в коворкингах).
