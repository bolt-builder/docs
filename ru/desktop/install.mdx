Настольное приложение Bolt оборачивает тот же движок, что и CLI, в полноценную оболочку Electron. Каждая возможность, доступная в терминале — агенты, MCP-серверы, плагины, удалённые сессии, сессии, которые можно форкать и шарить — работает идентично в настольном приложении, с добавлением многооконного и многовкладочного опыта, графического UI настроек, нативных уведомлений и автообновлений. Если вы уже используете CLI, настольное приложение — это дополнение drop-in, а не замена.

## Установка

### macOS

<Steps>
  <Step title="Установка однострочником (рекомендуется)">
    Откройте терминал и запустите:

    ```bash
    curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install-desktop | bash
    ```

    Скрипт загружает последний релиз, проверяет его и размещает приложение в `/Applications`. Никаких всплывающих окон Gatekeeper.
  </Step>

  <Step title="Запустите приложение">
    Откройте **Bolt** из `/Applications` или Spotlight. При первом запуске Bolt попросит вас выбрать LLM-провайдера по умолчанию и создаст глобальный файл конфигурации.
  </Step>
</Steps>

<Tip>
  Однострочник устанавливает приложение так, чтобы обойти диалог macOS Gatekeeper «неидентифицированный разработчик», так что вы сразу переходите к программированию без лишних запросов безопасности.
</Tip>

### Все платформы — скачать с релизов

Скачайте последний установщик для вашей платформы со [страницы релизов Bolt](https://github.com/Bolt-builder/bolt-cli/releases).

| Платформа | Тип установщика |
|----------|---------------|
| macOS (Apple Silicon) | `.dmg` |
| macOS (Intel) | `.dmg` |
| Windows | `.exe` установщик |
| Linux | `.AppImage` / `.deb` |

<Note>
  На Windows Bolt включает интеграцию с WSL (Windows Subsystem for Linux). Когда WSL доступна, Bolt может открывать сессии прямо внутри вашего дистрибутива WSL — давая вам нативное для Linux окружение агента с нативным Windows-интерфейсом вокруг.
</Note>

## Возможности

### Многооконное и многовкладочное управление сессиями

Открывайте столько окон, сколько хотите, каждое со своим набором вкладок. Вкладки соответствуют сессиям Bolt, так что вы можете запустить агента на рефакторинге в одной вкладке, задать вопрос в другой и выполнить фоновую задачу в третьей — всё одновременно.

### Композитор промптов

Композитор промптов поддерживает богатый ввод: вставляйте текст, перетаскивайте файлы как вложения или вставляйте изображение прямо из буфера обмена. Bolt автоматически кодирует изображение и отправляет его в любую модель с поддержкой зрения.

### Встроенный терминал и дерево файлов

Разделённая раскладка даёт вам разговор с агентом с одной стороны и живой терминал с деревом файлов проекта — с другой. Вы можете запускать команды, инспектировать вывод и передавать результаты обратно агенту, не переключая приложения.

### Палитра команд

Нажмите `Cmd/Ctrl+K`, чтобы открыть палитру команд. Отсюда можно переключаться между сессиями, менять агентов, открывать настройки или запускать любое действие, не касаясь мыши.

### Полноценный UI настроек

Панель настроек охватывает каждую опцию, которая живёт в `.bolt/bolt.jsonc` — клавиатурные привязки, выбор модели, LLM-провайдеры, MCP-серверы и аутентификация, — с выпадающими списками, переключателями и валидацией в реальном времени. Ручное редактирование файла конфигурации редко требуется.

### Нативные уведомления

Bolt отправляет нативное уведомление ОС, когда долгая задача завершается. Клик по уведомлению переносит вас прямо в сессию.

### Глубокие ссылки

Открывайте конкретную сессию, переходя по URL `bolt://`. Полезно для отправки ссылок на сессии товарищам по команде или закладок для work-in-progress.

### Автообновления

Настольное приложение обновляется по трём каналам:

| Канал | Описание |
|---------|-------------|
| `prod` | Стабильные релизы, обновляются на каждый production-тег |
| `beta` | Пре-релизные сборки для раннего доступа к новым функциям |
| `dev` | Nightly-сборки с ветки `dev` |

Переключайте каналы в **Settings → About**.

### 28 языков интерфейса

Интерфейс Bolt локализован на 28 языков. Меняйте язык отображения в **Settings → Appearance → Language**.
