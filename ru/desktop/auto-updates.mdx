Настольное приложение автоматически обновляется в фоне по трём каналам релизов:

| Канал | Периодичность | Для кого |
| --- | --- | --- |
| `prod` | Только стабильные релизы. | Для всех по умолчанию. |
| `beta` | Релиз-кандидаты. | Для команд, которым нужно предупреждение о следующем стабильном. |
| `dev` | Почти ежедневно. | Для early adopters и контрибьюторов. |

## Смена каналов

Переключите канал в панели настроек приложения. При следующем запуске приложение проверит выбранный канал на более новую сборку; вы также можете инициировать проверку вручную.

## Как это устроено

Обновления загружаются в фоне и применяются при следующем запуске. Если обновление не удаётся применить, приложение сохраняет предыдущую версию и показывает ошибку — промежуточного состояния не бывает.
