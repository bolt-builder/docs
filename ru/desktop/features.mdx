Настольное приложение — это тот же движок Bolt, обёрнутый в нативную оболочку с несколькими вещами, которые терминал сделать не может.

## Что внутри

- **Многооконные сессии в нескольких вкладках.** Запускайте несколько агентов параллельно по разным проектам, каждый в своей вкладке.
- **Композитор промптов.** Богатый ввод с прикреплением файлов и вставкой изображений из буфера обмена — бросайте скриншоты прямо в промпт.
- **Встроенный терминал \+ дерево файлов.** Настоящая shell и обозреватель проекта рядом с чатом.
- **Палитра команд.** `Cmd/Ctrl+K` для прыжков между сессиями, выполнения любой команды Bolt или запуска слэш-команды.
- **Настройки.** Клавиатурные привязки, модели, провайдеры и настроенные серверы, всё редактируется в настоящем UI настроек.
- **Нативные уведомления.** ОС уведомляет вас, когда долгий агент завершает работу.
- **Глубокие ссылки.** URL `bolt://` для перехода к сессиям откуда угодно.
- **Интеграция с WSL на Windows.** Работает с вашим WSL-окружением из коробки.
- **28 языков интерфейса.**
