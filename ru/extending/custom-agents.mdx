Помимо десяти встроенных агентов, вы можете определять собственных. Пользовательские агенты — это Markdown-файлы с блоком frontmatter, описывающим модель, уровень доступа и доступные инструменты агента, плюс тело, которое действует как его системный промпт.

## Создание агента

Самый быстрый путь — встроенный генератор, который задаёт несколько вопросов и записывает файл за вас:

```bash
bolt agent create
```

Агенты живут в `.opencode/agent/` в проекте (или в вашем глобальном каталоге конфигурации для персональных агентов). Каждый агент — это отдельный файл `.md`, имя которого становится именем агента.

## Анатомия файла агента

```md
---
name: "e2e-writer"
description: "Writes and updates Playwright end-to-end tests"
model: "anthropic/claude-opus-4-5"
access: "edit"
tools:
  - read
  - edit
  - write
  - grep
  - bash
---

You are an expert Playwright end-to-end test author. When asked to add tests:

1. Read existing tests in `e2e/` first to match style.
2. Prefer role-based selectors.
3. Always run `pnpm e2e -- --reporter=list` after editing.
```

Распространённые поля frontmatter:

| Поле | Назначение |
| --- | --- |
| `name` | Имя агента, используемое с `--agent`. |
| `description` | Однострочное описание, показываемое в списках. |
| `model` | Модель по умолчанию в формате `provider/model`. |
| `access` | `full`, `edit` или `read` (см. [Разрешения](/concepts/permissions)). |
| `tools` | Опциональный allow-list, ограничивающий, какие [инструменты](/concepts/tools) агент может вызывать. |

## Использование пользовательского агента

```bash
bolt run --agent e2e-writer "add a signup flow test"
```

В TUI нажмите `Tab`, чтобы циклически перебрать агентов; пользовательские агенты появляются рядом со встроенными.

## Субагенты

Агенты могут делегировать субагентам через инструмент `task`. Bolt поставляется с `@general` и `@explore`, а любой пользовательский агент, файл которого лежит под `.opencode/agent/`, также может вызываться как субагент по имени.
