Bolt держит каждую сессию, сообщение и вызов инструмента в локальной базе SQLite. Она полностью инспектируемая и полностью ваша — ничего не выгружается, если только вы явно не поделитесь сессией.

## Обычные операции

```bash
bolt db path                        # вывести путь к файлу SQLite
bolt db                             # открыть интерактивную SQL-оболочку
bolt db "SELECT id, title FROM sessions ORDER BY time_updated DESC LIMIT 20"
```

## Резервное копирование

Поскольку это единый файл SQLite, резервная копия — это просто копирование:

```bash
cp "$(bolt db path)" ~/backups/bolt-$(date +%Y%m%d).db
```

Для долгосрочного хранения или переноса предпочитайте `bolt export` / `bolt import` — они дают переносимое JSON-представление, которое переживает миграции схемы.

## Схема в общих чертах

- `sessions` — по одной строке на сессию, с названием, проектом, метками времени и статусом.
- `messages` — полный лог ходов на сессию.
- `tool_calls` — каждый вызов с входами, выходами и длительностью.

Точные столбцы эволюционируют; используйте `PRAGMA table_info(<table>)`, чтобы увидеть актуальную схему.
