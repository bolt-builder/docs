`bolt stats` агрегирует счётчики токенов и стоимость по локальной базе данных сессий. Поскольку каждый вызов инструмента записывается (см. [Локальную базу данных](/reference/local-database)), числа точны для LLM-вызовов, которые совершал Bolt.

## Базовое использование

```bash
bolt stats                       # сводка по текущему проекту
bolt stats --days 7              # последние семь дней
bolt stats --days 7 --models     # разбивка по моделям
```

## Что она показывает

- Общее число входных, выходных и кэш-токенов.
- Оценочная стоимость по провайдерам (по тарифным таблицам провайдеров на момент запуска).
- Разбивки по моделям, агентам и дням в зависимости от флагов.

## Снижение стоимости

- Используйте `--variant minimal` или `--variant low` на моделях с интенсивным рассуждением. См. [Провайдеры и модели](/concepts/providers-and-models).
- Предпочитайте агентов `ask` или `plan` для исследования; они только для чтения и избегают циклов с активным использованием инструментов.
- Переключайтесь на меньшую модель через `bolt models` для задач, не требующих frontier-возможностей.
