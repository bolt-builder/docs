Bolt по замыслу не привязан к модели. Под капотом он использует **Vercel AI SDK** для общения с провайдерами, а это значит, что любой провайдер, поддерживаемый SDK — Anthropic, OpenAI, Google, Amazon Bedrock, OpenRouter и другие, — работает «из коробки». Каталог провайдеров и моделей берётся с [models.dev](https://models.dev), поддерживаемой сообществом базы метаданных провайдеров и цен.

## Управление учётными данными провайдеров

Используйте `bolt providers` (синоним `bolt auth`) для добавления, просмотра и удаления учётных данных провайдеров.

### Добавление или обновление учётных данных

```bash
bolt providers login
# или эквивалентно:
bolt auth login
```

Это запустит интерактивный диалог для выбора провайдера и ввода учётных данных. Чтобы пропустить интерактивный поток, передавайте флаги напрямую:

```bash
bolt providers login --provider anthropic
bolt providers login --provider openai --method "API key"
```

### Список настроенных провайдеров

```bash
bolt providers list
# или:
bolt auth list
```

Отображает все сохранённые учётные данные и любые API-ключи провайдеров, обнаруженные в переменных окружения.

### Удаление учётных данных

```bash
bolt providers logout
bolt providers logout anthropic
```

### Аутентификация через переменные окружения

Для CI-пайплайнов или headless-окружений установите переменную окружения с API-ключом провайдера напрямую — интерактивный логин не требуется. Распространённые примеры:

```bash
export ANTHROPIC_API_KEY="sk-ant-..."
export OPENAI_API_KEY="sk-..."
export GOOGLE_GENERATIVE_AI_API_KEY="AIza..."
```

Bolt автоматически считывает эти переменные при запуске. `bolt providers list` покажет, какие переменные окружения он обнаружил.

## Просмотр доступных моделей

`bolt models` показывает список всех моделей, доступных через ваши настроенные провайдеры.

```bash
# Список всех моделей
bolt models

# Фильтр по одному провайдеру
bolt models anthropic

# Показ метаданных стоимости и возможностей
bolt models --verbose

# Обновить каталог моделей с models.dev
bolt models --refresh
```

<Tip>
  Запустите `bolt models --verbose`, чтобы увидеть цены на входные/выходные токены для каждой модели. Так проще сравнивать компромиссы по стоимости перед выбором модели для долгой задачи.
</Tip>

### Формат идентификатора модели

На модели всегда ссылаются в формате `provider/model`:

```
anthropic/claude-opus-4-5
openai/gpt-4o
google/gemini-2.5-pro
openrouter/anthropic/claude-opus-4-5
```

Используйте этот формат везде, где Bolt принимает модель — флаги CLI, файлы конфигурации и определения агентов.

## Выбор модели во время выполнения

### Флаг `--model` / `-m`

Флаг `--model` доступен в `bolt run`, `bolt commit` и `bolt review`:

```bash
bolt run --model anthropic/claude-opus-4-5 "refactor the payment module"
bolt commit --model openai/gpt-4o
bolt review --model google/gemini-2.5-pro --staged
```

### `--variant` — управление усилиями рассуждения

Некоторые модели поддерживают настраиваемые уровни усилий рассуждения (например, расширенное мышление Anthropic, модели рассуждения OpenAI). Используйте `--variant` для выбора уровня усилий:

```bash
bolt run --variant high "design a distributed rate limiter"
bolt run --variant minimal "rename this variable"
```

<Note>
  Доступные значения варианта зависят от провайдера и модели. Распространённые значения — `minimal`, `low`, `medium`, `high` и `max`, но точный набор варьируется. Проверьте документацию провайдера или используйте `bolt models --verbose`, чтобы увидеть поддерживаемые варианты для конкретной модели.
</Note>

### `--thinking` — показ блоков рассуждения

При использовании модели, поддерживающей расширенное мышление, передайте `--thinking`, чтобы вывести цепочку рассуждений модели в вывод:

```bash
bolt run --model anthropic/claude-opus-4-5 --variant high --thinking \
  "why does the token refresh logic race in the auth service?"
```

## Параллельные запуски best-of-N

`--best-of` отправляет один и тот же промпт нескольким моделям параллельно, затем использует модель-судью для ранжирования ответов и сохранения лучшего:

```bash
bolt run --best-of "anthropic/claude-opus-4-5,openai/gpt-4o,google/gemini-2.5-pro" \
  "implement a binary search tree with full test coverage"
```

По умолчанию судьёй выступает модель, переданная через `--model`, или первая запись в списке `--best-of`, если `--model` не задан. Флаг принимает список идентификаторов `provider/model` через запятую.

<Tip>
  Best-of-N особенно полезен для сложных алгоритмических задач или архитектурных решений, где разные модели могут привнести действительно разные подходы. Пусть Bolt запустит их параллельно и автоматически выберет победителя.
</Tip>
