Агенты в Bolt работают, вызывая инструменты. Каждое действие, которое вы видите в TUI (чтение файла, запуск тестов, поиск в вебе), — это выбор моделью инструмента и его выполнение Bolt'ом. У каждого агента есть заявленный уровень доступа, определяющий, какие инструменты он может вызвать, не спрашивая вас (см. [Разрешения](/concepts/permissions)).

## Встроенные инструменты

| Инструмент | Что делает |
| --- | --- |
| `read` | Читает файл с диска. |
| `write` | Создаёт новый файл или перезаписывает существующий. |
| `edit` | Применяет точечную правку (find/replace) к файлу. |
| `apply_patch` | Применяет патч в формате unified diff к одному или нескольким файлам. |
| `glob` | Показывает файлы, соответствующие glob-шаблону. |
| `grep` | Ищет содержимое файлов по regex/тексту. |
| `bash` | Запускает shell-команду. |
| `task` | Делегирует подзадачу субагенту (`@general`, `@explore` или пользовательскому субагенту). |
| `todowrite` | Ведёт структурированный список задач агента для многошаговой работы. |
| `webfetch` | Загружает URL и возвращает его содержимое. |
| `websearch` | Ищет в вебе. |
| `skill` | Вызывает именованный навык (см. [Навыки](/extending/skills)). |
| `memory_save` | Сохраняет факт в [память проекта](/concepts/project-memory). |
| `memory_recall` | Находит ранее сохранённую запись памяти. |
| `question` | Задаёт вам уточняющий вопрос и ждёт ответа. |
| `bash_background` | Запускает shell-команду как управляемый фоновый процесс (dev-серверы, watcher'ы, долгие сборки). |
| `process_output` | Читает накопленный вывод и статус фонового процесса, опционально ожидая его завершения. |
| `list_processes` | Показывает фоновые процессы с их id, статусом и командой. |
| `kill_process` | Завершает фоновый процесс (и его дерево процессов) по id. |
| `test_run` | Обнаруживает и запускает тесты проекта, возвращая структурированные результаты pass/fail и детали неуспехов. |

### Экспериментальные

| Инструмент | Что делает |
| --- | --- |
| `lsp` | Опрашивает language server для получения определений, ссылок и диагностики. |
| `execute` | Запускает код в изолированной песочнице code-mode. |
| `plan` | Формирует структурированный план перед внесением изменений. |

Экспериментальные инструменты могут меняться или переименовываться между релизами.

## Расширение набора инструментов

Помимо встроенных, Bolt может вызывать инструменты из трёх источников:

- **Пользовательские инструменты** в `.opencode/tool/` (или `.opencode/tools/`) в корне проекта. См. [Пользовательские инструменты](/extending/custom-tools).
- **Инструменты плагинов** от любого установленного [плагина](/extending/plugins).
- **Инструменты MCP** от любого [MCP-сервера](/extending/mcp-servers), настроенного для проекта.

Все три источника с точки зрения агента выглядят одинаково: они появляются в списке инструментов, соблюдают уровень доступа агента и отображаются в выводе вызовов инструментов в TUI.
