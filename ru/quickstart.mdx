Это руководство проведёт вас через установку Bolt, запуск его в проекте, подключение AI-провайдера и выполнение первого промпта. Весь процесс занимает менее минуты.

<Steps>
  <Step title="Установите Bolt">
    Самый быстрый путь — официальный скрипт установки, работающий на macOS и Linux:

    ```bash
    curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash
    ```

    Предпочитаете пакетный менеджер? Установите глобально через npm, bun, pnpm или yarn:

    ```bash
    npm i -g @bolt-builder/bolt-cli
    ```

    Для настольного приложения на macOS (без обхода Gatekeeper):

    ```bash
    curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install-desktop | bash
    ```

    См. [Руководство по установке](/installation) для всех методов, включая Homebrew, Chocolatey, Scoop и особенности Windows.
  </Step>
  <Step title="Откройте свой проект">
    Перейдите в каталог любого проекта и запустите интерактивный TUI:

    ```bash
    cd my-project
    bolt
    ```

    Bolt автоматически подхватывает контекст проекта — читает дерево файлов, понимает стек и делает это доступным каждому агенту с момента открытия.
  </Step>
  <Step title="Настройте AI-провайдера">
    При первом запуске Bolt предложит настроить провайдера, если ни один не задан. Это также можно выполнить в любой момент:

    ```bash
    bolt providers
    ```

    Это открывает поток управления провайдерами, где можно добавлять API-ключи для OpenAI, Anthropic и других поддерживаемых LLM-провайдеров. Конфигурация сохраняется в `.bolt/bolt.jsonc` в корне вашего проекта.

    ```jsonc
    {
      "$schema": "https://opencode.ai/config.json",
      "provider": {
        // Provider config goes here
      }
    }
    ```
  </Step>
  <Step title="Введите промпт и изучите агентов">
    Оказавшись в TUI, введите свой промпт и нажмите Enter. Используйте **Tab** для переключения между десятью встроенными агентами Bolt в любой момент — текущий агент показан в строке состояния.

    Промпты также можно запускать напрямую из командной строки, не открывая TUI:

    ```bash
    # Неинтерактивный промпт с агентом по умолчанию
    bolt run "explain this codebase"
    
    # Использовать конкретного агента
    bolt run --agent ask "what does this project do?"
    
    # Подключить TUI к работающему серверу (локальному или удалённому)
    bolt attach <url>
    ```
  </Step>
</Steps>

## Встроенные агенты

Переключайте агентов клавишей `Tab` в TUI или передавайте `--agent <name>` в `bolt run`. У каждого агента определён уровень доступа под его назначение.

| Агент | Доступ | Описание |
| --- | --- | --- |
| `code` | Full | По умолчанию: читает, пишет и запускает код |
| `plan` | Read | Исследует кодовую базу и формирует план без изменения файлов |
| `ask` | Read | Вопросы и исследование — без правок файлов |
| `code-review` | Read | Проверяет изменения на корректность, стиль и безопасность |
| `debug` | Full | Отлаживает падающие тесты, крэши и логические ошибки |
| `refactor` | Full | Безопасный рефакторинг с верификацией тестами на каждом шаге |
| `docs` | Edit | Пишет и обновляет документацию и комментарии |
| `security` | Read | Аудит безопасности: уязвимости, секреты, паттерны |
| `migrate` | Full | Обновления фреймворков и миграции зависимостей |
| `perf` | Full | Анализ производительности и оптимизация |

Также есть два встроенных субагента для делегирования: `@general` для сложных многошаговых задач и `@explore` для быстрого исследования кодовой базы только для чтения. Собственных агентов можно определять в виде Markdown-файлов или сгенерировать через `bolt agent create`.

## Распространённые команды, которые стоит попробовать далее

```bash
# Ревью staged-изменений с кодом выхода pass/fail
bolt review --staged

# Сгенерировать сообщение коммита для staged-изменений
bolt commit

# Список сессий и управление ими
bolt session list

# Просмотр статистики использования токенов и стоимости
bolt stats

# Запрос к локальной базе данных сессий
bolt db
```

<Tip>
  Передайте `--mini` в `bolt` или `bolt attach` для компактного UI, занимающего меньше места в терминале — отлично подходит для маленьких окон или разделённых панелей.

  ```bash
  bolt --mini
  bolt attach --mini <url>
  ```
</Tip>

<Warning>
  `bolt run` принимает флаги `--auto`, `--yolo` и `--dangerously-skip-permissions`, которые автоматически одобряют все запросы разрешений. Используйте их только в доверенных окружениях — они позволяют агенту читать, писать и выполнять без подтверждения.

  ```bash
  bolt run --auto "refactor this module"
  bolt run --yolo "refactor this module"
  bolt run --dangerously-skip-permissions "refactor this module"
  ```
</Warning>

<Note>
  Bolt поддерживает автодополнение shell для bash, zsh, fish и других оболочек. Сгенерируйте и установите автодополнения через:

  ```bash
  bolt completion
  ```

  Следуйте выведенным инструкциям, чтобы подключить скрипт автодополнения в конфиге вашей оболочки.
</Note>
