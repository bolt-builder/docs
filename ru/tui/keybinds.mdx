TUI Bolt спроектирован так, чтобы полностью управляться с клавиатуры. Эта страница перечисляет сочетания, к которым вы будете обращаться чаще всего. Полный список — запустите `bolt` и откройте встроенную справку.

## Основные

| Клавиши | Действие |
| --- | --- |
| `Tab` | Перейти к следующему агенту (`code`, `plan`, `ask`, ...). Текущий агент показан в строке состояния. |
| `Shift+Tab` | Перейти к предыдущему агенту. |
| `Enter` | Отправить текущее сообщение. |
| `Esc` | Отменить текущий ход. |
| `Ctrl+C` | Прервать текущий вызов инструмента. |
| `Ctrl+D` | Отсоединиться от сессии (она продолжает работать на сервере). |

## Режимы

### Режим `--mini`

Запустите Bolt с компактным макетом с разделённым подвалом, занимающим меньше места, отлично подходит для разделённых панелей:

```bash
bolt --mini
bolt attach --mini <url>
```

### Push-to-talk (голосовой ввод)

Удерживайте настроенную клавишу push-to-talk для диктовки промпта с помощью speech-to-text, отпустите для отправки. Настройте клавишу и STT-провайдера в `.bolt/bolt.jsonc`.
