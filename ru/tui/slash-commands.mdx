Слэш-команды вводятся в промпт TUI и меняют поведение текущей сессии. Они ничего не отправляют модели; они выполняются локально против самого Bolt.

## Справочник

| Команда | Что делает |
| --- | --- |
| `/memory` | Показать статус памяти проекта для этой сессии. |
| \`/memory use on | off\` | Читает ли эта сессия из [памяти проекта](/concepts/project-memory). |
| \`/memory contribute on | off\` | Записывает ли эта сессия обратно в память проекта в конце хода. |
| `/plan` | Переключить текущую сессию в режим планирования (только чтение, формирует план). |
| `/todos` | Показать текущий структурированный список задач агента. |
| `/btw` | Добавить внеочередное замечание («кстати...»), которое агент увидит на следующем ходу без вызова полного ответа. |

<Tip>
  Слэш-команды действуют в рамках сессии. Чтобы сделать предпочтение постоянным, задайте его в `.bolt/bolt.jsonc`. См. [Конфигурацию](/concepts/configuration).
</Tip>

## Добавление собственных

Пользовательские слэш-команды могут поставляться [плагинами](/extending/plugins) и файлами в `.opencode/command/`. Каждая команда — Markdown-файл, чей frontmatter описывает триггер и поведение.
