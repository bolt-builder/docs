Bolt pone un equipo completo de ingeniería de IA directamente en tu terminal. Se distribuye como una TUI rápida y controlada por teclado y como una app de escritorio nativa, ambas respaldadas por el mismo motor: diez agentes especializados, sesiones persistentes duraderas, gestión de servidores MCP con OAuth, un sistema de plugins y soporte para todos los principales proveedores de LLM.

## Qué hace Bolt

Bolt lee tu base de código, entiende qué estás construyendo y entrega código contigo — en la terminal o como app de escritorio. Cada sesión es duradera: puedes desconectarte, volver a conectarte desde otra máquina, bifurcar una rama de la conversación, compartir un enlace o exportar una transcripción saneada.

## Ponte en marcha

<Steps>
  <Step title="Instala Bolt">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash
    ```
    O instálalo con npm: `npm i -g @bolt-builder/bolt-cli`
  </Step>
  <Step title="Abre tu proyecto">
    Ve a cualquier directorio de proyecto y lanza la TUI:
    ```bash
    cd my-project
    bolt
    ```
  </Step>
  <Step title="Configura un proveedor">
    En el primer arranque, Bolt te pedirá que añadas un proveedor de LLM. También puedes ejecutar:
    ```bash
    bolt providers
    ```
  </Step>
  <Step title="Empieza a programar con IA">
    Escribe tu prompt en el pie de página de la TUI, pulsa Enter y deja que los agentes de Bolt se pongan a trabajar. Cambia de agente con `Tab`.
  </Step>
</Steps>

<Tip>
  Usa `bolt run "explain this codebase"` para obtener una respuesta rápida no interactiva sin abrir la TUI completa.
</Tip>
