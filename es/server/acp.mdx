Bolt implementa el Agent Client Protocol (ACP), que es como los editores como Zed se comunican con agentes de IA. Una vez configurado, el editor lanza `bolt acp` como subproceso y lo controla directamente — obtienes los agentes, herramientas, sesiones y stack de proveedores de Bolt sin salir de tu editor.

## Habilitar ACP

En los ajustes de IA de tu editor, añade Bolt como agente compatible con ACP y apúntalo a:

```bash
bolt acp
```

El editor gestionará el ciclo de vida del proceso. Configura proveedores, modelos y servidores MCP como lo harías normalmente en `.bolt/bolt.jsonc` — aquí también se aplican.

## Qué obtienes

- Cada agente de Bolt, invocable desde el panel de IA del editor.
- Sesiones compartidas con la TUI y la interfaz web (a través de la base de datos local).
- El mismo conjunto de herramientas, modelo de permisos y memoria de proyecto que cualquier otro punto de entrada de Bolt.
