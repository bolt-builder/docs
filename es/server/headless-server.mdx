`bolt serve` ejecuta un servidor de Bolt headless que expone el motor completo por HTTP: sesiones, agentes, herramientas, acceso a proveedores, MCP y eventos en streaming. Todo lo que Bolt puede hacer de forma interactiva, puede hacerlo por la API.

## Iniciar un servidor

```bash
bolt serve                              # localhost only, random port
bolt serve --hostname 0.0.0.0 --port 4096
bolt serve --mdns                       # advertise on the local network
```

<Warning>
  Enlazar a `0.0.0.0` expone Bolt en tu red. Siempre define `BOLT_SERVER_USERNAME` y `BOLT_SERVER_PASSWORD` antes de hacerlo.
</Warning>

## Conectar una TUI

Desde cualquier máquina que pueda llegar al servidor:

```bash
bolt attach http://server:4096
bolt attach --mini http://server:4096
```

O ejecuta un prompt de una sola vez contra un servidor remoto:

```bash
bolt run --attach http://server:4096 --dir /projects/api "what tests are failing?"
```

## Autenticación básica

Define credenciales por variables de entorno (consulta [Variables de entorno](/reference/environment-variables)):

```bash
export BOLT_SERVER_USERNAME=teamname
export BOLT_SERVER_PASSWORD=$(openssl rand -hex 24)
bolt serve --hostname 0.0.0.0 --port 4096
```

Todos los clientes deben enviar credenciales coincidentes.
