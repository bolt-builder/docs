Bolt đặt trọn cả một đội kỹ sư AI ngay trong terminal của bạn. Nó được cung cấp dưới dạng một TUI nhanh, điều khiển bằng bàn phím và một ứng dụng desktop gốc, cả hai đều được hậu thuẫn bởi cùng một engine: mười agent chuyên biệt, các phiên bền vững lâu dài, quản lý MCP server với OAuth, hệ thống plugin và hỗ trợ mọi nhà cung cấp LLM lớn.

## Bolt làm gì

Bolt đọc codebase của bạn, hiểu bạn đang xây dựng gì và ship code cùng bạn—trong terminal hoặc dưới dạng ứng dụng desktop. Mỗi phiên đều bền vững: tách ra, gắn lại từ máy khác, fork một nhánh của hội thoại, chia sẻ một liên kết, hoặc xuất một transcript đã được làm sạch.

## Bắt đầu và chạy

<Steps>
  <Step title="Cài đặt Bolt">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash
    ```
    Hoặc cài đặt qua npm: `npm i -g @bolt-builder/bolt-cli`
  </Step>
  <Step title="Mở dự án của bạn">
    Điều hướng tới bất kỳ thư mục dự án nào và khởi chạy TUI:
    ```bash
    cd my-project
    bolt
    ```
  </Step>
  <Step title="Cấu hình một provider">
    Ở lần khởi chạy đầu tiên Bolt yêu cầu bạn thêm một provider LLM. Bạn cũng có thể chạy:
    ```bash
    bolt providers
    ```
  </Step>
  <Step title="Bắt đầu lập trình với AI">
    Nhập prompt của bạn ở chân TUI, nhấn Enter và để các agent của Bolt bắt tay vào việc. Chuyển agent bằng `Tab`.
  </Step>
</Steps>

<Tip>
  Dùng `bolt run "giải thích codebase này"` để có câu trả lời nhanh không tương tác mà không cần mở TUI đầy đủ.
</Tip>
