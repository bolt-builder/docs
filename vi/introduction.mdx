Bolt là một agent lập trình AI ưu tiên terminal được xây dựng trên [Effect](https://effect.website), [OpenTUI](https://github.com/opentui/opentui) và [SolidJS](https://www.solidjs.com). Trỏ nó vào bất kỳ dự án nào và nó tự động lấy ngữ cảnh: nó khám phá code của bạn, tuân theo quy ước của bạn, thực thi lệnh shell, chỉnh sửa tệp, chạy test và ship các thay đổi.

Mười agent tích hợp sẵn (`code`, `plan`, `ask`, `code-review`, `debug`, `refactor`, `docs`, `security`, `migrate`, `perf`) cộng với các subagent `@general` và `@explore` bao phủ toàn bộ vòng lặp kỹ thuật. Các phiên là bền vững: tách, gắn lại (kể cả tới một server từ xa), fork, chia sẻ, xuất và nhập bất kỳ lúc nào. Bộ nhớ dự án lưu giữ những gì agent học được giữa các phiên. Có thể mở rộng qua MCP server (với OAuth), plugin, agent tùy chỉnh và công cụ tùy chỉnh.

Bolt là mã nguồn mở dưới giấy phép PolyForm Noncommercial 1.0.0.

## Vì sao chọn Bolt?

Bolt được thiết kế xoay quanh cách mà các nhà phát triển thực sự làm việc: trong terminal, qua nhiều phiên, trên các codebase thực. Đây là những gì tạo nên sự khác biệt:

- **TUI ưu tiên terminal.** Một giao diện nhanh, điều khiển bằng bàn phím được xây bằng [Effect](https://effect.website), [OpenTUI](https://github.com/opentui/opentui) và [SolidJS](https://www.solidjs.com). Nó có cảm giác gốc vì nó là gốc.
- **Cả một đội agent.** Mười agent chuyên biệt — `code`, `plan`, `ask`, `code-review`, `debug`, `refactor`, `docs`, `security`, `migrate` và `perf` — cộng với các subagent cho nghiên cứu và ủy thác nhiều bước. Chuyển giữa chúng bằng `Tab`.
- **Các phiên bạn có thể rời và tham gia lại.** Tách khỏi phiên và gắn lại sau, kể cả trên server từ xa. Fork, chia sẻ, xuất và nhập công việc bất kỳ lúc nào. Phiên được lưu trong SQLite và hoàn toàn có thể kiểm tra được với `bolt db`.
- **Mở rộng theo thiết kế.** MCP server với hỗ trợ OAuth đầy đủ, hệ thống plugin, tích hợp GitHub, server API tích hợp sẵn và giao diện web.
- **Ứng dụng desktop.** Cùng một engine được đóng gói trong trải nghiệm desktop đa cửa sổ, đa tab — với terminal tích hợp, cây tệp, command palette, 28 ngôn ngữ giao diện và tự động cập nhật.

## Agent tích hợp sẵn

Bolt được trang bị sẵn mười agent chuyên biệt. Mỗi agent có mức truy cập hệ thống tệp được xác định để phù hợp với mục đích của nó.

| Agent | Truy cập | Mô tả |
| --- | --- | --- |
| `code` | Full | Mặc định: đọc, ghi và chạy code |
| `plan` | Read | Khám phá codebase và tạo ra kế hoạch mà không thay đổi tệp |
| `ask` | Read | Câu hỏi và nghiên cứu — không chỉnh sửa tệp |
| `code-review` | Read | Review các thay đổi về tính đúng đắn, phong cách và bảo mật |
| `debug` | Full | Gỡ lỗi các test thất bại, crash và lỗi logic |
| `refactor` | Full | Refactor an toàn với xác minh test ở mỗi bước |
| `docs` | Edit | Viết và cập nhật tài liệu và bình luận |
| `security` | Read | Kiểm toán bảo mật: lỗ hổng, bí mật, các mẫu |
| `migrate` | Full | Nâng cấp framework và di chuyển dependency |
| `perf` | Full | Phân tích và tối ưu hóa hiệu năng |

Bạn cũng có thể định nghĩa agent của riêng mình dưới dạng tệp Markdown hoặc tạo một cái với `bolt agent create`.

## Ứng dụng desktop

Bolt cũng có sẵn dưới dạng ứng dụng desktop độc lập với quản lý phiên đa cửa sổ và đa tab, prompt composer với hỗ trợ tệp đính kèm và dán ảnh từ clipboard, terminal tích hợp và cây tệp, command palette, cài đặt đầy đủ cho phím tắt, mô hình, provider và server, thông báo gốc, deep link, tích hợp WSL trên Windows và tự động cập nhật qua các kênh dev, beta và production.

Tải ứng dụng desktop từ [trang releases](https://github.com/Bolt-builder/bolt-cli/releases), hoặc cài đặt bằng một dòng lệnh trên macOS mà không cần đi vòng qua Gatekeeper:

```bash
curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install-desktop | bash
```
