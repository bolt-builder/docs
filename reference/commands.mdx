Bolt exposes a single `bolt` binary with 86 subcommands. Running `bolt` with no arguments opens the terminal UI. This page is generated from the CLI's own `--help` output, so it always matches the released binary. Use `bolt <command> --help` for the same text inline.

Global flags available on every command: `--print-logs`, `--log-level`, `--pure`, `--profile <name>`, `--quiet`, `--verbose`, `--offline`, `--help`, `--version`.

Stable exit codes for scripting: `0` success, `1` failure or FAIL verdict, `2` no verdict determined, `3` budget hit, `4` auth error, `5` timeout, `6` plan gate found destructive actions.
