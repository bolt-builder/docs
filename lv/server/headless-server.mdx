`bolt serve` palaiž bezgalvas Bolt serveri, kas atklāj pilnu dzinēju caur HTTP: sesijas, aģentus, rīkus, sniedzēju piekļuvi, MCP un straumēšanas notikumus. Visu, ko Bolt var darīt interaktīvi, tas var darīt caur API.

## Palaidiet serveri

```bash
bolt serve                              # tikai localhost, nejaušs ports
bolt serve --hostname 0.0.0.0 --port 4096
bolt serve --mdns                       # reklamēt lokālajā tīklā
```

<Warning>
  Saistīšana ar `0.0.0.0` atklāj Bolt jūsu tīklā. Vienmēr iestatiet `BOLT_SERVER_USERNAME` un `BOLT_SERVER_PASSWORD` pirms tā darīšanas.
</Warning>

## Pievienojiet TUI

No jebkuras iekārtas, kas var sasniegt serveri:

```bash
bolt attach http://server:4096
bolt attach --mini http://server:4096
```

Vai palaidiet vienreizēju uzvedni pret attālinātu serveri:

```bash
bolt run --attach http://server:4096 --dir /projects/api "what tests are failing?"
```

## Basic auth

Iestatiet akreditācijas datus caur vides mainīgajiem (skatiet [Vides mainīgie](/reference/environment-variables)):

```bash
export BOLT_SERVER_USERNAME=teamname
export BOLT_SERVER_PASSWORD=$(openssl rand -hex 24)
bolt serve --hostname 0.0.0.0 --port 4096
```

Visiem klientiem ir jānosūta atbilstoši akreditācijas dati.
