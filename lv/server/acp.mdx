Bolt īsteno Agent Client Protocol (ACP), kas ir veids, kā redaktori, piemēram, Zed, runā ar MI aģentiem. Konfigurēts, redaktors palaiž `bolt acp` kā apakšprocesu un vada to tieši — jūs iegūstat Bolt aģentus, rīkus, sesijas un sniedzēju steku, neatstājot redaktoru.

## Iespējot ACP

Redaktora MI iestatījumos pievienojiet Bolt kā ACP saderīgu aģentu un norādiet to uz:

```bash
bolt acp
```

Redaktors pārvaldīs procesa dzīves ciklu. Konfigurējiet sniedzējus, modeļus un MCP serverus, kā parasti darāt failā `.bolt/bolt.jsonc` — tie attiecas arī šeit.

## Ko iegūstat

- Katru Bolt aģentu, izsaucamu no redaktora MI paneļa.
- Koplietotās sesijas ar TUI un tīmekļa UI (caur lokālo datubāzi).
- Tā pati rīku kopa, atļauju modelis un projekta atmiņa kā jebkurā citā Bolt ieejas punktā.
