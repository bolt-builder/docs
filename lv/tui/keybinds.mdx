Bolt TUI ir izstrādāts tā, lai to no gala līdz galam vadītu no tastatūras. Šajā lapā ir uzskaitīti īsceļi, pēc kuriem sniegsieties visbiežāk. Pilnīgu sarakstu iegūt, palaidiet `bolt` un atveriet lietotnes iekšējo palīdzību.

## Būtiskais

| Taustiņi | Darbība |
| --- | --- |
| `Tab` | Pārvietoties uz nākamo aģentu (`code`, `plan`, `ask`, ...). Pašreizējais aģents tiek parādīts statusa joslā. |
| `Shift+Tab` | Pārvietoties uz iepriekšējo aģentu. |
| `Enter` | Nosūtīt pašreizējo ziņu. |
| `Esc` | Atcelt izpildē esošo kārtu. |
| `Ctrl+C` | Pārtraukt pašreizējo rīka izsaukumu. |
| `Ctrl+D` | Atvienoties no sesijas (atstāj to darboties serverī). |

## Režīmi

### `--mini` režīms

Sāciet Bolt ar kompaktu sadalītas kājenes izkārtojumu, kas aizņem mazāk termināļa vietas, lieliski piemērots sadalītiem paneļiem:

```bash
bolt --mini
bolt attach --mini <url>
```

### Push-to-talk balss

Turiet konfigurēto push-to-talk taustiņu, lai diktētu uzvedni, izmantojot runas atpazīšanu, pēc tam atlaidiet, lai nosūtītu. Konfigurējiet taustiņu un STT sniedzēju failā `.bolt/bolt.jsonc`.
