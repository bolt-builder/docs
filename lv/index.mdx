## Ko Bolt dara

Bolt lasa jūsu koda bāzi, saprot, ko jūs veidojat, un piegādā kodu kopā ar jums — terminālī vai kā darbvirsmas lietotni. Katra sesija ir noturīga: atvienojieties, pievienojieties no citas iekārtas, dakšojiet sarunas atzaru, dalieties ar saiti vai eksportējiet notīrītu norakstu.

## Sāciet darbu

<Steps>
  <Step title="Instalējiet Bolt">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash
    ```
    Vai instalējiet ar npm: `npm i -g @bolt-builder/bolt-cli`
  </Step>
  <Step title="Atveriet savu projektu">
    Dodieties uz jebkuru projekta direktoriju un palaidiet TUI:
    ```bash
    cd my-project
    bolt
    ```
  </Step>
  <Step title="Konfigurējiet sniedzēju">
    Pirmajā palaišanas reizē Bolt jums lūgs pievienot LLM sniedzēju. Jūs varat arī palaist:
    ```bash
    bolt providers
    ```
  </Step>
  <Step title="Sāciet kodēt ar MI">
    Ierakstiet savu uzvedni TUI kājenē, nospiediet Enter un ļaujiet Bolt aģentiem strādāt. Pārslēdziet aģentus ar `Tab`.
  </Step>
</Steps>

<Tip>
  Izmantojiet `bolt run "explain this codebase"`, lai iegūtu ātru, neinteraktīvu atbildi, neatverot pilnu TUI.
</Tip>
