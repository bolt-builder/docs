Bolt stellt Ihnen ein komplettes KI-Entwicklerteam direkt ins Terminal. Es kommt als schnelles, tastaturgesteuertes TUI und als native Desktop-App, beide von derselben Engine angetrieben: zehn spezialisierte Agents, persistente und dauerhafte Sessions, MCP-Serververwaltung mit OAuth, ein Plugin-System und Unterstützung für jeden großen LLM-Provider.

## Was Bolt kann

Bolt liest Ihre Codebasis, versteht, woran Sie arbeiten, und liefert Code mit Ihnen aus – im Terminal oder als Desktop-App. Jede Session ist dauerhaft: trennen, von einem anderen Rechner erneut verbinden, einen Fork des Gesprächs erstellen, einen Link teilen oder ein bereinigtes Transkript exportieren.

## In wenigen Schritten startklar

<Steps>
  <Step title="Bolt installieren">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash
    ```
    Oder per npm installieren: `npm i -g @bolt-builder/bolt-cli`
  </Step>
  <Step title="Projekt öffnen">
    Navigieren Sie in ein beliebiges Projektverzeichnis und starten Sie das TUI:
    ```bash
    cd my-project
    bolt
    ```
  </Step>
  <Step title="Einen Provider konfigurieren">
    Beim ersten Start fordert Bolt Sie auf, einen LLM-Provider hinzuzufügen. Sie können auch ausführen:
    ```bash
    bolt providers
    ```
  </Step>
  <Step title="Mit KI zu coden beginnen">
    Tippen Sie Ihren Prompt in die Fußzeile des TUI, drücken Sie Enter und lassen Sie die Agents von Bolt arbeiten. Wechseln Sie Agents mit `Tab`.
  </Step>
</Steps>

<Tip>
  Verwenden Sie `bolt run "explain this codebase"` für eine schnelle, nicht-interaktive Antwort, ohne das komplette TUI zu öffnen.
</Tip>
