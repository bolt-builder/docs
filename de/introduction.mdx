Bolt ist ein terminal-first KI-Coding-Agent, der auf [Effect](https://effect.website), [OpenTUI](https://github.com/opentui/opentui) und [SolidJS](https://www.solidjs.com) aufbaut. Zeigen Sie damit auf ein beliebiges Projekt, und Bolt nimmt automatisch Kontext auf: Es erkundet Ihren Code, folgt Ihren Konventionen, führt Shell-Befehle aus, bearbeitet Dateien, führt Tests aus und liefert Änderungen aus.

Zehn integrierte Agents (`code`, `plan`, `ask`, `code-review`, `debug`, `refactor`, `docs`, `security`, `migrate`, `perf`) plus die Subagents `@general` und `@explore` decken den gesamten Engineering-Loop ab. Sessions sind dauerhaft: trennen, wieder verbinden (auch mit einem Remote-Server), forken, teilen, exportieren und importieren – jederzeit. Project Memory speichert, was der Agent zwischen Sessions gelernt hat. Erweiterbar über MCP-Server (mit OAuth), Plugins, benutzerdefinierte Agents und benutzerdefinierte Tools.

Bolt ist Open Source unter der PolyForm Noncommercial 1.0.0-Lizenz.

## Warum Bolt?

Bolt ist rund um die Art gestaltet, wie Entwickler tatsächlich arbeiten: im Terminal, über mehrere Sessions hinweg, an echten Codebasen. Das zeichnet Bolt aus:

- **Terminal-first TUI.** Eine schnelle, tastaturgesteuerte Oberfläche, gebaut mit [Effect](https://effect.website), [OpenTUI](https://github.com/opentui/opentui) und [SolidJS](https://www.solidjs.com). Es fühlt sich nativ an, weil es das auch ist.
- **Ein ganzes Team von Agents.** Zehn spezialisierte Agents – `code`, `plan`, `ask`, `code-review`, `debug`, `refactor`, `docs`, `security`, `migrate` und `perf` – plus Subagents für Recherche und mehrstufige Delegation. Wechseln Sie mit `Tab`.
- **Sessions, die Sie verlassen und wieder aufnehmen können.** Trennen Sie sich von einer Session und verbinden Sie sich später wieder, auch mit einem Remote-Server. Forken, teilen, exportieren und importieren Sie Arbeit jederzeit. Sessions werden in SQLite gespeichert und sind mit `bolt db` vollständig inspizierbar.
- **Erweiterbar von Grund auf.** MCP-Server mit vollständiger OAuth-Unterstützung, ein Plugin-System, GitHub-Integration, ein integrierter API-Server und eine Web-UI.
- **Desktop-App.** Dieselbe Engine, verpackt in ein Mehrfenster- und Mehr-Tab-Desktop-Erlebnis – mit integriertem Terminal, Dateibaum, Befehlspalette, 28 UI-Sprachen und Auto-Updates.

## Integrierte Agents

Bolt bringt zehn spezialisierte Agents mit. Jeder Agent verfügt über eine definierte Zugriffsebene auf das Dateisystem, passend zu seinem Zweck.

| Agent | Zugriff | Beschreibung |
| --- | --- | --- |
| `code` | Full | Standard: liest, schreibt und führt Code aus |
| `plan` | Read | Erkundet die Codebasis und erstellt einen Plan, ohne Dateien zu ändern |
| `ask` | Read | Fragen und Recherche – keine Dateibearbeitungen |
| `code-review` | Read | Überprüft Änderungen auf Korrektheit, Stil und Sicherheit |
| `debug` | Full | Debuggt fehlschlagende Tests, Abstürze und Logikfehler |
| `refactor` | Full | Sicheres Refactoring mit Testverifizierung bei jedem Schritt |
| `docs` | Edit | Schreibt und aktualisiert Dokumentation und Kommentare |
| `security` | Read | Sicherheitsaudit: Schwachstellen, Secrets, Muster |
| `migrate` | Full | Framework-Upgrades und Abhängigkeitsmigrationen |
| `perf` | Full | Performance-Analyse und -Optimierung |

Sie können auch eigene Agents als Markdown-Dateien definieren oder mit `bolt agent create` einen generieren lassen.

## Desktop-App

Bolt kommt außerdem als eigenständige Desktop-App mit Mehrfenster- und Mehr-Tab-Sitzungsverwaltung, einem Prompt-Composer mit Unterstützung für Anhänge und Einfügen von Bildern aus der Zwischenablage, integriertem Terminal und Dateibaum, einer Befehlspalette, vollständigen Einstellungen für Tastaturkürzel, Modelle, Provider und Server, nativen Benachrichtigungen, Deep Links, WSL-Integration unter Windows und Auto-Updates über die Kanäle Dev, Beta und Produktion.

Laden Sie die Desktop-App von der [Releases-Seite](https://github.com/Bolt-builder/bolt-cli/releases) herunter oder installieren Sie sie unter macOS in einer Zeile ohne Gatekeeper-Umweg:

```bash
curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install-desktop | bash
```
