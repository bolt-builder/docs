Die Desktop-App aktualisiert sich im Hintergrund über drei Release-Kanäle:

| Kanal | Kadenz | Für wen |
| --- | --- | --- |
| `prod` | Nur stabile Releases. | Standardmäßig für alle. |
| `beta` | Release Candidates. | Teams, die eine Vorschau auf das nächste Stable-Release möchten. |
| `dev` | Etwa nightly. | Early Adopters und Contributors. |

## Kanäle wechseln

Wechseln Sie den Kanal im Einstellungsbereich der App. Beim nächsten Start prüft die App den gewählten Kanal auf einen neueren Build; Sie können auch eine manuelle Prüfung anstoßen.

## Unter der Haube

Updates werden im Hintergrund heruntergeladen und beim nächsten Start angewendet. Schlägt das Anwenden eines Updates fehl, behält die App die vorherige Version und zeigt einen Fehler – es gibt keinen Zwischenzustand.
