Bolt は、Zed のようなエディタが AI エージェントと通信する方法である Agent Client Protocol (ACP) を実装しています。設定すると、エディタはサブプロセスとして `bolt acp` を生成し、直接駆動します — エディタを離れることなく、Bolt のエージェント、ツール、セッション、プロバイダスタックを利用できます。

## ACP を有効化する

エディタの AI 設定で、Bolt を ACP 互換エージェントとして追加し、次を指すようにします。

```bash
bolt acp
```

エディタがプロセスライフサイクルを管理します。通常通り `.bolt/bolt.jsonc` でプロバイダ、モデル、MCP サーバを設定してください — ここでも適用されます。

## 得られるもの

- エディタの AI パネルから呼び出せるすべての Bolt エージェント。
- (ローカルデータベースを介して) TUI と Web UI と共有されるセッション。
- 他の Bolt エントリポイントと同じツールセット、権限モデル、プロジェクトメモリ。
