Bolt には組み込みの HTTP サーバがあり、エンジンとインターフェイスを完全に切り離します。強力なリモートマシン (クラウド VM、開発コンテナ、夜通し稼働させたデスクトップ) 上でヘッドレスサーバを起動し、ノート PC、別のターミナル、あるいはブラウザから TUI をアタッチできます — すべて同じライブセッションを指しています。これにより Bolt はチーム、リモートワークロード、そしてマシンに SSH で入らずに様子を確認したい長時間実行タスクに適したものになります。

---

## `bolt serve`

完全な API を HTTP 上で公開し、TUI 接続を受け付けるヘッドレスの Bolt サーバを起動します。

```bash
bolt serve
```

### フラグ

| フラグ | デフォルト | 説明 |
|------|---------|-------------|
| `--hostname <host>` | `127.0.0.1` | バインドするホスト名または IP アドレス |
| `--port <n>` | `0` (auto) | リッスンするポート。Bolt は起動時に割り当てられたポートを表示します |
| `--mdns` | `false` | ゼロコンフィグのローカルネットワーク検出用に mDNS でサーバをアドバタイズします。ホスト名も `0.0.0.0` に設定されます |
| `--mdns-domain <name>` | `opencode.local` | カスタム mDNS サービスドメイン |
| `--cors <origin>` | `[]` | CORS 経由で許可する追加のオリジン (繰り返し指定可) |

<Warning>
  `OPENCODE_SERVER_PASSWORD` が設定されていない場合、Bolt は警告を表示し、サーバに到達できる誰にでも完全にオープンな状態になります。`127.0.0.1` 以外のインターフェイスにバインドする前に、必ずパスワードを設定してください。
</Warning>

### 認証

環境変数を使って HTTP Basic 認証でサーバを保護します。

| 変数 | 説明 |
|----------|-------------|
| `OPENCODE_SERVER_PASSWORD` | Basic 認証のパスワード |
| `OPENCODE_SERVER_USERNAME` | Basic 認証のユーザ名 (省略時は `opencode` にフォールバック) |

```bash
OPENCODE_SERVER_PASSWORD=my-secret bolt serve --hostname 0.0.0.0 --port 4096
```

## `bolt attach <url>`

実行中の Bolt サーバに完全な TUI をアタッチします。HTTP 経由で到達できる任意のサーバ — ローカルでもリモートでも — に対して動作します。

```bash
bolt attach http://my-dev-machine.local:4096
```

### フラグ

| フラグ | エイリアス | 説明 |
|------|-------|-------------|
| `--dir <path>` | | リモートサーバ上で実行するディレクトリ |
| `--continue` | `-c` | サーバ上の直近のセッションを継続 |
| `--session <id>` | `-s` | 継続するセッション ID |
| `--fork` | | 継続時にセッションをフォーク (`--continue` または `--session` と併用) |
| `--password <pw>` | `-p` | Basic 認証パスワード (`OPENCODE_SERVER_PASSWORD` を上書き) |
| `--username <user>` | `-u` | Basic 認証ユーザ名 (`OPENCODE_SERVER_USERNAME` を上書き) |
| `--mini` | | 完全な TUI の代わりに最小限の対話 UI を使用 |

```bash
# リモートサーバ上の直近のセッションを継続する
bolt attach http://10.0.0.5:4096 --continue --password my-secret

# 特定のセッションをフォークする
bolt attach http://10.0.0.5:4096 --session ses_abc123 --fork

# 最小 UI — 制限されたターミナルで有用
bolt attach http://10.0.0.5:4096 --mini
```

## `bolt web`

Bolt サーバを起動し、既定のブラウザで即座に Web UI を開きます。ローカルでブラウザベースのインターフェイスを起動する最も速い方法です。

```bash
bolt web
```

`bolt web` は `bolt serve` と同じネットワークフラグを受け付けます。

## mDNS 検出

`bolt serve` に `--mdns` を渡すと、mDNS を使ってローカルネットワーク上にサーバのアドレスをブロードキャストします。同じネットワーク上の任意のマシンから、IP アドレスやポートを知らなくても mDNS ホスト名でアタッチできます。

```bash
# サーバマシン側
OPENCODE_SERVER_PASSWORD=my-secret bolt serve --mdns

# 同じ LAN 上の別のマシンから
bolt attach http://opencode.local --password my-secret
```

既定の mDNS ドメインは `opencode.local` です。`--mdns-domain` で上書きできます。

```bash
bolt serve --mdns --mdns-domain mydevbox.local
```

## サーバを起動してリモートからアタッチする

<Steps>
  <Step title="サーバマシンでパスワードを設定">
    サーバを起動する前に `OPENCODE_SERVER_PASSWORD` をエクスポートします。設定していない場合、Bolt は警告を表示し、API は未認証状態になります。

    ```bash
    export OPENCODE_SERVER_PASSWORD=my-secret
    ```
  </Step>

  <Step title="ヘッドレスサーバを起動">
    ノート PC から到達できるようすべてのインターフェイスにバインドし、任意で固定ポートを選択します。

    ```bash
    bolt serve --hostname 0.0.0.0 --port 4096
    # opencode server listening on http://0.0.0.0:4096
    ```

    このターミナルは開いたままにしておきます (または `tmux` / `screen` / systemd ユニットで実行します)。
  </Step>

  <Step title="ノート PC からアタッチ">
    サーバに到達できる任意のマシンで、次を実行します。

    ```bash
    bolt attach http://192.168.1.10:4096 --password my-secret
    ```

    完全な TUI が開き、リモートエンジンに接続します。セッション、履歴、ツールの状態はすべてサーバ上にあります。
  </Step>

  <Step title="後でセッションを継続">
    TUI を終了 (`q` または `Ctrl-C`) してデタッチします。セッションはサーバ上で動き続けます。再参加するには次を実行します。

    ```bash
    bolt attach http://192.168.1.10:4096 --continue --password my-secret
    ```

    または、元のセッションに影響を与えずに分岐するにはフォークします。

    ```bash
    bolt attach http://192.168.1.10:4096 --continue --fork --password my-secret
    ```
  </Step>
</Steps>

## リモートワークフローの例

よくあるパターンは、コア数の多い開発マシン上で Bolt サーバを稼働させたまま、シンなノート PC から接続することです。

```
┌──────────────────────────────────────────────────┐
│  Dev machine (powerful, stays on)                │
│                                                  │
│  $ OPENCODE_SERVER_PASSWORD=secret bolt serve \  │
│      --hostname 0.0.0.0 --port 4096              │
│                                                  │
│  opencode server listening on http://0.0.0.0:4096│
└──────────────────────────────────────────────────┘
               ↑  HTTP (LAN / VPN / SSH tunnel)
┌──────────────────────────────────────────────────┐
│  Laptop                                          │
│                                                  │
│  $ bolt attach http://dev-machine:4096 \         │
│      --password secret                           │
└──────────────────────────────────────────────────┘
```

すべてのセッションデータはサーバの SQLite データベースに保存されます。ノート PC は TUI をレンダリングするだけで、いつでも切断・再接続でき、作業を失うことはありません。
