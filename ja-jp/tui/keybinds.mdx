Bolt TUI は最初から最後までキーボードで操作できるように設計されています。このページでは、最もよく使うショートカットを紹介します。完全な一覧は、`bolt` を実行してアプリ内ヘルプを開いてください。

## 必須

| キー | アクション |
| --- | --- |
| `Tab` | 次のエージェント (`code`、`plan`、`ask`、...) に切り替えます。現在のエージェントはステータスバーに表示されます。 |
| `Shift+Tab` | 前のエージェントに切り替えます。 |
| `Enter` | 現在のメッセージを送信します。 |
| `Esc` | 実行中のターンをキャンセルします。 |
| `Ctrl+C` | 現在のツール呼び出しを中断します。 |
| `Ctrl+D` | セッションからデタッチします (サーバ上では実行を継続します)。 |

## モード

### `--mini` モード

ターミナルスペースを節約するコンパクトなスプリットフッタレイアウトで Bolt を起動します。分割ペインに最適です。

```bash
bolt --mini
bolt attach --mini <url>
```

### プッシュトゥトーク音声

設定したプッシュトゥトークキーを押し続けてスピーチトゥテキストでプロンプトを口述し、離すと送信されます。キーと STT プロバイダは `.bolt/bolt.jsonc` で設定します。
