Bolt のエージェントはツールを呼び出すことで作業を行います。TUI で見えるすべてのアクション (ファイルの読み込み、テストの実行、Web 検索) は、モデルがツールを選び Bolt がそれを実行しているものです。各エージェントには宣言されたアクセスレベルがあり、事前に確認を求めることなく呼び出せるツールが決まっています ([権限](/concepts/permissions) を参照)。

## 組み込みツール

| ツール | 内容 |
| --- | --- |
| `read` | ディスクからファイルを読み込みます。 |
| `write` | 新しいファイルを作成、または既存のファイルを上書きします。 |
| `edit` | ファイルにターゲット指定の編集 (検索/置換) を適用します。 |
| `apply_patch` | 統合 diff 形式のパッチを 1 つ以上のファイルにわたって適用します。 |
| `glob` | glob パターンに一致するファイルを一覧表示します。 |
| `grep` | 正規表現/テキストでファイル内容を検索します。 |
| `bash` | シェルコマンドを実行します。 |
| `task` | サブタスクをサブエージェント (`@general`、`@explore`、またはカスタムサブエージェント) に委譲します。 |
| `todowrite` | 複数ステップの作業のためにエージェントの構造化されたタスクリストを維持します。 |
| `webfetch` | URL をフェッチしてそのコンテンツを返します。 |
| `websearch` | Web を検索します。 |
| `skill` | 名前付きスキルを呼び出します ([スキル](/extending/skills) を参照)。 |
| `memory_save` | [プロジェクトメモリ](/concepts/project-memory) に事実を永続化します。 |
| `memory_recall` | 以前に保存されたメモリを検索します。 |
| `question` | 明確化のための質問を尋ね、返答を待ちます。 |
| `bash_background` | シェルコマンドを管理されたバックグラウンドプロセスとして開始します (開発サーバ、ウォッチャ、長時間ビルド)。 |
| `process_output` | バックグラウンドプロセスの累積出力とステータスを読み取り、必要に応じて完了を待ちます。 |
| `list_processes` | バックグラウンドプロセスを ID、ステータス、コマンドと共に一覧表示します。 |
| `kill_process` | ID でバックグラウンドプロセス (およびそのプロセスツリー) を終了します。 |
| `test_run` | プロジェクトのテストを検出して実行し、構造化された合否結果と失敗の詳細を返します。 |

### 実験的

| ツール | 内容 |
| --- | --- |
| `lsp` | 言語サーバに定義、参照、診断を問い合わせます。 |
| `execute` | コードモードの分離サンドボックスでコードを実行します。 |
| `plan` | 変更を行う前に構造化された計画を作成します。 |

実験的ツールはリリース間で変更されたり名称変更されたりする可能性があります。

## ツールセットの拡張

組み込みを超えて、Bolt は 3 つのソースからツールを呼び出せます。

- **カスタムツール** — プロジェクトルートの `.opencode/tool/` (または `.opencode/tools/`) に配置します。[カスタムツール](/extending/custom-tools) を参照してください。
- **プラグインツール** — インストールされた任意の [プラグイン](/extending/plugins) が提供するツール。
- **MCP ツール** — プロジェクト用に設定された任意の [MCP サーバ](/extending/mcp-servers) からのツール。

3 つとも、エージェントの視点からは同一に見えます。ツールリストに表示され、エージェントのアクセスレベルを尊重し、TUI のツール呼び出し出力に表示されます。
