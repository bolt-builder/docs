## Install from Flathub

The easiest way to get Bolt on your Linux-based operating system is to install it from [Flathub](https://flathub.org/apps/details/app.zen_browser.zen). You can also use app stores that supports Flatpak, like GNOME Software, KDE Discover, Cosmic Store and more.

<a href='https://flathub.org/apps/details/app.zen_browser.zen'><img width='196' alt='Download on Flathub' src='https://flathub.org/api/badge?locale=en'/></a>

Your profile for Flatpak version of Bolt will be available in `~/.var/app/app.zen_browser.zen/zen/`. You can go to `about:profiles` to check your profile name, then open the directory manually using your file manager app with the prefix path above.

## Install from Tarball Scripts

Bolt provides install scripts that will install the browser directly to your home directory. Run this command from your terminal:

```
curl -fsSL https://github.com/zen-browser/updates-server/raw/refs/heads/main/install.sh | $SHELL
```

Bolt will be installed in `~/.tarball-installations/zen`.

You can also use the script below to install Twilight version of Bolt, which built freshly every night and contained the latest changes. You can use Bolt Twilight to try new features, [catch bugs and report them](https://github.com/bolt-builder/bolt-browser/issues) before it arrived on regular Beta builds!

```
curl -fsSL https://github.com/zen-browser/updates-server/raw/refs/heads/main/install-twilight.sh | $SHELL
```

Bolt Twilight will be installed in `~/.tarball-installations/zen-twilight`.

Your profile for tarball version of Bolt and Bolt Twilight will be available in `~/.zen/`. Check `about:profiles` to see your profile name and access the directory directly.

## Download Directly

You can also download Bolt tarball and AppImage files directly, as well as formats for other OS in [latest Bolt Github Releases](https://github.com/bolt-builder/bolt-browser/releases/latest) page.
