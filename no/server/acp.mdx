Bolt implementerer Agent Client Protocol (ACP), som er hvordan editorer som Zed snakker med AI-agenter. Når den er konfigurert, oppretter editoren `bolt acp` som en underprosess og driver den direkte — du får Bolts agenter, verktøy, økter og leverandørstack uten å forlate editoren.

## Aktiver ACP

I editorens AI-innstillinger, legg til Bolt som en ACP-kompatibel agent og pek den mot:

```bash
bolt acp
```

Editoren vil håndtere prosessens livssyklus. Konfigurer leverandører, modeller og MCP-servere som du normalt ville i `.bolt/bolt.jsonc` — de gjelder her også.

## Hva du får

- Hver Bolt-agent, kallbar fra editorens AI-panel.
- Delte økter med TUI-en og web-grensesnittet (via den lokale databasen).
- Samme verktøysett, tillatelsesmodell og prosjektminne som ethvert annet Bolt-inngangspunkt.
