Bolt eksponerer en enkelt `bolt`-binærfil med et rikt sett av underkommandoer. Å kjøre `bolt` uten argumenter åpner det fulle terminalgrensesnittet. Alle andre underkommandoer er listet nedenfor. Bruk `bolt <command> --help` når som helst for inline-hjelp.

<Accordion title="bolt (standard — start TUI)">
  Åpner det interaktive terminalgrensesnittet i gjeldende mappe. Bolt oppdager automatisk prosjektkonteksten, laster konfigurasjon og kobler til eventuelle konfigurerte leverandører.

  ```bash
  bolt
  bolt --mini          # minimal split-footer interactive mode
  bolt --log-level DEBUG
  ```

  **Globale flagg** — tilgjengelig for hver kommando:

  | Flagg | Type | Beskrivelse |
  | --- | --- | --- |
  | `--print-logs` | boolean | Skriv loggutdata til stderr |
  | `--log-level` | `DEBUG`\|`INFO`\|`WARN`\|`ERROR` | Sett loggnivå |
  | `--pure` | boolean | Kjør uten å laste eksterne plugins |
  | `--help`, `-h` | boolean | Vis hjelpetekst |
  | `--version`, `-v` | boolean | Skriv ut installert versjonsnummer |
</Accordion>

<Accordion title="bolt run [prompt]">
  Kjør Bolt med én ledetekst i ikke-interaktiv modus. Bolt starter en in-process-server, sender ledeteksten til aktiv økt, strømmer svaret til stdout og avslutter. Pipe stdin eller send `--file` for å legge ved kontekst.

  ```bash
  # Basic non-interactive prompt
  bolt run "explain the auth module"
  
  # Continue the most recent session
  bolt run --continue "now add error handling"
  
  # Use a specific model with a specific agent
  bolt run --model anthropic/claude-opus-4-5 --agent code "refactor auth.ts"
  
  # Stream raw JSON events for tooling integration
  bolt run --format json "summarize changes"
  
  # Fire the same task at multiple models and keep the best result
  bolt run --best-of "anthropic/claude-opus-4-5,openai/gpt-4o" "write unit tests"
  
  # Attach a file as context
  bolt run --file ./openapi.yaml "generate a client SDK"
  
  # Attach to a remote server and run a prompt there
  bolt run --attach http://my-server:4096 --dir /projects/api "what tests are failing?"
  
  # Skip all permission prompts (dangerous)
  bolt run --auto "delete all TODO comments"
  ```

  | Flagg | Alias | Type | Beskrivelse |
  | --- | --- | --- | --- |
  | `--command` |  | string | Skråstrekkommando som skal utføres; send argumenter som meldingen |
  | `--continue` | `-c` | boolean | Fortsett den nyeste økten |
  | `--session` | `-s` | string | Økt-ID som skal fortsettes |
  | `--fork` |  | boolean | Forgren økten før du fortsetter (krever `--continue` eller `--session`) |
  | `--share` |  | boolean | Del økten etter at den er fullført |
  | `--model` | `-m` | string | Modell å bruke i `provider/model`-format |
  | `--best-of` |  | string | Kommaseparert `provider/model`-liste; kjører oppgaven parallelt, rangerer resultater, beholder vinneren |
  | `--agent` |  | string | Agent å bruke (f.eks. `code`, `ask`, `review`) |
  | `--format` |  | `default`\|`json` | Utdataformat; `json` strømmer rå linjeavdelte JSON-hendelser |
  | `--file` | `-f` | string\[\] | Fil(er) som skal legges ved som kontekst |
  | `--title` |  | string | Tittel for økten |
  | `--attach` |  | string | Kjør mot en ekstern Bolt-server (f.eks. `http://localhost:4096`) |
  | `--password` | `-p` | string | Basic auth-passord for den eksterne serveren |
  | `--username` | `-u` | string | Basic auth-brukernavn for den eksterne serveren |
  | `--dir` |  | string | Arbeidsmappe; hvis `--attach` er satt, er dette mappen på fjernserveren |
  | `--port` |  | number | Port for den lokale in-process-serveren (tilfeldig hvis utelatt) |
  | `--variant` |  | string | Nivå for resonneringsinnsats, leverandørspesifikk (f.eks. `high`, `max`, `minimal`) |
  | `--thinking` |  | boolean | Vis resonnerings-/tenkeblokker i utdataene |
  | `--mini` |  | boolean | Start det minimale split-footer interaktive grensesnittet (skjult) |
  | `--interactive` | `-i` | boolean | Tving direkte interaktiv split-footer-modus |
  | `--auto` |  | boolean | Auto-godkjenn tillatelser som ikke er eksplisitt avslått |
  | `--yolo` |  | boolean | Hopp over alle tillatelsesforespørsler (alias for `--auto`, skjult) |
  | `--dangerously-skip-permissions` |  | boolean | Hopp over alle tillatelsessjekker (skjult) |
  | `--demo` |  | boolean | Aktiver direkte interaktive demo-skråstrekkommandoer (skjult) |
</Accordion>

<Accordion title="bolt attach <url>">
  Koble den fulle TUI-en til en kjørende Bolt-server. Serveren kan være lokal eller ekstern. Send `--mini` for å bruke det minimale split-footer-grensesnittet i stedet for full TUI.

  ```bash
  bolt attach http://localhost:4096
  bolt attach http://remote-host:4096 --dir /projects/api
  bolt attach http://remote-host:4096 --session abc123 --mini
  bolt attach http://remote-host:4096 --password secret --username alice
  ```

  | Flagg | Alias | Type | Beskrivelse |
  | --- | --- | --- | --- |
  | `--dir` |  | string | Mappe på fjernserveren |
  | `--continue` | `-c` | boolean | Fortsett den nyeste økten på fjernserveren |
  | `--session` | `-s` | string | Økt-ID som skal fortsettes |
  | `--fork` |  | boolean | Forgren økten når du fortsetter |
  | `--password` | `-p` | string | Basic auth-passord |
  | `--username` | `-u` | string | Basic auth-brukernavn |
  | `--mini` |  | boolean | Bruk det minimale interaktive grensesnittet |
  | `--no-replay` |  | boolean | Deaktiver reprise av øktshistorikk ved gjenopptakelse og etter endring av størrelse (krever `--mini`) |
  | `--replay-limit` |  | number | Begrens synlig reprise til de nyeste N meldingene (krever `--mini`) |
</Accordion>

<Accordion title="bolt serve">
  Start en headless Bolt API-server. Serveren eksponerer et REST\+SSE-API som TUI-en, `bolt run --attach` og `bolt attach` kan koble til. Bind til `0.0.0.0` for å gjøre den tilgjengelig fra andre maskiner — sett alltid `BOLT_SERVER_PASSWORD` når du gjør dette.

  ```bash
  bolt serve
  bolt serve --hostname 0.0.0.0 --port 4096
  bolt serve --mdns
  ```

  | Flagg | Type | Beskrivelse |
  | --- | --- | --- |
  | `--hostname` | string | Adresse å binde til (standard: `127.0.0.1`) |
  | `--port` | number | Port å lytte på (tilfeldig hvis utelatt) |
  | `--mdns` | boolean | Aktiver mDNS-tjenesteoppdagelse (setter hostname til `0.0.0.0`) |
  | `--mdns-domain` | string | Egendefinert domenenavn for mDNS-tjeneste (standard: `opencode.local`) |
  | `--cors` | string\[\] | Ytterligere domener å tillate for CORS |

  <Warning>
    `BOLT_SERVER_PASSWORD` er ikke satt som standard. Serveren vil logge en advarsel og godta alle tilkoblinger til du setter det.
  </Warning>
</Accordion>

<Accordion title="bolt session">
  Håndter Bolt-økter lagret i den lokale SQLite-databasen.

  **Underkommandoer**

  ```bash
  bolt session list                         # list all root sessions
  bolt session list --format json           # machine-readable output
  bolt session list -n 20                   # show 20 most recent sessions
  bolt session delete <sessionID>           # permanently delete a session
  ```

  **Flagg for `bolt session list`**

  | Flagg | Alias | Type | Beskrivelse |
  | --- | --- | --- | --- |
  | `--max-count` | `-n` | number | Begrens utdata til de N nyeste øktene |
  | `--format` |  | `table`\|`json` | Utdataformat (standard: `table`) |
</Accordion>

<Accordion title="bolt agent">
  List og opprett egendefinerte agenter. Agenter er markdown-filer med YAML-frontmatter som definerer en systemledetekst, tillatelser og modus.

  ```bash
  bolt agent list                           # list all available agents
  bolt agent create                         # interactive agent creation wizard
  
  # Non-interactive creation
  bolt agent create \
    --description "Audit code for security vulnerabilities" \
    --mode primary \
    --permissions "read,grep,glob" \
    --model anthropic/claude-opus-4-5 \
    --path .bolt/agents
  ```

  **Flagg for `bolt agent create`**

  | Flagg | Alias | Type | Beskrivelse |
  | --- | --- | --- | --- |
  | `--path` |  | string | Katalogsti å skrive agentfilen til |
  | `--description` |  | string | Beskrivelse i naturlig språk av hva agenten skal gjøre |
  | `--mode` |  | `all`\|`primary`\|`subagent` | Om agenten fungerer som en primær agent, underagent eller begge |
  | `--permissions` | `--tools` | string | Kommaseparert liste over tillatte tillatelser (standard: alle) |
  | `--model` | `-m` | string | Modell å bruke i `provider/model`-format |
</Accordion>

<Accordion title="bolt providers (alias: auth)">
  Håndter AI-leverandørlegitimasjoner interaktivt. Legitimasjoner lagres i OS-datamappen din (`~/.local/share/bolt/auth.json` på Linux, `~/Library/Application Support/bolt/auth.json` på macOS).

  ```bash
  bolt providers             # interactive credential management menu
  bolt auth                  # alias for bolt providers
  
  bolt providers list        # list stored credentials and active env vars
  bolt providers login       # add a credential for a provider
  bolt providers login --provider anthropic
  bolt providers login --provider anthropic --method "API Key"
  bolt providers logout      # remove a stored credential
  bolt providers logout --provider openai
  ```
</Accordion>

<Accordion title="bolt models [provider]">
  List alle modeller tilgjengelige fra de konfigurerte leverandørene dine.

  ```bash
  bolt models                         # list all models from all providers
  bolt models anthropic               # filter to a single provider
  bolt models --verbose               # include cost metadata in output
  bolt models --refresh               # force-refresh the models.dev cache
  ```

  | Flagg | Type | Beskrivelse |
  | --- | --- | --- |
  | `--verbose` | boolean | Inkluder JSON-kostmetadata for hver modell |
  | `--refresh` | boolean | Oppdater modellcache fra models.dev |
</Accordion>

<Accordion title="bolt mcp">
  Håndter Model Context Protocol (MCP)-servere. Bolt støtter både eksterne (HTTP/SSE)-servere med OAuth og lokale (stdio)-servere.

  ```bash
  bolt mcp add                              # interactive wizard to add a server
  bolt mcp add my-server --url https://mcp.example.com/tools
  bolt mcp add local-server -- npx @my-org/mcp-server
  bolt mcp list                             # show all configured servers and status
  bolt mcp auth <name>                      # run the OAuth flow for a server
  bolt mcp auth list                        # show OAuth status for all servers
  bolt mcp logout <name>                    # remove stored OAuth tokens
  bolt mcp debug <name>                     # probe connectivity and OAuth config
  ```

  **Flagg for `bolt mcp add`**

  | Flagg | Type | Beskrivelse |
  | --- | --- | --- |
  | `--url` | string | URL for en ekstern MCP-server |
  | `--env` | string\[\] | Miljøvariabel for en lokal server (`KEY=VALUE`) |
  | `--header` | string\[\] | HTTP-header for en ekstern server (`KEY=VALUE`) |
</Accordion>

<Accordion title="bolt plugin install <module>">
  Installer en Bolt-plugin fra npm og oppdater relevant konfigurasjonsfil. Plugins kan utvide TUI-en, legge til nye skråstrekkommandoer eller registrere nye leverandører.

  ```bash
  bolt plugin install @my-org/bolt-plugin
  bolt plugin install @my-org/bolt-plugin --global      # install to global config
  bolt plugin install @my-org/bolt-plugin --force        # replace existing version
  ```

  | Flagg | Alias | Type | Beskrivelse |
  | --- | --- | --- | --- |
  | `--global` | `-g` | boolean | Legg pluginen til den globale konfigurasjonen i stedet for prosjektkonfigurasjonen |
  | `--force` | `-f` | boolean | Erstatt en allerede-konfigurert plugin-versjon |
</Accordion>

<Accordion title="bolt github">
  Håndter Bolt GitHub Actions-integrasjonen, som lar Bolt svare på pull requests, issues og andre GitHub-hendelser.

  ```bash
  bolt github install           # scaffold the GitHub Actions workflow in your repo
  bolt github run               # run the GitHub agent locally (for testing)
  bolt github run --event pull_request --token ghp_xxx
  ```

  **Flagg for `bolt github run`**

  | Flagg | Type | Beskrivelse |
  | --- | --- | --- |
  | `--event` | string | GitHub-hendelsesnavn å simulere (f.eks. `pull_request`) |
  | `--token` | string | GitHub personal access token |
</Accordion>

<Accordion title="bolt pr <number>">
  Sjekk ut en GitHub-pull request som en lokal gren ved hjelp av `gh`-CLI-en, og start deretter Bolt i den utsjekkede mappen. Hvis PR-beskrivelsen inneholder en dele-lenke for økt, importerer Bolt den økten automatisk.

  ```bash
  bolt pr 123
  ```

  <Note>
    Denne kommandoen krever at [GitHub CLI (`gh`)](https://cli.github.com/) er installert og autentisert.
  </Note>
</Accordion>

<Accordion title="bolt commit">
  Generer en commit-melding for staged (eller alle sporede) endringer ved hjelp av en AI-modell og commit deretter. Modellen inspiserer nylig commit-historikk for stilkontekst.

  ```bash
  bolt commit                        # commit staged changes
  bolt commit --all                  # stage and commit all tracked changes
  bolt commit --dry-run              # print the generated message without committing
  bolt commit --model openai/gpt-4o  # use a specific model
  ```

  | Flagg | Alias | Type | Beskrivelse |
  | --- | --- | --- | --- |
  | `--all` | `-a` | boolean | Commit alle sporede endringer, ikke bare staged |
  | `--dry-run` |  | boolean | Skriv ut den genererte meldingen uten å committe |
  | `--model` | `-m` | string | Modell å bruke i `provider/model`-format |
</Accordion>

<Accordion title="bolt review">
  Kjør en AI-kodegjennomgang på en diff og avslutt med kode `0` (bestått) eller `1` (ikke bestått). `code-review`-agenten undersøker diffen for korrekthet, stil og sikkerhetsproblemer, og sender ut en `Verdict: PASS`- eller `Verdict: FAIL`-linje.

  ```bash
  bolt review                          # review uncommitted changes (git diff HEAD)
  bolt review --staged                 # review only staged changes
  bolt review --branch main            # review changes since merge base with main
  bolt review --model openai/o3        # use a specific model
  ```

  | Flagg | Alias | Type | Beskrivelse |
  | --- | --- | --- | --- |
  | `--staged` |  | boolean | Gjennomgå kun staged endringer |
  | `--branch` |  | string | Gjennomgå endringer siden merge-base med denne grenen |
  | `--model` | `-m` | string | Modell å bruke i `provider/model`-format |

  <Note>
    Avslutningskoder: `0` = PASS, `1` = FAIL, `2` = kunne ikke fastslå verdikt.
  </Note>
</Accordion>

<Accordion title="bolt export [sessionID]">
  Eksporter en økt som JSON til stdout. Nyttig for arkivering, deling eller mating inn i andre verktøy. Send `--sanitize` før du deler offentlig for å redigere ut filstier, ledetekster og annet sensitivt utskriftsinnhold.

  ```bash
  bolt export                          # interactive session picker, then write to stdout
  bolt export abc123                   # export a specific session
  bolt export abc123 --sanitize        # redact secrets and paths
  bolt export abc123 > session.json    # write to a file
  ```

  | Flagg | Type | Beskrivelse |
  | --- | --- | --- |
  | `--sanitize` | boolean | Rediger ut sensitive data (filstier, ledeteksttekst, verktøy-I/O) før eksport |
</Accordion>

<Accordion title="bolt import <file>">
  Importer en tidligere eksportert økt til den lokale databasen. Godtar enten en lokal JSON-fil eller en dele-URL for økten.

  ```bash
  bolt import ./session.json
  bolt import https://opncd.ai/share/abc123
  ```
</Accordion>

<Accordion title="bolt stats">
  Vis aggregert tokenbruk og kostnadsstatistikk på tvers av alle økter. Utdata inkluderer en oversiktstabell, kostnads- og token-oversikt, modellbruk og et stolpediagram over verktøybruk.

  ```bash
  bolt stats
  bolt stats --days 7             # last 7 days only
  bolt stats --models             # include per-model breakdown
  bolt stats --models 5           # show top 5 models
  bolt stats --tools 10           # show top 10 tools
  bolt stats --project ""         # filter to the current project only
  ```

  | Flagg | Type | Beskrivelse |
  | --- | --- | --- |
  | `--days` | number | Begrens til de siste N dagene (standard: alle tider) |
  | `--tools` | number | Antall verktøy å vise i verktøybruksdiagrammet |
  | `--models` | boolean\|number | Vis modellstatistikk; send et tall for å begrense listen |
  | `--project` | string | Filtrer etter prosjekt-ID; tom streng betyr gjeldende prosjekt |
</Accordion>

<Accordion title="bolt logs">
  Skriv ut Bolt-applikasjonsloggen. Loggen lagres i OS-loggmappen (f.eks. `~/.local/state/bolt/opencode.log`).

  ```bash
  bolt logs                        # print the last 1000 lines
  bolt logs --tail 200             # print the last 200 lines
  bolt logs --follow               # stream new lines as they are written
  bolt logs -f                     # alias for --follow
  ```

  | Flagg | Alias | Type | Beskrivelse |
  | --- | --- | --- | --- |
  | `--tail` |  | number | Antall etterfølgende linjer som skal skrives ut (standard: 1000) |
  | `--follow` | `-f` | boolean | Strøm nye logglinjer i sanntid |
</Accordion>

<Accordion title="bolt db [query]">
  Spør eller inspiser den lokale SQLite-øktdatabasen direkte.

  ```bash
  bolt db path                                  # print the database file path
  bolt db "SELECT id, title FROM sessions"      # run a SQL query (TSV output)
  bolt db "SELECT * FROM sessions" --format json
  ```

  | Flagg | Type | Beskrivelse |
  | --- | --- | --- |
  | `--format` | `json`\|`tsv` | Utdataformat for spørringsresultater (standard: `tsv`) |
</Accordion>

<Accordion title="bolt upgrade [target]">
  Oppgrader Bolt til siste utgave eller en bestemt versjon. Bolt oppdager installasjonsmetoden automatisk og bruker riktig pakkebehandler.

  ```bash
  bolt upgrade                         # upgrade to the latest version
  bolt upgrade 0.2.0                   # upgrade (or downgrade) to a specific version
  bolt upgrade --method npm            # force a specific installation method
  bolt upgrade --method curl
  ```

  | Flagg | Alias | Type | Beskrivelse |
  | --- | --- | --- | --- |
  | `--method` | `-m` | `curl`\|`npm`\|`pnpm`\|`bun`\|`brew`\|`choco`\|`scoop` | Installasjonsmetode å bruke |
</Accordion>

<Accordion title="bolt uninstall">

  ```bash
  bolt uninstall
  ```
</Accordion>

<Accordion title="bolt debug">
  En samling underkommandoer for feilsøking og introspeksjon. Nyttig når du sender inn feilrapporter eller diagnostiserer uventet oppførsel.

  ```bash
  bolt debug info          # print version, OS, terminal, and loaded plugins
  bolt debug config        # print the fully-resolved configuration
  bolt debug paths         # print all global data/config/cache directories
  bolt debug lsp           # inspect LSP state
  bolt debug ripgrep       # test ripgrep availability
  bolt debug file          # inspect file tool behavior
  bolt debug scrap         # scratchpad for debugging
  bolt debug skill         # inspect available skills
  bolt debug snapshot      # inspect session snapshots
  bolt debug startup       # measure startup time
  bolt debug agents        # list agents and their resolved config
  bolt debug v2            # inspect V2 session core state
  bolt debug wait          # block indefinitely (for process debugging)
  ```
</Accordion>

<Accordion title="bolt acp">
  Start en ACP (Agent Client Protocol)-server. ACP er protokollen som brukes av editor-integrasjoner som [Zed](https://zed.dev) for å kommunisere med Bolt over stdin/stdout.

  ```bash
  bolt acp
  bolt acp --cwd /path/to/project
  ```

  | Flagg | Type | Beskrivelse |
  | --- | --- | --- |
  | `--cwd` | string | Arbeidsmappe for serveren (standard: `process.cwd()`) |
  | `--hostname` | string | Bind hostname (standard: `127.0.0.1`) |
  | `--port` | number | Bind-port |
  | `--mdns` | boolean | Aktiver mDNS-tjenesteoppdagelse |
  | `--mdns-domain` | string | Egendefinert domenenavn for mDNS-tjeneste (standard: `opencode.local`) |
  | `--cors` | string\[\] | Ytterligere domener å tillate for CORS |
</Accordion>
