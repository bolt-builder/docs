Bolt gir deg et komplett AI-utviklerteam direkte i terminalen. Den leveres som en rask, tastaturdrevet TUI og en native skrivebordsapp, begge drevet av samme motor: ti spesialiserte agenter, vedvarende, robuste økter, MCP-serverhåndtering med OAuth, et plugin-system og støtte for alle store LLM-leverandører.

## Hva Bolt gjør

Bolt leser kodebasen din, forstår hva du bygger, og leverer kode sammen med deg – i terminalen eller som skrivebordsapp. Hver økt er robust: koble fra, koble til igjen fra en annen maskin, forgren en gren av samtalen, del en lenke, eller eksporter en renset utskrift.

## Kom i gang

<Steps>
  <Step title="Installer Bolt">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash
    ```
    Eller installer via npm: `npm i -g @bolt-builder/bolt-cli`
  </Step>
  <Step title="Åpne prosjektet ditt">
    Naviger til en prosjektmappe og start TUI-en:
    ```bash
    cd my-project
    bolt
    ```
  </Step>
  <Step title="Konfigurer en leverandør">
    Ved første oppstart ber Bolt deg legge til en LLM-leverandør. Du kan også kjøre:
    ```bash
    bolt providers
    ```
  </Step>
  <Step title="Start koding med AI">
    Skriv ledeteksten din i TUI-bunnfeltet, trykk Enter og la Bolts agenter gå i gang. Bytt agent med `Tab`.
  </Step>
</Steps>

<Tip>
  Bruk `bolt run "explain this codebase"` for et raskt ikke-interaktivt svar uten å åpne hele TUI-en.
</Tip>
