Агенти в Bolt виконують роботу, викликаючи інструменти. Кожна дія, яку ви бачите в TUI (читання файлу, запуск тестів, пошук в Інтернеті), — це модель, що обирає інструмент, і Bolt його виконує. Кожен агент має задекларований рівень доступу, який визначає, які інструменти він може викликати без попереднього запиту у вас (див. [Дозволи](/concepts/permissions)).

## Вбудовані інструменти

| Інструмент | Що робить |
| --- | --- |
| `read` | Читає файл з диска. |
| `write` | Створює новий файл або перезаписує наявний. |
| `edit` | Застосовує цільове редагування (find/replace) до файлу. |
| `apply_patch` | Застосовує патч у стилі unified-diff до одного чи кількох файлів. |
| `glob` | Перелічує файли, що відповідають glob-патерну. |
| `grep` | Шукає вміст файлу за regex/текстом. |
| `bash` | Виконує shell-команду. |
| `task` | Делегує підзавдання субагенту (`@general`, `@explore` або власному субагенту). |
| `todowrite` | Веде структурований список завдань агента для багатоетапної роботи. |
| `webfetch` | Отримує URL і повертає його вміст. |
| `websearch` | Виконує пошук в Інтернеті. |
| `skill` | Викликає іменовану навичку (див. [Навички](/extending/skills)). |
| `memory_save` | Зберігає факт у [пам'яті проєкту](/concepts/project-memory). |
| `memory_recall` | Шукає раніше збережений спогад. |
| `question` | Ставить вам уточнююче запитання й чекає на відповідь. |
| `bash_background` | Запускає shell-команду як керований фоновий процес (dev-сервери, спостерігачі, довгі збірки). |
| `process_output` | Читає накопичений вивід і статус фонового процесу, за потреби чекаючи на його завершення. |
| `list_processes` | Перелічує фонові процеси з їх id, статусом і командою. |
| `kill_process` | Завершує фоновий процес (і його дерево процесів) за id. |
| `test_run` | Виявляє та запускає тести проєкту, повертаючи структуровані результати pass/fail і деталі невдач. |

### Експериментальні

| Інструмент | Що робить |
| --- | --- |
| `lsp` | Запитує мовний сервер про визначення, посилання та діагностики. |
| `execute` | Виконує код в ізольованій пісочниці code-mode. |
| `plan` | Створює структурований план перед внесенням змін. |

Експериментальні інструменти можуть змінюватися чи перейменовуватися між випусками.

## Розширення набору інструментів

Окрім вбудованих, Bolt може викликати інструменти з трьох джерел:

- **Власні інструменти** в `.opencode/tool/` (або `.opencode/tools/`) в корені проєкту. Див. [Власні інструменти](/extending/custom-tools).
- **Інструменти плагінів**, надані будь-яким встановленим [плагіном](/extending/plugins).
- **MCP-інструменти** з будь-якого [MCP-сервера](/extending/mcp-servers), налаштованого для проєкту.

Усі три виглядають однаково з точки зору агента: вони з'являються у списку інструментів, дотримуються рівня доступу агента та з'являються у виводі виклику інструменту TUI.
