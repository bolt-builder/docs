Bolt має вбудований HTTP-сервер, що повністю відділяє рушій від інтерфейсу. Ви можете запустити headless-сервер на потужному віддаленому комп'ютері (хмарна VM, dev-контейнер, десктоп, залишений увімкненим на ніч) і приєднати TUI з ноутбука, другого термінала або навіть браузера — усі вказують на ту саму живу сесію. Це робить Bolt придатним для команд, віддалених навантажень і тривалих завдань, які ви хочете перевірити без SSH у машину.

---

## `bolt serve`

Запускає headless-сервер Bolt, що виставляє повний API через HTTP і приймає TUI-підключення.

```bash
bolt serve
```

### Прапорці

| Прапорець | За замовчуванням | Опис |
|------|---------|-------------|
| `--hostname <host>` | `127.0.0.1` | Hostname або IP-адреса для прив'язки |
| `--port <n>` | `0` (авто) | Порт для прослуховування; Bolt друкує призначений порт під час запуску |
| `--mdns` | `false` | Оголошує сервер через mDNS для виявлення в локальній мережі з нульовою конфігурацією; також встановлює hostname у `0.0.0.0` |
| `--mdns-domain <name>` | `opencode.local` | Власний домен сервісу mDNS |
| `--cors <origin>` | `[]` | Додаткові origins, дозволені через CORS (повторювані) |

<Warning>
  Якщо `OPENCODE_SERVER_PASSWORD` не встановлено, Bolt друкує попередження, а сервер повністю відкритий для будь-кого, хто може його досягти. Завжди встановлюйте пароль перед прив'язкою до будь-якого інтерфейсу, окрім `127.0.0.1`.
</Warning>

### Автентифікація

Захищайте сервер за допомогою HTTP Basic Auth, використовуючи змінні середовища:

| Змінна | Опис |
|----------|-------------|
| `OPENCODE_SERVER_PASSWORD` | Пароль базової автентифікації |
| `OPENCODE_SERVER_USERNAME` | Ім'я користувача базової автентифікації (за замовчуванням `opencode`, якщо пропущено) |

```bash
OPENCODE_SERVER_PASSWORD=my-secret bolt serve --hostname 0.0.0.0 --port 4096
```

## `bolt attach <url>`

Приєднує повний TUI до запущеного сервера Bolt. Це працює проти будь-якого сервера, доступного через HTTP — локального чи віддаленого.

```bash
bolt attach http://my-dev-machine.local:4096
```

### Прапорці

| Прапорець | Псевдонім | Опис |
|------|-------|-------------|
| `--dir <path>` | | Каталог для запуску на віддаленому сервері |
| `--continue` | `-c` | Продовжити останню сесію на сервері |
| `--session <id>` | `-s` | ID сесії для продовження |
| `--fork` | | Розгалужити сесію під час продовження (використовуйте з `--continue` або `--session`) |
| `--password <pw>` | `-p` | Пароль базової автентифікації (перевизначає `OPENCODE_SERVER_PASSWORD`) |
| `--username <user>` | `-u` | Ім'я користувача базової автентифікації (перевизначає `OPENCODE_SERVER_USERNAME`) |
| `--mini` | | Використати мінімальний інтерактивний UI замість повного TUI |

```bash
# Continue the last session on a remote server
bolt attach http://10.0.0.5:4096 --continue --password my-secret

# Fork a specific session
bolt attach http://10.0.0.5:4096 --session ses_abc123 --fork

# Minimal UI — useful in restricted terminals
bolt attach http://10.0.0.5:4096 --mini
```

## `bolt web`

Запускає сервер Bolt і одразу відкриває веб-UI у стандартному браузері. Це найшвидший спосіб отримати браузерний інтерфейс, запущений локально.

```bash
bolt web
```

`bolt web` приймає ті самі мережеві прапорці, що й `bolt serve`.

## Виявлення mDNS

Передайте `--mdns` до `bolt serve`, щоб транслювати адресу сервера у вашій локальній мережі за допомогою mDNS. Будь-який комп'ютер у тій самій мережі може потім приєднатися, використовуючи mDNS-hostname, не знаючи IP-адреси чи порту.

```bash
# On the server machine
OPENCODE_SERVER_PASSWORD=my-secret bolt serve --mdns

# From another machine on the same LAN
bolt attach http://opencode.local --password my-secret
```

Домен mDNS за замовчуванням — `opencode.local`. Перевизначте його за допомогою `--mdns-domain`:

```bash
bolt serve --mdns --mdns-domain mydevbox.local
```

## Запуск сервера й віддалене приєднання

<Steps>
  <Step title="Встановіть пароль на серверному комп'ютері">
    Експортуйте `OPENCODE_SERVER_PASSWORD` перед запуском сервера. Без нього Bolt друкує попередження, а API — без автентифікації.

    ```bash
    export OPENCODE_SERVER_PASSWORD=my-secret
    ```
  </Step>

  <Step title="Запустіть headless-сервер">
    Прив'яжіть до всіх інтерфейсів, щоб ваш ноутбук міг досягти його, та за бажанням оберіть фіксований порт:

    ```bash
    bolt serve --hostname 0.0.0.0 --port 4096
    # opencode server listening on http://0.0.0.0:4096
    ```

    Залиште цей термінал відкритим (або запустіть у `tmux` / `screen` / systemd-юніт).
  </Step>

  <Step title="Приєднайтеся з ноутбука">
    На будь-якому комп'ютері, що може досягти сервера, виконайте:

    ```bash
    bolt attach http://192.168.1.10:4096 --password my-secret
    ```

    Повний TUI відкривається й під'єднується до віддаленого рушія. Сесії, історія та стан інструментів живуть на сервері.
  </Step>

  <Step title="Продовжте сесію пізніше">
    Від'єднайтеся, вийшовши з TUI (`q` або `Ctrl-C`). Сесія продовжує працювати на сервері. Щоб повернутися:

    ```bash
    bolt attach http://192.168.1.10:4096 --continue --password my-secret
    ```

    Або розгалужте її, щоб відгалузитися без впливу на оригінал:

    ```bash
    bolt attach http://192.168.1.10:4096 --continue --fork --password my-secret
    ```
  </Step>
</Steps>

## Приклад віддаленого робочого процесу

Поширеним паттерном є залишити сервер Bolt працювати на dev-машині з великою кількістю ядер і під'єднуватися з тонкого ноутбука.

```
┌──────────────────────────────────────────────────┐
│  Dev machine (powerful, stays on)                │
│                                                  │
│  $ OPENCODE_SERVER_PASSWORD=secret bolt serve \  │
│      --hostname 0.0.0.0 --port 4096              │
│                                                  │
│  opencode server listening on http://0.0.0.0:4096│
└──────────────────────────────────────────────────┘
               ↑  HTTP (LAN / VPN / SSH tunnel)
┌──────────────────────────────────────────────────┐
│  Laptop                                          │
│                                                  │
│  $ bolt attach http://dev-machine:4096 \         │
│      --password secret                           │
└──────────────────────────────────────────────────┘
```

Усі дані сесій зберігаються у SQLite-базі даних сервера. Ноутбук лише рендерить TUI — він може від'єднатися й повторно під'єднатися будь-коли без втрати роботи.
