`bolt web` запускає сервер Bolt і надає перед ним браузерний UI. Це той самий рушій, що й TUI, лише відрендерений у вкладці браузера.

## Запуск

```bash
bolt web                                # localhost only
bolt web --hostname 0.0.0.0 --port 4096
```

Потім відкрийте надрукований URL. При виставленні через мережу спочатку встановіть базову автентифікацію:

```bash
export BOLT_SERVER_USERNAME=teamname
export BOLT_SERVER_PASSWORD=$(openssl rand -hex 24)
bolt web --hostname 0.0.0.0 --port 4096
```

## Коли використовувати веб-UI

- Запуск Bolt на потужному віддаленому комп'ютері, але керування з ноутбука.
- Обмін живою сесією з колегою для парного налагодження.
- Середовища, де повний TUI незручний (Chromebook, планшети, коворкінг-машини).
