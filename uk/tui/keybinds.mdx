TUI Bolt розроблено для повного керування з клавіатури. Ця сторінка перелічує комбінації, до яких ви звертатиметеся найчастіше. Для вичерпного списку запустіть `bolt` і відкрийте внутрішню довідку.

## Основні

| Клавіші | Дія |
| --- | --- |
| `Tab` | Перейти до наступного агента (`code`, `plan`, `ask`, ...). Поточний агент показано в рядку статусу. |
| `Shift+Tab` | Перейти до попереднього агента. |
| `Enter` | Надіслати поточне повідомлення. |
| `Esc` | Скасувати поточний хід. |
| `Ctrl+C` | Перервати поточний виклик інструменту. |
| `Ctrl+D` | Від'єднатися від сесії (залишається працювати на сервері). |

## Режими

### Режим `--mini`

Запускайте Bolt із компактним макетом із розділеним футером, що займає менше місця в терміналі, чудово для розділених панелей:

```bash
bolt --mini
bolt attach --mini <url>
```

### Голосове введення push-to-talk

Утримуйте налаштовану клавішу push-to-talk, щоб продиктувати промпт за допомогою speech-to-text, потім відпустіть, щоб надіслати. Налаштуйте клавішу та STT-провайдера у `.bolt/bolt.jsonc`.
