Десктопний застосунок Bolt обгортає той самий рушій, що й CLI, у повну оболонку Electron. Кожна функція, доступна в терміналі — агенти, MCP-сервери, плагіни, віддалені сесії, сесії, які можна розгалужувати та якими можна ділитися — працює однаково в десктопному застосунку, з додаванням багатовіконного та багатовкладкового досвіду, графічного UI налаштувань, нативних сповіщень та автооновлень. Якщо ви вже використовуєте CLI, десктопний застосунок є повноцінним доповненням, а не заміною.

---

## Встановлення

### macOS

<Steps>
  <Step title="Встановіть однорядковою командою (рекомендовано)">
    Відкрийте термінал і виконайте:

    ```bash
    curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install-desktop | bash
    ```

    Скрипт завантажує останній випуск, перевіряє його та розміщує застосунок у `/Applications`. Без спливаючих вікон Gatekeeper.
  </Step>

  <Step title="Запустіть застосунок">
    Відкрийте **Bolt** з `/Applications` або Spotlight. Під час першого запуску Bolt просить обрати LLM-провайдера за замовчуванням і створює глобальний файл конфігурації.
  </Step>
</Steps>

<Tip>
  Однорядкова команда встановлює застосунок так, щоб обійти діалог "unidentified developer" від macOS Gatekeeper, тож ви одразу переходите до програмування без додаткових запитів безпеки.
</Tip>

### Усі платформи — завантаження з релізів

Завантажте останній інсталятор для вашої платформи зі [сторінки релізів Bolt](https://github.com/Bolt-builder/bolt-cli/releases).

| Платформа | Тип інсталятора |
|----------|---------------|
| macOS (Apple Silicon) | `.dmg` |
| macOS (Intel) | `.dmg` |
| Windows | `.exe` installer |
| Linux | `.AppImage` / `.deb` |

<Note>
  На Windows Bolt включає інтеграцію WSL (Windows Subsystem for Linux). Коли WSL доступний, Bolt може відкривати сесії безпосередньо у вашому дистрибутиві WSL — надаючи вам Linux-нативне середовище агента з нативним UI Windows навколо нього.
</Note>

## Можливості

### Багатовіконне та багатовкладкове керування сесіями

Відкривайте скільки завгодно вікон, кожне з власним набором вкладок. Вкладки відповідають безпосередньо сесіям Bolt, тож ви можете запускати агента на рефакторингу в одній вкладці, ставити питання в іншій і запускати фонове завдання в третій — і все це одночасно.

### Композитор промптів

Композитор промптів підтримує багате введення: вставляйте текст, перетягуйте файли як вкладення або вставляйте зображення безпосередньо з буфера обміну. Bolt автоматично кодує зображення й надсилає його будь-якій моделі з можливостями зору.

### Інтегрований термінал і дерево файлів

Розділений макет надає розмову з агентом з одного боку та живий термінал і дерево файлів проєкту з іншого. Ви можете запускати команди, перевіряти вивід і повертати результати агенту, не перемикаючи застосунки.

### Палітра команд

Натисніть `Cmd/Ctrl+K`, щоб відкрити палітру команд. Звідси ви можете перемикати сесії, змінювати агентів, відкривати налаштування або запускати будь-яку дію без миші.

### Повний UI налаштувань

Панель налаштувань охоплює кожну опцію, яка живе в `.bolt/bolt.jsonc` — комбінації клавіш, вибір моделі, LLM-провайдерів, MCP-сервери та автентифікацію — з випадними списками, перемикачами та вбудованою валідацією. Рідко потрібно редагувати файл конфігурації вручну.

### Нативні сповіщення

Bolt викликає нативне сповіщення ОС, коли тривале завдання завершується. Клацніть сповіщення, щоб перейти безпосередньо до сесії.

### Глибокі посилання

Відкривайте конкретну сесію, переходячи за URL `bolt://`. Корисно для обміну посиланнями на сесії з колегами або закладення роботи в процесі.

### Автооновлення

Десктопний застосунок оновлюється сам через три канали:

| Канал | Опис |
|---------|-------------|
| `prod` | Стабільні релізи, оновлюються на кожному продакшн-тегу |
| `beta` | Пре-релізні збірки для раннього доступу до нових функцій |
| `dev` | Нічні збірки з гілки `dev` |

Перемикайте канали в **Settings → About**.

### 28 мов інтерфейсу

Інтерфейс Bolt локалізовано на 28 мов. Змінюйте мову відображення в **Settings → Appearance → Language**.
