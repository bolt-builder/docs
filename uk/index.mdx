Bolt поміщає повноцінну AI-команду інженерів прямо у ваш термінал. Він постачається як швидкий, керований з клавіатури TUI та як нативний десктопний застосунок — обидва побудовані на одному рушії: десять спеціалізованих агентів, стійкі довготривалі сесії, керування MCP-серверами з OAuth, система плагінів і підтримка всіх провідних LLM-провайдерів.

## Що робить Bolt

Bolt читає вашу кодову базу, розуміє, що ви створюєте, і пише код разом з вами — у терміналі або в десктопному застосунку. Кожна сесія довговічна: від'єднуйтесь, під'єднуйтесь знову з іншого комп'ютера, розгалужуйте розмову, діліться посиланням або експортуйте очищену стенограму.

## Запуск і робота

<Steps>
  <Step title="Встановіть Bolt">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash
    ```
    Або встановіть через npm: `npm i -g @bolt-builder/bolt-cli`
  </Step>
  <Step title="Відкрийте свій проєкт">
    Перейдіть у каталог будь-якого проєкту та запустіть TUI:
    ```bash
    cd my-project
    bolt
    ```
  </Step>
  <Step title="Налаштуйте провайдера">
    Під час першого запуску Bolt запропонує додати LLM-провайдера. Також можна виконати:
    ```bash
    bolt providers
    ```
  </Step>
  <Step title="Почніть програмувати з AI">
    Введіть промпт у нижній частині TUI, натисніть Enter і дайте агентам Bolt приступити до роботи. Перемикайте агентів клавішею `Tab`.
  </Step>
</Steps>

<Tip>
  Використовуйте `bolt run "explain this codebase"` для швидкої неінтерактивної відповіді без запуску повного TUI.
</Tip>
