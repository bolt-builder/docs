`bolt stats` агрегує кількість токенів і вартість за локальною базою даних сесій. Оскільки кожен виклик інструменту записується (див. [Локальну базу даних](/reference/local-database)), числа точні для LLM-викликів, які виконував Bolt.

## Базове використання

```bash
bolt stats                       # summary for the current project
bolt stats --days 7              # last seven days
bolt stats --days 7 --models     # break down by model
```

## Що показує

- Загальну кількість вхідних, вихідних токенів і токенів кешу.
- Оцінену вартість на провайдера (використовуючи цінові таблиці провайдера на момент запуску).
- Розбивку за моделями, агентами й днями залежно від прапорців.

## Зменшення вартості

- Використовуйте `--variant minimal` або `--variant low` на моделях з важким міркуванням. Див. [Провайдери та моделі](/concepts/providers-and-models).
- Надавайте перевагу агенту `ask` або `plan` для дослідження; вони лише для читання й уникають циклів із інтенсивним використанням інструментів.
- Перемикайтеся на меншу модель за допомогою `bolt models` для завдань, що не потребують передової здатності.
