Bolt тримає кожну сесію, повідомлення та виклик інструменту в локальній базі даних SQLite. Вона повністю переглядається й повністю ваша — нічого не завантажується, якщо ви явно не поділитеся сесією.

## Поширені операції

```bash
bolt db path                        # print the path to the SQLite file
bolt db                             # open an interactive SQL shell
bolt db "SELECT id, title FROM sessions ORDER BY time_updated DESC LIMIT 20"
```

## Резервне копіювання

Оскільки це один файл SQLite, резервне копіювання — це копіювання:

```bash
cp "$(bolt db path)" ~/backups/bolt-$(date +%Y%m%d).db
```

Для тривалого зберігання чи транспортування надавайте перевагу `bolt export` / `bolt import` — вони створюють переносне JSON-представлення, яке переживає міграції схеми.

## Схема з першого погляду

- `sessions` — один рядок на сесію з заголовком, проєктом, часовими мітками та статусом.
- `messages` — повний лог ходів на сесію.
- `tool_calls` — кожен виклик з входами, виходами та тривалістю.

Точні стовпці еволюціонують; використовуйте `PRAGMA table_info(<table>)`, щоб побачити живу схему.
