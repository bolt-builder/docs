Окрім десяти вбудованих агентів, ви можете визначати власних. Власні агенти — це Markdown-файли з блоком frontmatter, який описує модель агента, рівень доступу та доступні інструменти, плюс тіло, що діє як його системний промпт.

## Створення агента

Найшвидший шлях — вбудований генератор, який ставить кілька запитань і записує файл за вас:

```bash
bolt agent create
```

Агенти живуть під `.opencode/agent/` у проєкті (або в глобальному каталозі конфігурації для персональних агентів). Кожен агент — це один `.md`-файл, чиє ім'я файлу стає ім'ям агента.

## Анатомія файлу агента

```md
---
name: "e2e-writer"
description: "Writes and updates Playwright end-to-end tests"
model: "anthropic/claude-opus-4-5"
access: "edit"
tools:
  - read
  - edit
  - write
  - grep
  - bash
---

You are an expert Playwright end-to-end test author. When asked to add tests:

1. Read existing tests in `e2e/` first to match style.
2. Prefer role-based selectors.
3. Always run `pnpm e2e -- --reporter=list` after editing.
```

Загальні поля frontmatter:

| Поле | Призначення |
| --- | --- |
| `name` | Ім'я агента, що використовується з `--agent`. |
| `description` | Однорядковий підсумок, що показується у списках. |
| `model` | Модель за замовчуванням у форматі `provider/model`. |
| `access` | `full`, `edit` або `read` (див. [Дозволи](/concepts/permissions)). |
| `tools` | Необов'язковий allow-list, що обмежує, які [інструменти](/concepts/tools) агент може викликати. |

## Використання власного агента

```bash
bolt run --agent e2e-writer "add a signup flow test"
```

У TUI натискайте `Tab`, щоб перебирати агентів; власні агенти з'являються поруч із вбудованими.

## Субагенти

Агенти можуть делегувати субагентам через інструмент `task`. Bolt постачається з `@general` і `@explore`, і будь-який власний агент, файл якого живе під `.opencode/agent/`, також може бути викликаний як субагент за іменем.
