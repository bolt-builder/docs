Bolt agents फ़ाइलें पढ़ सकते हैं, फ़ाइलें लिख सकते हैं, और shell कमांड चला सकते हैं। यह शक्ति दो लेयर्स के माध्यम से स्कोप की जाती है: per-agent एक्सेस लेवल, और इंटरैक्टिव permission prompts जिन्हें आप अप्रूव, अस्वीकार, या पहले से कॉन्फ़िगर कर सकते हैं।

## Agent एक्सेस लेवल

प्रत्येक बिल्ट-इन agent का एक घोषित एक्सेस लेवल होता है:

| एक्सेस लेवल | फ़ाइलें पढ़ें | फ़ाइलें लिखें | Shell कमांड चलाएँ |
| --- | --- | --- | --- |
| **Full** | ✓ | ✓ | ✓ |
| **Edit** | ✓ | ✓ | ✗ |
| **Read** | ✓ | ✗ | ✗ |

बिल्ट-इन मैपिंग:

- **Full** — `code`, `debug`, `refactor`, `migrate`, `perf`
- **Edit** — `docs`
- **Read** — `plan`, `ask`, `code-review`, `security`

TUI में `Tab` से agents बदलें, या `bolt run` को `--agent <name>` पास करें।

## इंटरैक्टिव prompts

Agent के एक्सेस लेवल के भीतर, संभावित रूप से विनाशकारी क्रियाओं के लिए अभी भी पुष्टि मांगी जाती है। आप एक बार अप्रूव कर सकते हैं, पूरे सेशन के लिए अप्रूव कर सकते हैं, या अस्वीकार कर सकते हैं। अस्वीकार किए गए कॉल agent को त्रुटि लौटाते हैं और वह आगे बढ़ जाता है।

## Non-interactive अप्रूवल

CI, स्क्रिप्ट्स, या विश्वसनीय स्थानीय वर्कफ़्लो के लिए, `bolt run` ऐसे flags का समर्थन करता है जो prompts को छोड़ देते हैं:

```bash
bolt run --auto "tidy up imports"                   # auto-approve anything not explicitly denied
bolt run --yolo "tidy up imports"                   # alias for --auto
bolt run --dangerously-skip-permissions "..."       # bypass every prompt
```

<Warning>
  `--auto`, `--yolo` और `--dangerously-skip-permissions` agent को बिना पूछे पढ़ने, लिखने और execute करने देते हैं। इनका उपयोग केवल विश्वसनीय वातावरण में करें।
</Warning>

## कॉन्फ़िगरेशन-लेवल नियम

आप पूरे प्रोजेक्ट के लिए विशिष्ट tools को पहले से अस्वीकृत (या पहले से अनुमत) कर सकते हैं, `.bolt/bolt.jsonc` में एक `permission` ब्लॉक जोड़कर। यह प्रोजेक्ट के हर सेशन पर लागू होता है, जिसमें non-interactive `bolt run` कॉल शामिल हैं। स्कीमा के लिए [Configuration](/concepts/configuration) देखें।
