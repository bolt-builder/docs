Plugins आपको Bolt को उसकी बिल्ट-इन क्षमताओं से आगे बढ़ाने देते हैं। एक plugin एक Node या Bun मॉड्यूल है जो एक Bolt plugin manifest एक्सपोर्ट करता है; जब लोड होता है, तो यह नए LLM providers, कस्टम authentication methods, अतिरिक्त tools, और workspace adapters रजिस्टर कर सकता है। Plugins को एकल प्रोजेक्ट के लिए इंस्टॉल किया जा सकता है या आपके सभी काम में globally लागू किया जा सकता है।

## एक plugin इंस्टॉल करना

npm से plugin इंस्टॉल करने और आपके config में स्वचालित रूप से इसे रजिस्टर करने के लिए `bolt plugin install` (alias: `bolt plug`) का उपयोग करें:

```bash
bolt plugin install <module>
```

### Flags

| Flag | Alias | विवरण |
|------|-------|-------------|
| `--global` | `-g` | वर्तमान प्रोजेक्ट के बजाय global config में इंस्टॉल करें |
| `--force` | `-f` | उसी module के लिए मौजूदा प्रविष्टि को replace करें |

### Scope: प्रोजेक्ट बनाम global

डिफ़ॉल्ट रूप से, `bolt plugin install` plugin को प्रोजेक्ट-लेवल `.bolt/bolt.jsonc` में जोड़ता है। इसे अपने user-wide config में जोड़ने के लिए `--global` पास करें ताकि यह हर प्रोजेक्ट में लोड हो।

```bash
# Project-scoped (default)
bolt plugin install @acme/bolt-plugin-jira

# Global — loads in every project
bolt plugin install @acme/bolt-plugin-jira --global
```

<Note>
  सभी बाहरी plugins अक्षम के साथ Bolt शुरू करने के लिए `bolt --pure` चलाएँ (या `OPENCODE_PURE=1` सेट करें)। यह debug करने के लिए उपयोगी है कि क्या कोई plugin अनपेक्षित व्यवहार का कारण बन रहा है, बिना इसे uninstall किए।
</Note>

## एक प्रकाशित plugin इंस्टॉल करना

<Steps>
  <Step title="Plugin पैकेज खोजें">
    npm पर `bolt-plugin` या `opencode-plugin` वाले पैकेजों की खोज करें, या provider के दस्तावेज़ से एक लिंक का पालन करें।
  </Step>

  <Step title="अपने प्रोजेक्ट में इंस्टॉल करें">
    ```bash
    bolt plugin install @acme/bolt-plugin-jira
    ```

    Bolt पैकेज को इंस्टॉल करता है, सर्वर और TUI targets का पता लगाने के लिए इसका manifest पढ़ता है, फिर प्रविष्टि को `.bolt/bolt.jsonc` में लिखता है।
  </Step>

  <Step title="Config verify करें">
    `.bolt/bolt.jsonc` खोलें और पुष्टि करें कि plugin प्रविष्टि जोड़ी गई थी:

    ```jsonc
    {
      "plugin": [
        "@acme/bolt-plugin-jira"
      ]
    }
    ```
  </Step>

  <Step title="एक session शुरू करें">
    ```bash
    bolt
    ```

    Bolt स्टार्टअप पर plugin लोड करता है। यह जो भी providers या tools रजिस्टर करता है, वे तुरंत उपलब्ध होते हैं।
  </Step>
</Steps>

## मैन्युअल plugin कॉन्फ़िगरेशन

आप `.bolt/bolt.jsonc` को सीधे एडिट करके plugins रजिस्टर कर सकते हैं। यह विकास के अंतर्गत स्थानीय plugins के लिए उपयोगी है:

```jsonc
{
  "plugin": [
    "./plugins/my-plugin.ts"
  ]
}
```

Relative paths प्रोजेक्ट रूट से हल किए जाते हैं। TypeScript और JavaScript दोनों entry points समर्थित हैं।

## एक plugin बनाना

Plugins को `@opencode-ai/plugin` पैकेज के विरुद्ध लिखा जाता है, जो `Hooks` इंटरफ़ेस प्रदान करता है जिसे आपके module को संतुष्ट करना चाहिए।

```bash
npm install --save-dev @opencode-ai/plugin
```

एक न्यूनतम plugin एक function एक्सपोर्ट करता है जो एक `PluginInput` object प्राप्त करता है और एक `Hooks` object लौटाता है:

```typescript
import type { Plugin } from "@opencode-ai/plugin"

const myPlugin: Plugin = async (input) => {
  return {
    // auth hook — register custom authentication methods
    auth: {
      methods: [
        {
          id: "my-provider-auth",
          name: "My Provider",
          // ... provider-specific fields
        },
      ],
    },
  }
}

export default myPlugin
```

### उपलब्ध hook types

| Hook | उद्देश्य |
|------|---------|
| `auth` | `methods` array के साथ कस्टम authentication providers रजिस्टर करें |
| `event` | session events (messages, tool calls, completions) पर प्रतिक्रिया दें |
| `config` | रनटाइम पर कॉन्फ़िगरेशन बदलावों का जवाब दें |
| `dispose` | plugin unload होने पर resources को साफ़ करें |

`PluginInput` object `client` (एक typed Bolt API client), `project`, `worktree`, `directory`, और `serverUrl` उजागर करता है ताकि आपका plugin चल रहे सर्वर के साथ इंटरैक्ट कर सके।
