`bolt web` एक Bolt server शुरू करता है और इसके सामने एक browser UI serve करता है। यह TUI के समान इंजन है, बस एक browser tab में render किया गया है।

## इसे शुरू करें

```bash
bolt web                                # localhost only
bolt web --hostname 0.0.0.0 --port 4096
```

फिर प्रिंट किए गए URL को खोलें। नेटवर्क पर उजागर करते समय, पहले basic auth सेट करें:

```bash
export BOLT_SERVER_USERNAME=teamname
export BOLT_SERVER_PASSWORD=$(openssl rand -hex 24)
bolt web --hostname 0.0.0.0 --port 4096
```

## वेब UI का उपयोग कब करें

- एक शक्तिशाली रिमोट मशीन पर Bolt चलाना लेकिन इसे laptop से चलाना।
- pair-debugging के लिए किसी teammate के साथ live session साझा करना।
- ऐसे वातावरण जहाँ पूर्ण TUI अजीब है (Chromebooks, tablets, coworking मशीनें)।
