Bolt आपके टर्मिनल में सीधे एक पूर्ण AI इंजीनियरिंग टीम रखता है। यह एक तेज़, कीबोर्ड-चालित TUI और एक नेटिव डेस्कटॉप ऐप के रूप में आता है, दोनों एक ही इंजन द्वारा समर्थित हैं: दस विशेष agents, स्थायी टिकाऊ sessions, OAuth के साथ MCP सर्वर प्रबंधन, एक plugin सिस्टम, और हर प्रमुख LLM provider के लिए समर्थन।

## Bolt क्या करता है

Bolt आपके कोडबेस को पढ़ता है, समझता है कि आप क्या बना रहे हैं, और आपके साथ कोड शिप करता है—टर्मिनल में या डेस्कटॉप ऐप के रूप में। प्रत्येक सेशन टिकाऊ है: detach करें, दूसरी मशीन से फिर से attach करें, बातचीत की एक branch fork करें, एक लिंक साझा करें, या एक sanitized transcript एक्सपोर्ट करें।

## शुरू करें और चलाएँ

<Steps>
  <Step title="Bolt इंस्टॉल करें">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash
    ```
    या npm के माध्यम से इंस्टॉल करें: `npm i -g @bolt-builder/bolt-cli`
  </Step>
  <Step title="अपना प्रोजेक्ट खोलें">
    किसी भी प्रोजेक्ट डायरेक्टरी में जाएँ और TUI लॉन्च करें:
    ```bash
    cd my-project
    bolt
    ```
  </Step>
  <Step title="एक provider कॉन्फ़िगर करें">
    पहले लॉन्च पर Bolt आपको एक LLM provider जोड़ने के लिए कहता है। आप यह भी चला सकते हैं:
    ```bash
    bolt providers
    ```
  </Step>
  <Step title="AI के साथ कोडिंग शुरू करें">
    TUI फ़ुटर में अपना prompt टाइप करें, Enter दबाएँ, और Bolt के agents को काम पर लगने दें। `Tab` से agents बदलें।
  </Step>
</Steps>

<Tip>
  पूर्ण TUI खोले बिना त्वरित non-interactive उत्तर के लिए `bolt run "explain this codebase"` का उपयोग करें।
</Tip>
