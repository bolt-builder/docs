`bolt serve` spouští bezhlavý Bolt server, který vystavuje plný engine přes HTTP: sezení, agenty, nástroje, přístup k providerům, MCP a streamovací události. Cokoli, co Bolt umí interaktivně, umí i přes API.

## Spuštění serveru

```bash
bolt serve                              # localhost only, random port
bolt serve --hostname 0.0.0.0 --port 4096
bolt serve --mdns                       # advertise on the local network
```

<Warning>
  Bind na `0.0.0.0` vystaví Bolt do sítě. Před tím vždy nastav `BOLT_SERVER_USERNAME` a `BOLT_SERVER_PASSWORD`.
</Warning>

## Připojení TUI

Z libovolného stroje, který má na server dosah:

```bash
bolt attach http://server:4096
bolt attach --mini http://server:4096
```

Nebo spusť jednorázový prompt proti vzdálenému serveru:

```bash
bolt run --attach http://server:4096 --dir /projects/api "what tests are failing?"
```

## Basic auth

Nastav přihlašovací údaje přes proměnné prostředí (viz [Proměnné prostředí](/reference/environment-variables)):

```bash
export BOLT_SERVER_USERNAME=teamname
export BOLT_SERVER_PASSWORD=$(openssl rand -hex 24)
bolt serve --hostname 0.0.0.0 --port 4096
```

Všichni klienti musí posílat odpovídající přihlašovací údaje.
