Bolt je AI kódovací agent primárně pro terminál, postavený na [Effect](https://effect.website), [OpenTUI](https://github.com/opentui/opentui) a [SolidJS](https://www.solidjs.com). Namiř ho na libovolný projekt a automaticky si vezme kontext: prozkoumá tvůj kód, dodržuje tvé konvence, spouští shellové příkazy, edituje soubory, spouští testy a dodává změny.

Deset vestavěných agentů (`code`, `plan`, `ask`, `code-review`, `debug`, `refactor`, `docs`, `security`, `migrate`, `perf`) plus subagenti `@general` a `@explore` pokryjí celou engineering smyčku. Sezení jsou trvalá: můžeš se odpojit, znovu připojit (i ke vzdálenému serveru), rozvětvit, sdílet, exportovat a importovat kdykoli. Paměť projektu uchovává, co se agent naučí mezi sezeními. Rozšiřitelné přes MCP servery (s OAuth), pluginy, vlastní agenty a vlastní nástroje.

Bolt je open source pod licencí PolyForm Noncommercial 1.0.0.

## Proč Bolt?

Bolt je navržený kolem toho, jak vývojáři skutečně pracují: v terminálu, napříč více sezeními, na skutečných kódových základnách. Zde je, co ho odlišuje:

- **TUI primárně pro terminál.** Rychlé, klávesnicí ovládané rozhraní postavené na [Effect](https://effect.website), [OpenTUI](https://github.com/opentui/opentui) a [SolidJS](https://www.solidjs.com). Působí nativně, protože nativní je.
- **Celý tým agentů.** Deset specializovaných agentů — `code`, `plan`, `ask`, `code-review`, `debug`, `refactor`, `docs`, `security`, `migrate` a `perf` — plus subagenti pro výzkum a vícekrokové delegování. Mezi nimi přepínej pomocí `Tab`.
- **Sezení, která můžeš opustit a znovu se přihlásit.** Odpoj se od sezení a připoj se později, i na vzdáleném serveru. Rozvětvi, sdílej, exportuj a importuj práci kdykoli. Sezení jsou uložena v SQLite a plně prohledávatelná pomocí `bolt db`.
- **Rozšiřitelnost jako filozofie.** MCP servery s plnou podporou OAuth, systém pluginů, integrace s GitHubem, vestavěný API server a webové UI.
- **Desktopová aplikace.** Stejný engine zabalený do zážitku ve více oknech a záložkách — s integrovaným terminálem, stromem souborů, paletou příkazů, 28 jazyky UI a automatickými aktualizacemi.

## Vestavění agenti

Bolt se dodává s deseti specializovanými agenty. Každý agent má definovanou úroveň přístupu k souborovému systému odpovídající jeho účelu.

| Agent | Přístup | Popis |
| --- | --- | --- |
| `code` | Full | Výchozí: čte, píše a spouští kód |
| `plan` | Read | Prozkoumává kódovou základnu a vytváří plán bez změn souborů |
| `ask` | Read | Otázky a výzkum — žádné úpravy souborů |
| `code-review` | Read | Reviewuje změny na správnost, styl a bezpečnost |
| `debug` | Full | Ladí padající testy, pády a logické chyby |
| `refactor` | Full | Bezpečný refaktoring s ověřením testy v každém kroku |
| `docs` | Edit | Píše a aktualizuje dokumentaci a komentáře |
| `security` | Read | Bezpečnostní audit: zranitelnosti, tajné klíče, vzory |
| `migrate` | Full | Upgrady frameworků a migrace závislostí |
| `perf` | Full | Analýza výkonu a optimalizace |

Vlastní agenty si můžeš také definovat jako Markdown soubory nebo vygenerovat pomocí `bolt agent create`.

## Desktopová aplikace

Bolt se dodává i jako samostatná desktopová aplikace se správou sezení ve více oknech a záložkách, prompt composerem s podporou příloh a vkládání obrázků ze schránky, integrovaným terminálem a stromem souborů, paletou příkazů, plným nastavením pro klávesové zkratky, modely, providery a servery, nativními notifikacemi, deep linky, integrací s WSL na Windows a automatickými aktualizacemi napříč kanály dev, beta a produkce.

Stáhni desktopovou aplikaci ze [stránky releases](https://github.com/Bolt-builder/bolt-cli/releases), nebo ji nainstaluj jedním řádkem na macOS bez zajížďky přes Gatekeeper:

```bash
curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install-desktop | bash
```
