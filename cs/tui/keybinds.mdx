TUI Boltu je navrženo tak, aby se dalo řídit z klávesnice od začátku do konce. Tato stránka uvádí zkratky, po kterých budeš sahat nejčastěji. Vyčerpávající seznam získáš spuštěním `bolt` a otevřením in-app nápovědy.

## Základy

| Klávesy | Akce |
| --- | --- |
| `Tab` | Přejít na dalšího agenta (`code`, `plan`, `ask`, ...). Aktuální agent je zobrazen ve stavovém řádku. |
| `Shift+Tab` | Přejít na předchozího agenta. |
| `Enter` | Odeslat aktuální zprávu. |
| `Esc` | Zrušit probíhající tah. |
| `Ctrl+C` | Přerušit aktuální volání nástroje. |
| `Ctrl+D` | Odpojit se od sezení (zůstane běžet na serveru). |

## Režimy

### Režim `--mini`

Spusť Bolt s kompaktním rozvržením se split-footerem, které zabírá méně místa v terminálu, skvělé pro rozdělené panely:

```bash
bolt --mini
bolt attach --mini <url>
```

### Push-to-talk hlas

Podrž nakonfigurovanou push-to-talk klávesu a nadiktuj prompt pomocí speech-to-text, poté ji pusť pro odeslání. Klávesu a STT providera nakonfiguruj v `.bolt/bolt.jsonc`.
