Bolt ti přináší celý AI engineering tým přímo do terminálu. Dodává se jako rychlé, klávesnicí ovládané TUI i nativní desktopová aplikace, přičemž obě používají stejný engine: deset specializovaných agentů, trvalá odolná sezení, správa MCP serverů s OAuth, systém pluginů a podpora všech hlavních LLM providerů.

## Co Bolt dělá

Bolt čte tvůj kód, rozumí tomu, co stavíš, a píše kód spolu s tebou — v terminálu nebo jako desktopová aplikace. Každé sezení je trvalé: můžeš se odpojit, znovu připojit z jiného stroje, rozvětvit konverzaci, sdílet odkaz nebo exportovat očištěný záznam.

## Jak začít

<Steps>
  <Step title="Nainstaluj Bolt">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash
    ```
    Nebo nainstaluj přes npm: `npm i -g @bolt-builder/bolt-cli`
  </Step>
  <Step title="Otevři svůj projekt">
    Přejdi do libovolného adresáře s projektem a spusť TUI:
    ```bash
    cd my-project
    bolt
    ```
  </Step>
  <Step title="Nakonfiguruj providera">
    Při prvním spuštění tě Bolt vyzve k přidání LLM providera. Můžeš také spustit:
    ```bash
    bolt providers
    ```
  </Step>
  <Step title="Začni kódovat s AI">
    Napiš svůj prompt do zápatí TUI, stiskni Enter a nech agenty Boltu pracovat. Mezi agenty přepínáš pomocí `Tab`.
  </Step>
</Steps>

<Tip>
  Použij `bolt run "explain this codebase"` pro rychlou neinteraktivní odpověď bez otevírání celého TUI.
</Tip>
