O Bolt coloca uma equipa de engenharia de IA completa diretamente no seu terminal. É distribuído como um TUI rápido e controlado pelo teclado e como uma aplicação de desktop nativa, ambos suportados pelo mesmo motor: dez agentes especializados, sessões duradouras persistentes, gestão de servidores MCP com OAuth, um sistema de plugins e suporte para todos os principais fornecedores de LLM.

## O que o Bolt faz

O Bolt lê o seu código-fonte, entende o que está a construir e escreve código consigo—no terminal ou como aplicação de desktop. Cada sessão é duradoura: desanexe, reanexe a partir de outra máquina, faça fork de uma ramificação da conversa, partilhe uma ligação ou exporte uma transcrição sanitizada.

## Começar rapidamente

<Steps>
  <Step title="Instalar o Bolt">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash
    ```
    Ou instale via npm: `npm i -g @bolt-builder/bolt-cli`
  </Step>
  <Step title="Abrir o seu projeto">
    Navegue para qualquer diretório de projeto e inicie o TUI:
    ```bash
    cd my-project
    bolt
    ```
  </Step>
  <Step title="Configurar um fornecedor">
    No primeiro arranque, o Bolt pede-lhe para adicionar um fornecedor de LLM. Também pode executar:
    ```bash
    bolt providers
    ```
  </Step>
  <Step title="Começar a programar com IA">
    Escreva o seu prompt no rodapé do TUI, prima Enter e deixe os agentes do Bolt fazerem o trabalho. Alterne agentes com `Tab`.
  </Step>
</Steps>

<Tip>
  Utilize `bolt run "explain this codebase"` para uma resposta rápida não interativa, sem abrir o TUI completo.
</Tip>
