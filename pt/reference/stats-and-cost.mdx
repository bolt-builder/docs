`bolt stats` agrega contagens de tokens e custo na base de dados de sessões local. Como cada chamada de ferramenta é registada (consulte [Base de Dados Local](/reference/local-database)), os números são exatos para as chamadas de LLM que o Bolt orquestrou.

## Utilização básica

```bash
bolt stats                       # resumo do projeto atual
bolt stats --days 7              # últimos sete dias
bolt stats --days 7 --models     # discriminação por modelo
```

## O que mostra

- Tokens totais de entrada, saída e cache.
- Custo estimado por fornecedor (utilizando as tabelas de preços do fornecedor no momento da execução).
- Discriminação por modelo, por agente e por dia consoante as flags.

## Reduzir o custo

- Utilize `--variant minimal` ou `--variant low` em modelos com muito raciocínio. Consulte [Fornecedores e Modelos](/concepts/providers-and-models).
- Prefira o agente `ask` ou `plan` para exploração; são apenas de leitura e evitam ciclos com muitas ferramentas.
- Mude para um modelo mais pequeno com `bolt models` para tarefas que não precisam de capacidade de topo.
