スラッシュコマンドは TUI プロンプトに入力され、現在のセッションの動作を変更します。モデルには何も送信されません。Bolt 自体に対してローカルに実行されます。

## リファレンス

| コマンド | 内容 |
| --- | --- |
| `/memory` | このセッションのプロジェクトメモリステータスを表示します。 |
| \`/memory use on | off\` | このセッションが [プロジェクトメモリ](/concepts/project-memory) から読み取るかどうか。 |
| \`/memory contribute on | off\` | ターン終了時にこのセッションがプロジェクトメモリに書き戻すかどうか。 |
| `/plan` | 現在のセッションを計画モード (読み取り専用、計画を生成) に切り替えます。 |
| `/todos` | エージェントの現在の構造化タスクリストを表示します。 |
| `/btw` | 帯域外のメモを注入 (「ところで...」)。完全な応答をトリガーせずに、エージェントが次のターンで見ることになります。 |

<Tip>
  スラッシュコマンドはセッションスコープです。設定を永続化するには、代わりに `.bolt/bolt.jsonc` で設定してください。[設定](/concepts/configuration) を参照してください。
</Tip>

## 独自のものを追加する

カスタムスラッシュコマンドは [プラグイン](/extending/plugins) や `.opencode/command/` 内のファイルによって提供できます。各コマンドは、トリガーと動作を記述するフロントマターを持つ Markdown ファイルです。
