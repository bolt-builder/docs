Bolt TUI は端から端までキーボードから駆動できるよう設計されています。このページには、最もよく手を伸ばすショートカットが一覧化されています。網羅的なリストについては、`bolt` を実行してアプリ内ヘルプを開いてください。

## 基本

| キー | アクション |
| --- | --- |
| `Tab` | 次のエージェントに循環 (`code`、`plan`、`ask`、...)。現在のエージェントはステータスバーに表示されます。 |
| `Shift+Tab` | 前のエージェントに循環。 |
| `Enter` | 現在のメッセージを送信。 |
| `Esc` | 進行中のターンをキャンセル。 |
| `Ctrl+C` | 現在のツール呼び出しを中断。 |
| `Ctrl+D` | セッションからデタッチ (サーバ上では実行が継続)。 |

## モード

### `--mini` モード

ターミナル空間を消費しないコンパクトな split-footer レイアウトで Bolt を起動します。分割ペインに最適です。

```bash
bolt --mini
bolt attach --mini <url>
```

### プッシュツートーク音声

設定されたプッシュツートークキーを長押しして音声からテキストへの変換でプロンプトを口述し、離して送信します。キーと STT プロバイダを `.bolt/bolt.jsonc` で設定してください。
