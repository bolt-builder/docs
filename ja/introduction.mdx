Bolt は [Effect](https://effect.website)、[OpenTUI](https://github.com/opentui/opentui)、[SolidJS](https://www.solidjs.com) 上に構築された、ターミナルファーストの AI コーディングエージェントです。任意のプロジェクトに向けると、コンテキストを自動的にピックアップします。コードを探索し、あなたの慣習に従い、シェルコマンドを実行し、ファイルを編集し、テストを実行し、変更を出荷します。

10 の組み込みエージェント (`code`、`plan`、`ask`、`code-review`、`debug`、`refactor`、`docs`、`security`、`migrate`、`perf`) と `@general`、`@explore` サブエージェントが、エンジニアリングループ全体をカバーします。セッションは耐久性があります。デタッチ、(リモートサーバへも) 再アタッチ、フォーク、共有、エクスポート、インポートがいつでも可能です。プロジェクトメモリは、セッション間でエージェントが学んだことを永続化します。MCP サーバ (OAuth 付き)、プラグイン、カスタムエージェント、カスタムツールを通じて拡張可能です。

Bolt は PolyForm Noncommercial 1.0.0 ライセンスの下でオープンソース化されています。

## Bolt を選ぶ理由

Bolt は開発者が実際に働く方法 — ターミナルで、複数のセッションを横断して、実際のコードベースで — を中心に設計されています。差別化ポイントは次のとおりです。

- **ターミナルファーストの TUI。** [Effect](https://effect.website)、[OpenTUI](https://github.com/opentui/opentui)、[SolidJS](https://www.solidjs.com) で構築された高速でキーボード駆動のインターフェイス。ネイティブに感じられるのは、実際にネイティブだからです。
- **エージェントのチーム全員。** 10 の専門エージェント — `code`、`plan`、`ask`、`code-review`、`debug`、`refactor`、`docs`、`security`、`migrate`、`perf` — に加え、リサーチと複数ステップ委譲用のサブエージェント。`Tab` で切り替えられます。
- **離れて再参加できるセッション。** セッションからデタッチし、後で (リモートサーバでも) アタッチできます。作業をいつでもフォーク、共有、エクスポート、インポートできます。セッションは SQLite に保存され、`bolt db` で完全に検査可能です。
- **拡張性を設計に組み込み。** 完全な OAuth サポート付きの MCP サーバ、プラグインシステム、GitHub 連携、組み込み API サーバ、Web UI。
- **デスクトップアプリ。** 同じエンジンをマルチウィンドウ・マルチタブのデスクトップ体験でラップ — 統合ターミナル、ファイルツリー、コマンドパレット、28 の UI 言語、自動更新付き。

## 組み込みエージェント

Bolt は 10 の専門エージェントを同梱しています。各エージェントは目的に合わせて定義されたファイルシステムアクセスレベルを持ちます。

| エージェント | アクセス | 説明 |
| --- | --- | --- |
| `code` | Full | デフォルト: コードの読み込み、書き込み、実行 |
| `plan` | Read | ファイルを変更せずにコードベースを探索して計画を作成 |
| `ask` | Read | 質問とリサーチ — ファイル編集なし |
| `code-review` | Read | 正確性、スタイル、セキュリティで変更をレビュー |
| `debug` | Full | 失敗したテスト、クラッシュ、ロジックエラーをデバッグ |
| `refactor` | Full | 各ステップでテスト検証を伴う安全なリファクタリング |
| `docs` | Edit | ドキュメントとコメントの記述と更新 |
| `security` | Read | セキュリティ監査: 脆弱性、シークレット、パターン |
| `migrate` | Full | フレームワークのアップグレードと依存関係の移行 |
| `perf` | Full | パフォーマンス分析と最適化 |

Markdown ファイルとして独自のエージェントを定義することも、`bolt agent create` で生成することもできます。

## デスクトップアプリ

Bolt はスタンドアロンのデスクトップアプリとしても提供されており、マルチウィンドウ・マルチタブのセッション管理、添付ファイルとクリップボード画像貼り付けをサポートするプロンプトコンポーザ、統合ターミナルとファイルツリー、コマンドパレット、キーバインド・モデル・プロバイダ・サーバのための完全な設定、ネイティブ通知、ディープリンク、Windows での WSL 統合、そして dev、beta、本番チャネル全体での自動更新を備えています。

デスクトップアプリを [リリースページ](https://github.com/Bolt-builder/bolt-cli/releases) からダウンロードするか、macOS で Gatekeeper を回避しつつワンラインでインストールできます。

```bash
curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install-desktop | bash
```
