Bolt posa un equip complet d'enginyeria d'IA directament al teu terminal. Es distribueix com un TUI ràpid impulsat per teclat i una aplicació d'escriptori nativa, tots dos recolzats pel mateix motor: deu agents especialitzats, sessions duradores persistents, gestió de servidors MCP amb OAuth, un sistema de plugins i suport per a cada proveïdor d'LLM important.

## Què fa Bolt

Bolt llegeix el teu codi base, entén el que estàs construint i envia codi amb tu — al terminal o com a aplicació d'escriptori. Cada sessió és duradora: desconnecta't, torna a connectar-te des d'una altra màquina, bifurca una branca de la conversa, comparteix un enllaç o exporta una transcripció sanejada.

## Posa'ns en marxa

<Steps>
  <Step title="Instal·la Bolt">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash
    ```
    O instal·la via npm: `npm i -g @bolt-builder/bolt-cli`
  </Step>
  <Step title="Obre el teu projecte">
    Navega a qualsevol directori de projecte i llança el TUI:
    ```bash
    cd my-project
    bolt
    ```
  </Step>
  <Step title="Configura un proveïdor">
    Al primer llançament, Bolt et demana afegir un proveïdor d'LLM. També pots executar:
    ```bash
    bolt providers
    ```
  </Step>
  <Step title="Comença a codificar amb IA">
    Escriu el teu prompt al peu del TUI, prem Enter i deixa que els agents de Bolt es posin a treballar. Canvia d'agent amb `Tab`.
  </Step>
</Steps>

<Tip>
  Utilitza `bolt run "explain this codebase"` per obtenir una resposta ràpida no interactiva sense obrir el TUI complet.
</Tip>
