Bolt és agnòstic al model per disseny. Sota el capó utilitza el **Vercel AI SDK** per parlar amb els proveïdors, cosa que significa que qualsevol proveïdor que el SDK suporti — Anthropic, OpenAI, Google, Amazon Bedrock, OpenRouter i més — funciona des del primer moment. El catàleg de proveïdors i models s'obté de [models.dev](https://models.dev), una base de dades mantinguda per la comunitat amb metadades de proveïdors i preus.

## Gestió de credencials de proveïdor

Utilitza `bolt providers` (amb l'àlies `bolt auth`) per afegir, llistar i eliminar credencials de proveïdor.

### Afegir o actualitzar credencials

```bash
bolt providers login
# or equivalently:
bolt auth login
```

Això llança un avís interactiu per seleccionar un proveïdor i introduir credencials. Per ometre el flux interactiu, passa els flags directament:

```bash
bolt providers login --provider anthropic
bolt providers login --provider openai --method "API key"
```

### Llistar proveïdors configurats

```bash
bolt providers list
# or:
bolt auth list
```

Mostra totes les credencials emmagatzemades i les claus API de proveïdors detectades des de variables d'entorn.

### Eliminar credencials

```bash
bolt providers logout
bolt providers logout anthropic
```

### Autenticació amb variables d'entorn

Per a canonades de CI o entorns sense capçalera, estableix la variable d'entorn de la clau API del proveïdor directament — no cal inici de sessió interactiu. Exemples comuns:

```bash
export ANTHROPIC_API_KEY="sk-ant-..."
export OPENAI_API_KEY="sk-..."
export GOOGLE_GENERATIVE_AI_API_KEY="AIza..."
```

Bolt llegeix aquestes variables automàticament a l'inici. `bolt providers list` mostrarà quines variables d'entorn ha detectat.

## Explorar els models disponibles

`bolt models` llista tots els models disponibles entre els teus proveïdors configurats.

```bash
# List all models
bolt models

# Filter to one provider
bolt models anthropic

# Show cost and capability metadata
bolt models --verbose

# Refresh the model catalog from models.dev
bolt models --refresh
```

<Tip>
  Executa `bolt models --verbose` per veure els preus per token d'entrada/sortida de cada model. Això facilita comparar les compensacions de cost abans de comprometre's amb un model per a una tasca de llarga durada.
</Tip>

### Format d'identificador del model

Els models sempre es referencien en format `provider/model`:

```
anthropic/claude-opus-4-5
openai/gpt-4o
google/gemini-2.5-pro
openrouter/anthropic/claude-opus-4-5
```

Utilitza aquest format allà on Bolt accepti un model — flags de CLI, fitxers de configuració i definicions d'agent.

## Seleccionar un model en temps d'execució

### Flag `--model` / `-m`

El flag `--model` està disponible a `bolt run`, `bolt commit` i `bolt review`:

```bash
bolt run --model anthropic/claude-opus-4-5 "refactor the payment module"
bolt commit --model openai/gpt-4o
bolt review --model google/gemini-2.5-pro --staged
```

### `--variant` — controlar l'esforç de raonament

Alguns models suporten nivells d'esforç de raonament configurables (per exemple, el pensament ampliat d'Anthropic, els models de raonament d'OpenAI). Utilitza `--variant` per seleccionar el nivell d'esforç:

```bash
bolt run --variant high "design a distributed rate limiter"
bolt run --variant minimal "rename this variable"
```

<Note>
  Els valors de variant disponibles depenen del proveïdor i del model. Els valors comuns són `minimal`, `low`, `medium`, `high` i `max`, però el conjunt exacte varia. Consulta la documentació del teu proveïdor o utilitza `bolt models --verbose` per veure les variants suportades per a un model determinat.
</Note>

### `--thinking` — mostrar blocs de raonament

Quan utilitzes un model que suporta pensament ampliat, passa `--thinking` per mostrar la cadena de pensament del model a la sortida:

```bash
bolt run --model anthropic/claude-opus-4-5 --variant high --thinking \
  "why does the token refresh logic race in the auth service?"
```

## Execucions paral·leles Best-of-N

`--best-of` dispara el mateix prompt a diversos models en paral·lel, després utilitza un model jutge per classificar les respostes i quedar-se amb la millor:

```bash
bolt run --best-of "anthropic/claude-opus-4-5,openai/gpt-4o,google/gemini-2.5-pro" \
  "implement a binary search tree with full test coverage"
```

El jutge per defecte és el model passat via `--model`, o la primera entrada de la llista `--best-of` si `--model` no està definit. El flag accepta una llista separada per comes d'identificadors `provider/model`.

<Tip>
  Best-of-N és especialment útil per a problemes algorísmics complexos o decisions d'arquitectura on diferents models poden aportar enfocaments genuïnament diferents. Deixa que Bolt els executi en paral·lel i triï el guanyador automàticament.
</Tip>
