Bolt és un agent de codificació d'IA amb prioritat al terminal construït amb [Effect](https://effect.website), [OpenTUI](https://github.com/opentui/opentui) i [SolidJS](https://www.solidjs.com). Apunta'l a qualsevol projecte i recull el context automàticament: explora el teu codi, segueix les teves convencions, executa ordres de shell, edita fitxers, executa proves i envia canvis.

Deu agents integrats (`code`, `plan`, `ask`, `code-review`, `debug`, `refactor`, `docs`, `security`, `migrate`, `perf`) més els subagents `@general` i `@explore` cobreixen tot el bucle d'enginyeria. Les sessions són duradores: desconnecta't, torna a connectar-te (fins i tot a un servidor remot), bifurca, comparteix, exporta i importa en qualsevol moment. La memòria del projecte persisteix el que l'agent aprèn entre sessions. Extensible via servidors MCP (amb OAuth), plugins, agents personalitzats i eines personalitzades.

Bolt és codi obert sota la llicència PolyForm Noncommercial 1.0.0.

## Per què Bolt?

Bolt està dissenyat al voltant de com els desenvolupadors treballen realment: al terminal, entre múltiples sessions, en codis base reals. Aquí hi ha el que el distingeix:

- **TUI amb prioritat al terminal.** Una interfície ràpida impulsada per teclat construïda amb [Effect](https://effect.website), [OpenTUI](https://github.com/opentui/opentui) i [SolidJS](https://www.solidjs.com). Se sent nadiu perquè ho és.
- **Un equip complet d'agents.** Deu agents especialitzats — `code`, `plan`, `ask`, `code-review`, `debug`, `refactor`, `docs`, `security`, `migrate` i `perf` — més subagents per a la recerca i la delegació multipas. Canvia entre ells amb `Tab`.
- **Sessions que pots deixar i tornar a unir-te.** Desconnecta't d'una sessió i torna a connectar-t'hi més tard, fins i tot en un servidor remot. Bifurca, comparteix, exporta i importa treball en qualsevol moment. Les sessions s'emmagatzemen en SQLite i són totalment inspeccionables amb `bolt db`.
- **Extensible per disseny.** Servidors MCP amb suport complet d'OAuth, un sistema de plugins, integració amb GitHub, un servidor API integrat i una interfície web.
- **Aplicació d'escriptori.** El mateix motor embolicat en una experiència d'escriptori multifinestra i multipestanya — amb un terminal integrat, arbre de fitxers, paleta d'ordres, 28 idiomes d'interfície i actualitzacions automàtiques.

## Agents integrats

Bolt inclou deu agents especialitzats. Cada agent té un nivell definit d'accés al sistema de fitxers que coincideix amb el seu propòsit.

| Agent | Accés | Descripció |
| --- | --- | --- |
| `code` | Full | Predeterminat: llegeix, escriu i executa codi |
| `plan` | Read | Explora el codi base i produeix un pla sense canviar fitxers |
| `ask` | Read | Preguntes i recerca — sense edicions de fitxers |
| `code-review` | Read | Revisa canvis per correcció, estil i seguretat |
| `debug` | Full | Depura proves fallides, bloquejos i errors de lògica |
| `refactor` | Full | Refactorització segura amb verificació de proves a cada pas |
| `docs` | Edit | Escriu i actualitza documentació i comentaris |
| `security` | Read | Auditoria de seguretat: vulnerabilitats, secrets, patrons |
| `migrate` | Full | Actualitzacions de framework i migracions de dependències |
| `perf` | Full | Anàlisi de rendiment i optimització |

També pots definir els teus propis agents com a fitxers Markdown o generar-ne un amb `bolt agent create`.

## Aplicació d'escriptori

Bolt també es distribueix com una aplicació d'escriptori autònoma amb gestió de sessions multifinestra i multipestanya, un compositor de prompt amb suport d'adjunts i enganxament d'imatges del porta-retalls, un terminal integrat i arbre de fitxers, una paleta d'ordres, configuració completa per a combinacions de tecles, models, proveïdors i servidors, notificacions natives, enllaços profunds, integració amb WSL a Windows i actualitzacions automàtiques a través dels canals dev, beta i producció.

Descarrega l'aplicació d'escriptori des de la [pàgina de llançaments](https://github.com/Bolt-builder/bolt-cli/releases), o instal·la-la en una línia a macOS sense el detour de Gatekeeper:

```bash
curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install-desktop | bash
```
