## Bolt 能做什么

Bolt 读取你的代码库，理解你正在构建的内容，并与你一起交付代码——在终端或桌面应用中。每个会话都是持久的：可分离、从另一台机器重新连接、分叉一个对话分支、分享链接，或导出一份脱敏的会话记录。

## 上手运行

<Steps>
  <Step title="安装 Bolt">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash
    ```
    或者通过 npm 安装：`npm i -g @bolt-builder/bolt-cli`
  </Step>
  <Step title="打开你的项目">
    进入任意项目目录并启动 TUI：
    ```bash
    cd my-project
    bolt
    ```
  </Step>
  <Step title="配置提供商">
    首次启动时 Bolt 会提示你添加 LLM 提供商。你也可以运行：
    ```bash
    bolt providers
    ```
  </Step>
  <Step title="开始与 AI 编码">
    在 TUI 底部输入你的提示，按 Enter，让 Bolt 的代理开始工作。使用 `Tab` 切换代理。
  </Step>
</Steps>

<Tip>
  使用 `bolt run "explain this codebase"` 无需打开完整 TUI 就能快速获得非交互式回答。
</Tip>
