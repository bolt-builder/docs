自定义工具允许你将任何可编写脚本的东西（shell 脚本、Node/Bun/Python 程序、小型二进制文件）作为代理可以按名称调用的工具公开。它们是让 Bolt 访问你项目自身的构建、部署或数据工作流的最简单方式。

## 它们在哪里

将文件放入以下之一：

- `.opencode/tool/` — 项目范围,与仓库一起签入。
- `.opencode/tools/` — 接受作为上面的别名。

每个文件成为以文件命名的工具（去掉扩展名）。工具在 Bolt 下次启动时自动加载。

## 工具的结构

自定义工具在头部声明其名称、描述和输入 schema,然后实现行为。确切的形式取决于你选择的运行时（shell 脚本、TypeScript 等）,但每个工具都必须：

1. 为其输入公布 JSON Schema,以便模型知道如何调用它。
2. 返回一个值（或错误）,Bolt 可以在 TUI 中渲染并反馈给模型。

一旦加载,该工具就会出现在代理的工具列表中,与 `bash` 和 `grep` 等内置工具并列,并由相同的[权限](/concepts/permissions)系统门控。

## 何时使用自定义工具 vs MCP 服务器

- **自定义工具** — 小型、项目特定、跨项目无复用。编写速度快。
- **MCP 服务器** — 跨项目共享,或包装带认证的真实外部服务。参见 [MCP 服务器](/extending/mcp-servers)。
- **插件工具** — 作为 npm 包与其他扩展点一起分发。参见[插件](/extending/plugins)。
