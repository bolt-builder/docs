桌面应用是同一个 Bolt 引擎,包装在原生外壳中,增加了一些终端无法轻松完成的功能。

## 内部功能

- **多窗口、多标签会话。** 跨项目并行运行多个代理,每个都在自己的标签中。
- **提示编辑器。** 具有文件附件和剪贴板图像粘贴的丰富输入 — 将屏幕截图直接拖入提示。
- **集成终端 \+ 文件树。** 真实的 shell 和聊天旁边的项目浏览器。
- **命令面板。** `Cmd/Ctrl+K` 在会话之间跳转、运行任何 Bolt 命令,或触发斜杠命令。
- **设置。** 键绑定、模型、提供商和已配置的服务器,全部可在真实的设置 UI 中编辑。
- **原生通知。** 长时间运行的代理完成时操作系统会通知你。
- **深度链接。** `bolt://` URL 可从任何地方跳转到会话。
- **Windows 上的 WSL 集成。** 开箱即用地针对你的 WSL 环境运行。
- **28 种 UI 语言。**
