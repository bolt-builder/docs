Bolt exponerar en enda `bolt`-binär med en rik uppsättning underkommandon. Att köra `bolt` utan argument öppnar det fullständiga terminal-UI:t. Alla andra underkommandon listas nedan. Använd `bolt <command> --help` när som helst för inline-hjälp.

<Accordion title="bolt (standard — starta TUI)">
  Öppnar det interaktiva terminal-UI:t i den aktuella katalogen. Bolt upptäcker automatiskt din projektkontext, laddar konfiguration och ansluter till alla konfigurerade leverantörer.

  ```bash
  bolt
  bolt --mini          # minimal split-footer interactive mode
  bolt --log-level DEBUG
  ```

  **Globala flaggor** — tillgängliga på varje kommando:

  | Flagga | Typ | Beskrivning |
  | --- | --- | --- |
  | `--print-logs` | boolean | Skriv ut loggutdata till stderr |
  | `--log-level` | `DEBUG`\|`INFO`\|`WARN`\|`ERROR` | Sätt loggens verbositetsnivå |
  | `--pure` | boolean | Kör utan att ladda några externa plugins |
  | `--help`, `-h` | boolean | Visa hjälptext |
  | `--version`, `-v` | boolean | Skriv ut det installerade versionsnumret |
</Accordion>

<Accordion title="bolt run [prompt]">
  Kör Bolt med en enskild prompt i icke-interaktivt läge. Bolt startar en in-process-server, skickar prompten till den aktiva sessionen, strömmar svaret till stdout och avslutar sedan. Piping av stdin eller `--file` kan användas för att bifoga kontext.

  ```bash
  # Basic non-interactive prompt
  bolt run "explain the auth module"
  
  # Continue the most recent session
  bolt run --continue "now add error handling"
  
  # Use a specific model with a specific agent
  bolt run --model anthropic/claude-opus-4-5 --agent code "refactor auth.ts"
  
  # Stream raw JSON events for tooling integration
  bolt run --format json "summarize changes"
  
  # Fire the same task at multiple models and keep the best result
  bolt run --best-of "anthropic/claude-opus-4-5,openai/gpt-4o" "write unit tests"
  
  # Attach a file as context
  bolt run --file ./openapi.yaml "generate a client SDK"
  
  # Attach to a remote server and run a prompt there
  bolt run --attach http://my-server:4096 --dir /projects/api "what tests are failing?"
  
  # Skip all permission prompts (dangerous)
  bolt run --auto "delete all TODO comments"
  ```

  | Flagga | Alias | Typ | Beskrivning |
  | --- | --- | --- | --- |
  | `--command` |  | string | Slash-kommando att köra; skicka argument som meddelandet |
  | `--continue` | `-c` | boolean | Fortsätt den senaste sessionen |
  | `--session` | `-s` | string | Sessions-ID att fortsätta |
  | `--fork` |  | boolean | Förgrena sessionen innan fortsättning (kräver `--continue` eller `--session`) |
  | `--share` |  | boolean | Dela sessionen efter att den avslutats |
  | `--model` | `-m` | string | Modell att använda i formatet `provider/model` |
  | `--best-of` |  | string | Kommaseparerad lista av `provider/model`; kör uppgiften parallellt, rangordnar resultat, behåller vinnaren |
  | `--agent` |  | string | Agent att använda (t.ex. `code`, `ask`, `review`) |
  | `--format` |  | `default`\|`json` | Utdataformat; `json` strömmar rå ny-radseparerad JSON-händelser |
  | `--file` | `-f` | string\[\] | Fil(er) att bifoga som kontext |
  | `--title` |  | string | Titel för sessionen |
  | `--attach` |  | string | Kör mot en fjärr-Bolt-server (t.ex. `http://localhost:4096`) |
  | `--password` | `-p` | string | Basic auth-lösenord för fjärrservern |
  | `--username` | `-u` | string | Basic auth-användarnamn för fjärrservern |
  | `--dir` |  | string | Arbetskatalog; om `--attach` är satt är detta katalogen på fjärrservern |
  | `--port` |  | number | Port för den lokala in-process-servern (slumpmässig om utelämnad) |
  | `--variant` |  | string | Reasoning-effort-nivå, leverantörsspecifik (t.ex. `high`, `max`, `minimal`) |
  | `--thinking` |  | boolean | Visa reasoning/thinking-block i utdata |
  | `--mini` |  | boolean | Starta det minimala split-footer interaktiva UI:t (dolt) |
  | `--interactive` | `-i` | boolean | Framtvinga direkt interaktivt split-footer-läge |
  | `--auto` |  | boolean | Auto-godkänn behörigheter som inte uttryckligen nekats |
  | `--yolo` |  | boolean | Hoppa över alla behörighetsprompter (alias för `--auto`, dolt) |
  | `--dangerously-skip-permissions` |  | boolean | Hoppa över alla behörighetskontroller (dolt) |
  | `--demo` |  | boolean | Aktivera direkta interaktiva demo-slash-kommandon (dolt) |
</Accordion>

<Accordion title="bolt attach <url>">
  Anslut den fullständiga TUI:n till en körande Bolt-server. Servern kan vara lokal eller fjärran. Skicka `--mini` för att använda det minimala split-footer-UI:t istället för den fullständiga TUI:n.

  ```bash
  bolt attach http://localhost:4096
  bolt attach http://remote-host:4096 --dir /projects/api
  bolt attach http://remote-host:4096 --session abc123 --mini
  bolt attach http://remote-host:4096 --password secret --username alice
  ```

  | Flagga | Alias | Typ | Beskrivning |
  | --- | --- | --- | --- |
  | `--dir` |  | string | Katalog på fjärrservern |
  | `--continue` | `-c` | boolean | Fortsätt den senaste sessionen på fjärrservern |
  | `--session` | `-s` | string | Sessions-ID att fortsätta |
  | `--fork` |  | boolean | Förgrena sessionen vid fortsättning |
  | `--password` | `-p` | string | Basic auth-lösenord |
  | `--username` | `-u` | string | Basic auth-användarnamn |
  | `--mini` |  | boolean | Använd det minimala interaktiva UI:t |
  | `--no-replay` |  | boolean | Inaktivera sessionshistorikuppspelning vid återupptag och efter storleksändring (kräver `--mini`) |
  | `--replay-limit` |  | number | Begränsa synlig uppspelning till de N senaste meddelandena (kräver `--mini`) |
</Accordion>

<Accordion title="bolt serve">
  Starta en headless Bolt API-server. Servern exponerar ett REST\+SSE API som TUI:n, `bolt run --attach` och `bolt attach` kan ansluta till. Binda på `0.0.0.0` för att göra den nåbar från andra maskiner — sätt alltid `BOLT_SERVER_PASSWORD` när du gör det.

  ```bash
  bolt serve
  bolt serve --hostname 0.0.0.0 --port 4096
  bolt serve --mdns
  ```

  | Flagga | Typ | Beskrivning |
  | --- | --- | --- |
  | `--hostname` | string | Adress att binda (standard: `127.0.0.1`) |
  | `--port` | number | Port att lyssna på (slumpmässig om utelämnad) |
  | `--mdns` | boolean | Aktivera mDNS-tjänsteupptäckt (sätter hostname som standard till `0.0.0.0`) |
  | `--mdns-domain` | string | Anpassat domännamn för mDNS-tjänsten (standard: `opencode.local`) |
  | `--cors` | string\[\] | Ytterligare domäner att tillåta för CORS |

  <Warning>
    `BOLT_SERVER_PASSWORD` är inte satt som standard. Servern loggar en varning och accepterar alla anslutningar tills du sätter det.
  </Warning>
</Accordion>

<Accordion title="bolt session">
  Hantera Bolt-sessioner lagrade i den lokala SQLite-databasen.

  **Underkommandon**

  ```bash
  bolt session list                         # list all root sessions
  bolt session list --format json           # machine-readable output
  bolt session list -n 20                   # show 20 most recent sessions
  bolt session delete <sessionID>           # permanently delete a session
  ```

  **Flaggor för `bolt session list`**

  | Flagga | Alias | Typ | Beskrivning |
  | --- | --- | --- | --- |
  | `--max-count` | `-n` | number | Begränsa utdata till de N senaste sessionerna |
  | `--format` |  | `table`\|`json` | Utdataformat (standard: `table`) |
</Accordion>

<Accordion title="bolt agent">
  Lista och skapa anpassade agenter. Agenter är markdown-filer med YAML-frontmatter som definierar en systemprompt, behörigheter och läge.

  ```bash
  bolt agent list                           # list all available agents
  bolt agent create                         # interactive agent creation wizard
  
  # Non-interactive creation
  bolt agent create \
    --description "Audit code for security vulnerabilities" \
    --mode primary \
    --permissions "read,grep,glob" \
    --model anthropic/claude-opus-4-5 \
    --path .bolt/agents
  ```

  **Flaggor för `bolt agent create`**

  | Flagga | Alias | Typ | Beskrivning |
  | --- | --- | --- | --- |
  | `--path` |  | string | Katalogsökväg att skriva agentfilen till |
  | `--description` |  | string | Naturlig språkbeskrivning av vad agenten ska göra |
  | `--mode` |  | `all`\|`primary`\|`subagent` | Om agenten agerar som primär agent, underagent eller båda |
  | `--permissions` | `--tools` | string | Kommaseparerad lista över tillåtna behörigheter (standard: alla) |
  | `--model` | `-m` | string | Modell att använda i formatet `provider/model` |
</Accordion>

<Accordion title="bolt providers (alias: auth)">
  Hantera AI-leverantörsinloggningsuppgifter interaktivt. Inloggningsuppgifter lagras i din OS-datakatalog (`~/.local/share/bolt/auth.json` på Linux, `~/Library/Application Support/bolt/auth.json` på macOS).

  ```bash
  bolt providers             # interactive credential management menu
  bolt auth                  # alias for bolt providers
  
  bolt providers list        # list stored credentials and active env vars
  bolt providers login       # add a credential for a provider
  bolt providers login --provider anthropic
  bolt providers login --provider anthropic --method "API Key"
  bolt providers logout      # remove a stored credential
  bolt providers logout --provider openai
  ```
</Accordion>

<Accordion title="bolt models [provider]">
  Lista alla modeller tillgängliga från dina konfigurerade leverantörer.

  ```bash
  bolt models                         # list all models from all providers
  bolt models anthropic               # filter to a single provider
  bolt models --verbose               # include cost metadata in output
  bolt models --refresh               # force-refresh the models.dev cache
  ```

  | Flagga | Typ | Beskrivning |
  | --- | --- | --- |
  | `--verbose` | boolean | Inkludera JSON-kostnadsmetadata för varje modell |
  | `--refresh` | boolean | Uppdatera modellcachen från models.dev |
</Accordion>

<Accordion title="bolt mcp">
  Hantera Model Context Protocol (MCP)-servrar. Bolt stöder både fjärr-(HTTP/SSE) servrar med OAuth och lokala (stdio) servrar.

  ```bash
  bolt mcp add                              # interactive wizard to add a server
  bolt mcp add my-server --url https://mcp.example.com/tools
  bolt mcp add local-server -- npx @my-org/mcp-server
  bolt mcp list                             # show all configured servers and status
  bolt mcp auth <name>                      # run the OAuth flow for a server
  bolt mcp auth list                        # show OAuth status for all servers
  bolt mcp logout <name>                    # remove stored OAuth tokens
  bolt mcp debug <name>                     # probe connectivity and OAuth config
  ```

  **Flaggor för `bolt mcp add`**

  | Flagga | Typ | Beskrivning |
  | --- | --- | --- |
  | `--url` | string | URL för en fjärr-MCP-server |
  | `--env` | string\[\] | Miljövariabel för en lokal server (`KEY=VALUE`) |
  | `--header` | string\[\] | HTTP-header för en fjärrserver (`KEY=VALUE`) |
</Accordion>

<Accordion title="bolt plugin install <module>">
  Installera ett Bolt-plugin från npm och uppdatera relevant konfigurationsfil. Plugins kan utöka TUI:n, lägga till nya slash-kommandon eller registrera nya leverantörer.

  ```bash
  bolt plugin install @my-org/bolt-plugin
  bolt plugin install @my-org/bolt-plugin --global      # install to global config
  bolt plugin install @my-org/bolt-plugin --force        # replace existing version
  ```

  | Flagga | Alias | Typ | Beskrivning |
  | --- | --- | --- | --- |
  | `--global` | `-g` | boolean | Lägg till pluginet i den globala konfigurationen istället för projektkonfigurationen |
  | `--force` | `-f` | boolean | Ersätt en redan konfigurerad pluginversion |
</Accordion>

<Accordion title="bolt github">
  Hantera Bolts GitHub Actions-integration, som låter Bolt reagera på pull requests, issues och andra GitHub-händelser.

  ```bash
  bolt github install           # scaffold the GitHub Actions workflow in your repo
  bolt github run               # run the GitHub agent locally (for testing)
  bolt github run --event pull_request --token ghp_xxx
  ```

  **Flaggor för `bolt github run`**

  | Flagga | Typ | Beskrivning |
  | --- | --- | --- |
  | `--event` | string | GitHub-händelsenamn att simulera (t.ex. `pull_request`) |
  | `--token` | string | GitHub personal access token |
</Accordion>

<Accordion title="bolt pr <number>">
  Checka ut en GitHub pull request som en lokal gren med hjälp av `gh`-CLI:t och starta sedan Bolt i den utcheckade katalogen. Om PR-beskrivningen innehåller en session-share-länk importerar Bolt sessionen automatiskt.

  ```bash
  bolt pr 123
  ```

  <Note>
    Detta kommando kräver att [GitHub CLI (`gh`)](https://cli.github.com/) är installerat och autentiserat.
  </Note>
</Accordion>

<Accordion title="bolt commit">
  Generera ett commit-meddelande för staged (eller alla spårade) ändringar med en AI-modell och committa sedan. Modellen inspekterar den senaste commit-historiken för stilkontext.

  ```bash
  bolt commit                        # commit staged changes
  bolt commit --all                  # stage and commit all tracked changes
  bolt commit --dry-run              # print the generated message without committing
  bolt commit --model openai/gpt-4o  # use a specific model
  ```

  | Flagga | Alias | Typ | Beskrivning |
  | --- | --- | --- | --- |
  | `--all` | `-a` | boolean | Committa alla spårade ändringar, inte bara staged |
  | `--dry-run` |  | boolean | Skriv ut det genererade meddelandet utan att committa |
  | `--model` | `-m` | string | Modell att använda i formatet `provider/model` |
</Accordion>

<Accordion title="bolt review">
  Kör en AI-kodgranskning på en diff och avsluta med kod `0` (pass) eller `1` (fail). Agenten `code-review` undersöker diffen för korrekthet, stil och säkerhetsproblem och sänder ut en `Verdict: PASS`- eller `Verdict: FAIL`-rad.

  ```bash
  bolt review                          # review uncommitted changes (git diff HEAD)
  bolt review --staged                 # review only staged changes
  bolt review --branch main            # review changes since merge base with main
  bolt review --model openai/o3        # use a specific model
  ```

  | Flagga | Alias | Typ | Beskrivning |
  | --- | --- | --- | --- |
  | `--staged` |  | boolean | Granska endast staged-ändringar |
  | `--branch` |  | string | Granska ändringar sedan merge base med den här grenen |
  | `--model` | `-m` | string | Modell att använda i formatet `provider/model` |

  <Note>
    Avslutningskoder: `0` = PASS, `1` = FAIL, `2` = utfall kunde inte bestämmas.
  </Note>
</Accordion>

<Accordion title="bolt export [sessionID]">
  Exportera en session som JSON till stdout. Användbart för arkivering, delning eller matning in i andra verktyg. Skicka `--sanitize` innan du delar offentligt för att redigera bort filsökvägar, prompter och annat känsligt transkriptinnehåll.

  ```bash
  bolt export                          # interactive session picker, then write to stdout
  bolt export abc123                   # export a specific session
  bolt export abc123 --sanitize        # redact secrets and paths
  bolt export abc123 > session.json    # write to a file
  ```

  | Flagga | Typ | Beskrivning |
  | --- | --- | --- |
  | `--sanitize` | boolean | Redigera bort känslig data (filsökvägar, prompttext, verktygs-I/O) före export |
</Accordion>

<Accordion title="bolt import <file>">
  Importera en tidigare exporterad session till den lokala databasen. Accepterar antingen en lokal JSON-fil eller en delnings-URL för sessioner.

  ```bash
  bolt import ./session.json
  bolt import https://opncd.ai/share/abc123
  ```
</Accordion>

<Accordion title="bolt stats">
  Visa aggregerad tokenanvändnings- och kostnadsstatistik över alla sessioner. Utdata inkluderar en översiktstabell, kostnads- och tokenuppdelning, modellanvändning och ett stapeldiagram över verktygsanvändning.

  ```bash
  bolt stats
  bolt stats --days 7             # last 7 days only
  bolt stats --models             # include per-model breakdown
  bolt stats --models 5           # show top 5 models
  bolt stats --tools 10           # show top 10 tools
  bolt stats --project ""         # filter to the current project only
  ```

  | Flagga | Typ | Beskrivning |
  | --- | --- | --- |
  | `--days` | number | Begränsa till de senaste N dagarna (standard: all tid) |
  | `--tools` | number | Antal verktyg att visa i diagrammet över verktygsanvändning |
  | `--models` | boolean\|number | Visa modellstatistik; skicka ett tal för att begränsa listan |
  | `--project` | string | Filtrera efter projekt-ID; tom sträng betyder aktuellt projekt |
</Accordion>

<Accordion title="bolt logs">
  Skriv ut Bolts applikationslogg. Loggen lagras i OS-loggkatalogen (t.ex. `~/.local/state/bolt/opencode.log`).

  ```bash
  bolt logs                        # print the last 1000 lines
  bolt logs --tail 200             # print the last 200 lines
  bolt logs --follow               # stream new lines as they are written
  bolt logs -f                     # alias for --follow
  ```

  | Flagga | Alias | Typ | Beskrivning |
  | --- | --- | --- | --- |
  | `--tail` |  | number | Antal avslutande rader att skriva ut (standard: 1000) |
  | `--follow` | `-f` | boolean | Strömma nya loggrader i realtid |
</Accordion>

<Accordion title="bolt db [query]">
  Fråga eller inspektera den lokala SQLite-sessionsdatabasen direkt.

  ```bash
  bolt db path                                  # print the database file path
  bolt db "SELECT id, title FROM sessions"      # run a SQL query (TSV output)
  bolt db "SELECT * FROM sessions" --format json
  ```

  | Flagga | Typ | Beskrivning |
  | --- | --- | --- |
  | `--format` | `json`\|`tsv` | Utdataformat för frågeresultat (standard: `tsv`) |
</Accordion>

<Accordion title="bolt upgrade [target]">
  Uppgradera Bolt till senaste versionen eller en specifik version. Bolt upptäcker installationsmetoden automatiskt och använder lämplig pakethanterare.

  ```bash
  bolt upgrade                         # upgrade to the latest version
  bolt upgrade 0.2.0                   # upgrade (or downgrade) to a specific version
  bolt upgrade --method npm            # force a specific installation method
  bolt upgrade --method curl
  ```

  | Flagga | Alias | Typ | Beskrivning |
  | --- | --- | --- | --- |
  | `--method` | `-m` | `curl`\|`npm`\|`pnpm`\|`bun`\|`brew`\|`choco`\|`scoop` | Installationsmetod att använda |
</Accordion>

<Accordion title="bolt uninstall">

  ```bash
  bolt uninstall
  ```
</Accordion>

<Accordion title="bolt debug">
  En samling underkommandon för felsökning och introspektion. Användbart vid buggrapporter eller diagnostik av oväntat beteende.

  ```bash
  bolt debug info          # print version, OS, terminal, and loaded plugins
  bolt debug config        # print the fully-resolved configuration
  bolt debug paths         # print all global data/config/cache directories
  bolt debug lsp           # inspect LSP state
  bolt debug ripgrep       # test ripgrep availability
  bolt debug file          # inspect file tool behavior
  bolt debug scrap         # scratchpad for debugging
  bolt debug skill         # inspect available skills
  bolt debug snapshot      # inspect session snapshots
  bolt debug startup       # measure startup time
  bolt debug agents        # list agents and their resolved config
  bolt debug v2            # inspect V2 session core state
  bolt debug wait          # block indefinitely (for process debugging)
  ```
</Accordion>

<Accordion title="bolt acp">
  Starta en ACP (Agent Client Protocol)-server. ACP är protokollet som används av editor-integrationer som [Zed](https://zed.dev) för att kommunicera med Bolt över stdin/stdout.

  ```bash
  bolt acp
  bolt acp --cwd /path/to/project
  ```

  | Flagga | Typ | Beskrivning |
  | --- | --- | --- |
  | `--cwd` | string | Arbetskatalog för servern (standard: `process.cwd()`) |
  | `--hostname` | string | Bind-hostname (standard: `127.0.0.1`) |
  | `--port` | number | Bind-port |
  | `--mdns` | boolean | Aktivera mDNS-tjänsteupptäckt |
  | `--mdns-domain` | string | Anpassat domännamn för mDNS-tjänsten (standard: `opencode.local`) |
  | `--cors` | string\[\] | Ytterligare domäner att tillåta för CORS |
</Accordion>
