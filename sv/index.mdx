Bolt placerar ett komplett AI-utvecklingsteam direkt i din terminal. Den levereras som en snabb, tangentbordsdriven TUI och en inbyggd skrivbordsapp, båda stödda av samma motor: tio specialiserade agenter, beständiga och robusta sessioner, MCP-serverhantering med OAuth, ett pluginsystem och stöd för alla större LLM-leverantörer.

## Vad Bolt gör

Bolt läser din kodbas, förstår vad du bygger och levererar kod tillsammans med dig – i terminalen eller som en skrivbordsapp. Varje session är beständig: koppla från, återanslut från en annan maskin, förgrena en gren av konversationen, dela en länk eller exportera ett sanerat transkript.

## Kom igång

<Steps>
  <Step title="Installera Bolt">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash
    ```
    Eller installera via npm: `npm i -g @bolt-builder/bolt-cli`
  </Step>
  <Step title="Öppna ditt projekt">
    Navigera till valfri projektkatalog och starta TUI:n:
    ```bash
    cd my-project
    bolt
    ```
  </Step>
  <Step title="Konfigurera en leverantör">
    Vid första starten uppmanar Bolt dig att lägga till en LLM-leverantör. Du kan även köra:
    ```bash
    bolt providers
    ```
  </Step>
  <Step title="Börja koda med AI">
    Skriv din prompt i TUI-foten, tryck på Enter och låt Bolts agenter sätta igång. Växla mellan agenter med `Tab`.
  </Step>
</Steps>

<Tip>
  Använd `bolt run "explain this codebase"` för ett snabbt icke-interaktivt svar utan att öppna hela TUI:n.
</Tip>
