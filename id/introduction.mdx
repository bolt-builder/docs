Bolt adalah agent coding AI yang mengutamakan terminal, dibangun di atas [Effect](https://effect.website), [OpenTUI](https://github.com/opentui/opentui), dan [SolidJS](https://www.solidjs.com). Arahkan ke proyek mana pun dan Bolt mengambil konteksnya secara otomatis: mengeksplorasi kode kamu, mengikuti konvensi kamu, mengeksekusi perintah shell, mengedit file, menjalankan tes, dan mengirimkan perubahan.

Sepuluh agent bawaan (`code`, `plan`, `ask`, `code-review`, `debug`, `refactor`, `docs`, `security`, `migrate`, `perf`) plus subagent `@general` dan `@explore` mencakup seluruh loop engineering. Sesi tahan lama: detach, re-attach (bahkan ke server remote), fork, share, export, dan import kapan saja. Project memory mempertahankan apa yang dipelajari agent antar sesi. Dapat diperluas via MCP server (dengan OAuth), plugin, custom agent, dan custom tool.

Bolt adalah sumber terbuka di bawah lisensi PolyForm Noncommercial 1.0.0.

## Mengapa Bolt?

Bolt dirancang seputar cara pengembang benar-benar bekerja: di terminal, di banyak sesi, pada basis kode nyata. Berikut yang membedakannya:

- **TUI yang mengutamakan terminal.** Antarmuka yang cepat dan berbasis keyboard yang dibangun dengan [Effect](https://effect.website), [OpenTUI](https://github.com/opentui/opentui), dan [SolidJS](https://www.solidjs.com). Terasa native karena memang native.
- **Seluruh tim agent.** Sepuluh agent khusus — `code`, `plan`, `ask`, `code-review`, `debug`, `refactor`, `docs`, `security`, `migrate`, dan `perf` — plus subagent untuk penelitian dan delegasi multi-langkah. Beralih antar mereka dengan `Tab`.
- **Sesi yang dapat kamu tinggalkan dan gabungkan kembali.** Detach dari sesi dan attach nanti, bahkan di server remote. Fork, share, export, dan import pekerjaan kapan saja. Sesi disimpan di SQLite dan sepenuhnya dapat diperiksa dengan `bolt db`.
- **Dapat diperluas secara desain.** MCP server dengan dukungan OAuth penuh, sistem plugin, integrasi GitHub, server API bawaan, dan UI web.
- **Aplikasi desktop.** Engine yang sama dibungkus dalam pengalaman desktop multi-window dan multi-tab — dengan terminal terintegrasi, file tree, command palette, 28 bahasa UI, dan auto-update.

## Agent bawaan

Bolt hadir dengan sepuluh agent khusus. Setiap agent memiliki tingkat akses file-system yang ditentukan agar cocok dengan tujuannya.

| Agent | Akses | Deskripsi |
| --- | --- | --- |
| `code` | Full | Default: membaca, menulis, dan menjalankan kode |
| `plan` | Read | Mengeksplorasi basis kode dan menghasilkan rencana tanpa mengubah file |
| `ask` | Read | Pertanyaan dan penelitian — tanpa edit file |
| `code-review` | Read | Meninjau perubahan untuk kebenaran, gaya, dan keamanan |
| `debug` | Full | Men-debug tes yang gagal, crash, dan kesalahan logika |
| `refactor` | Full | Refactoring aman dengan verifikasi tes di setiap langkah |
| `docs` | Edit | Menulis dan memperbarui dokumentasi dan komentar |
| `security` | Read | Audit keamanan: kerentanan, secret, pola |
| `migrate` | Full | Upgrade framework dan migrasi dependensi |
| `perf` | Full | Analisis performa dan optimasi |

Kamu juga dapat mendefinisikan agent kamu sendiri sebagai file Markdown atau menghasilkan satu dengan `bolt agent create`.

## Aplikasi desktop

Bolt juga hadir sebagai aplikasi desktop yang berdiri sendiri dengan manajemen sesi multi-window dan multi-tab, prompt composer dengan dukungan lampiran dan paste gambar dari clipboard, terminal dan file tree terintegrasi, command palette, setelan penuh untuk keybind, model, provider dan server, notifikasi native, deep link, integrasi WSL di Windows, dan auto-update di seluruh channel dev, beta, dan production.

Unduh aplikasi desktop dari [halaman rilis](https://github.com/Bolt-builder/bolt-cli/releases), atau instal dalam satu baris di macOS tanpa jalan memutar Gatekeeper:

```bash
curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install-desktop | bash
```
