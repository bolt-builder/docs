Bolt dirancang untuk agnostik terhadap model. Di balik layar, Bolt menggunakan **Vercel AI SDK** untuk berbicara dengan provider, yang berarti provider apa pun yang didukung SDK — Anthropic, OpenAI, Google, Amazon Bedrock, OpenRouter, dan lainnya — bekerja langsung. Katalog provider dan model bersumber dari [models.dev](https://models.dev), database metadata dan harga provider yang dikelola komunitas.

## Mengelola kredensial provider

Gunakan `bolt providers` (alias `bolt auth`) untuk menambahkan, mendaftar, dan menghapus kredensial provider.

### Menambah atau memperbarui kredensial

```bash
bolt providers login
# or equivalently:
bolt auth login
```

Ini meluncurkan prompt interaktif untuk memilih provider dan memasukkan kredensial. Untuk melewati alur interaktif, teruskan flag secara langsung:

```bash
bolt providers login --provider anthropic
bolt providers login --provider openai --method "API key"
```

### Menampilkan provider yang dikonfigurasi

```bash
bolt providers list
# or:
bolt auth list
```

Menampilkan semua kredensial yang disimpan dan API key provider apa pun yang terdeteksi dari variabel lingkungan.

### Menghapus kredensial

```bash
bolt providers logout
bolt providers logout anthropic
```

### Autentikasi variabel lingkungan

Untuk pipeline CI atau lingkungan headless, atur variabel lingkungan API key provider secara langsung — tidak perlu login interaktif. Contoh umum:

```bash
export ANTHROPIC_API_KEY="sk-ant-..."
export OPENAI_API_KEY="sk-..."
export GOOGLE_GENERATIVE_AI_API_KEY="AIza..."
```

Bolt membaca variabel-variabel ini secara otomatis saat startup. `bolt providers list` akan menampilkan variabel lingkungan mana yang terdeteksi.

## Menelusuri model yang tersedia

`bolt models` menampilkan setiap model yang tersedia di seluruh provider yang telah kamu konfigurasi.

```bash
# List all models
bolt models

# Filter to one provider
bolt models anthropic

# Show cost and capability metadata
bolt models --verbose

# Refresh the model catalog from models.dev
bolt models --refresh
```

<Tip>
  Jalankan `bolt models --verbose` untuk melihat harga token input/output untuk setiap model. Ini memudahkan perbandingan trade-off biaya sebelum memutuskan model untuk tugas yang berjalan lama.
</Tip>

### Format pengenal model

Model selalu direferensikan dalam format `provider/model`:

```
anthropic/claude-opus-4-5
openai/gpt-4o
google/gemini-2.5-pro
openrouter/anthropic/claude-opus-4-5
```

Gunakan format ini di mana pun Bolt menerima sebuah model — flag CLI, file config, dan definisi agent.

## Memilih model saat runtime

### Flag `--model` / `-m`

Flag `--model` tersedia di `bolt run`, `bolt commit`, dan `bolt review`:

```bash
bolt run --model anthropic/claude-opus-4-5 "refactor the payment module"
bolt commit --model openai/gpt-4o
bolt review --model google/gemini-2.5-pro --staged
```

### `--variant` — mengontrol reasoning effort

Beberapa model mendukung level reasoning effort yang dapat dikonfigurasi (misalnya, extended thinking Anthropic, model reasoning OpenAI). Gunakan `--variant` untuk memilih tingkat effort:

```bash
bolt run --variant high "design a distributed rate limiter"
bolt run --variant minimal "rename this variable"
```

<Note>
  Nilai varian yang tersedia bergantung pada provider dan model. Nilai umum adalah `minimal`, `low`, `medium`, `high`, dan `max`, tetapi rangkaian pastinya bervariasi. Periksa dokumentasi provider kamu atau gunakan `bolt models --verbose` untuk melihat varian yang didukung untuk model tertentu.
</Note>

### `--thinking` — tampilkan blok reasoning

Saat menggunakan model yang mendukung extended thinking, teruskan `--thinking` untuk menampilkan chain-of-thought model dalam output:

```bash
bolt run --model anthropic/claude-opus-4-5 --variant high --thinking \
  "why does the token refresh logic race in the auth service?"
```

## Run paralel best-of-N

`--best-of` menembakkan prompt yang sama ke banyak model secara paralel, lalu menggunakan model juri untuk memeringkat respons dan menyimpan yang terbaik:

```bash
bolt run --best-of "anthropic/claude-opus-4-5,openai/gpt-4o,google/gemini-2.5-pro" \
  "implement a binary search tree with full test coverage"
```

Juri secara default menggunakan model yang diteruskan via `--model`, atau entri pertama dalam daftar `--best-of` jika `--model` tidak diatur. Flag menerima daftar pengenal `provider/model` yang dipisahkan koma.

<Tip>
  Best-of-N sangat berguna untuk masalah algoritmik kompleks atau keputusan arsitektur di mana model yang berbeda mungkin membawa pendekatan yang benar-benar berbeda. Biarkan Bolt menjalankannya secara paralel dan memilih pemenang secara otomatis.
</Tip>
