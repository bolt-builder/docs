Bolt menempatkan tim engineering AI penuh langsung di terminal kamu. Bolt hadir sebagai TUI yang cepat dan berbasis keyboard serta aplikasi desktop native, keduanya didukung oleh engine yang sama: sepuluh agent khusus, sesi persisten yang tahan lama, manajemen MCP server dengan OAuth, sistem plugin, dan dukungan untuk setiap provider LLM utama.

## Apa yang dilakukan Bolt

Bolt membaca basis kode kamu, memahami apa yang sedang kamu bangun, dan mengirimkan kode bersamamu—di terminal atau sebagai aplikasi desktop. Setiap sesi tahan lama: detach, re-attach dari mesin lain, fork percabangan percakapan, share sebuah tautan, atau ekspor transkrip yang di-sanitasi.

## Mulai jalan

<Steps>
  <Step title="Install Bolt">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash
    ```
    Atau instal via npm: `npm i -g @bolt-builder/bolt-cli`
  </Step>
  <Step title="Open your project">
    Navigasikan ke direktori proyek mana pun dan luncurkan TUI:
    ```bash
    cd my-project
    bolt
    ```
  </Step>
  <Step title="Configure a provider">
    Pada peluncuran pertama, Bolt memintamu menambahkan provider LLM. Kamu juga dapat menjalankan:
    ```bash
    bolt providers
    ```
  </Step>
  <Step title="Start coding with AI">
    Ketik prompt kamu di footer TUI, tekan Enter, dan biarkan agent Bolt bekerja. Ganti agent dengan `Tab`.
  </Step>
</Steps>

<Tip>
  Gunakan `bolt run "explain this codebase"` untuk jawaban non-interaktif yang cepat tanpa membuka TUI penuh.
</Tip>
