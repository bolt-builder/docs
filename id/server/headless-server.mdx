`bolt serve` menjalankan server Bolt headless yang mengekspos engine penuh melalui HTTP: sesi, agent, tool, akses provider, MCP, dan event streaming. Apa pun yang dapat dilakukan Bolt secara interaktif, dapat dilakukannya melalui API.

## Mulai sebuah server

```bash
bolt serve                              # localhost only, random port
bolt serve --hostname 0.0.0.0 --port 4096
bolt serve --mdns                       # advertise on the local network
```

<Warning>
  Binding ke `0.0.0.0` mengekspos Bolt di jaringan kamu. Selalu atur `BOLT_SERVER_USERNAME` dan `BOLT_SERVER_PASSWORD` sebelum melakukannya.
</Warning>

## Attach TUI

Dari mesin mana pun yang dapat menjangkau server:

```bash
bolt attach http://server:4096
bolt attach --mini http://server:4096
```

Atau jalankan prompt sekali jalan terhadap server remote:

```bash
bolt run --attach http://server:4096 --dir /projects/api "what tests are failing?"
```

## Basic auth

Atur kredensial melalui variabel lingkungan (lihat [Env Variables](/reference/environment-variables)):

```bash
export BOLT_SERVER_USERNAME=teamname
export BOLT_SERVER_PASSWORD=$(openssl rand -hex 24)
bolt serve --hostname 0.0.0.0 --port 4096
```

Semua klien harus mengirim kredensial yang cocok.
