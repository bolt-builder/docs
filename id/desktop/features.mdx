Aplikasi desktop adalah engine Bolt yang sama, dibungkus dalam shell native dengan beberapa hal yang tidak mudah dilakukan terminal.

## Apa isinya

- **Sesi multi-window dan multi-tab.** Jalankan beberapa agent secara paralel di berbagai proyek, masing-masing di tab-nya sendiri.
- **Prompt composer.** Input kaya dengan lampiran file dan paste gambar dari clipboard — jatuhkan screenshot langsung ke prompt.
- **Terminal terintegrasi \+ file tree.** Shell nyata dan penjelajah proyek di samping chat.
- **Command palette.** `Cmd/Ctrl+K` untuk berpindah antar sesi, menjalankan perintah Bolt apa pun, atau memicu slash command.
- **Setelan.** Keybind, model, provider, dan server yang dikonfigurasi, semuanya dapat diedit dalam UI setelan yang sesungguhnya.
- **Notifikasi native.** OS memberitahumu ketika agent yang berjalan lama selesai.
- **Deep link.** URL `bolt://` untuk melompat ke sesi dari mana saja.
- **Integrasi WSL di Windows.** Berjalan terhadap lingkungan WSL kamu langsung dari awal.
- **28 bahasa UI.**
