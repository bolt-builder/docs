Bolt implementeert het Agent Client Protocol (ACP), de manier waarop editors zoals Zed met AI-agents praten. Eenmaal geconfigureerd start de editor `bolt acp` als subprocess en stuurt het direct aan — je krijgt Bolts agents, tools, sessies en providerstack zonder je editor te verlaten.

## ACP inschakelen

Voeg in de AI-instellingen van je editor Bolt toe als ACP-compatibele agent en wijs het aan naar:

```bash
bolt acp
```

De editor beheert de proceslevenscyclus. Configureer providers, modellen en MCP-servers zoals gewoonlijk in `.bolt/bolt.jsonc` — ze gelden hier ook.

## Wat je krijgt

- Elke Bolt-agent, aanroepbaar vanuit het AI-paneel van de editor.
- Gedeelde sessies met de TUI en web-UI (via de lokale database).
- Dezelfde toolset, permissiemodel en projectgeheugen als elk ander Bolt-entrypoint.
