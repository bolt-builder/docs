Bolt kan op macOS, Linux en Windows worden geïnstalleerd met de methode die bij je workflow past — een curl-oneliner, een grote Node.js-package-manager, of een systeem-package-manager zoals Homebrew, Chocolatey of Scoop.

## Snelle installatie (macOS / Linux)

De snelste manier om te beginnen is het officiële installatiescript. Het detecteert automatisch je OS en architectuur, downloadt de juiste binary naar `~/.bolt/bin` en voegt hem toe aan je `$PATH`.

```bash
curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash
```

De installer zet ook optionele voice-input-afhankelijkheden op (sox en whisper-cpp voor offline transcriptie). Om dat over te slaan, geef `--no-voice` mee:

```bash
curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash -s -- --no-voice
```

Om een specifieke versie vast te zetten:

```bash
curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash -s -- --version 1.20.2
```

## Package managers

Installeer Bolt globaal met de package manager van je keuze:

<CodeGroup>

```bash npm
npm i -g @bolt-builder/bolt-cli
```

```bash bun
bun add -g @bolt-builder/bolt-cli
```

```bash pnpm
pnpm add -g @bolt-builder/bolt-cli
```

```bash yarn
yarn global add @bolt-builder/bolt-cli
```

</CodeGroup>

## De installatie verifiëren

<Steps>
  <Step title="Controleer de geïnstalleerde versie">
    Bevestig na installatie dat `bolt` beschikbaar is op je `$PATH`:

    ```bash
    bolt --version
    ```

    Als het commando niet gevonden wordt, open dan een nieuwe terminalsessie (of laad je shell-config opnieuw) zodat het bijgewerkte `$PATH` van kracht wordt.
  </Step>
</Steps>

## Upgraden

Voer `bolt upgrade` uit om te updaten naar de nieuwste release:

```bash
bolt upgrade
```

Bolt detecteert automatisch je oorspronkelijke installatiemethode. Je kunt hem overschrijven met de `--method`-flag:

```bash
bolt upgrade --method <method>
```

Ondersteunde methoden zijn: `curl`, `npm`, `pnpm`, `bun`, `brew`, `choco`, `scoop`.

Je kunt ook upgraden naar een specifieke versie door de versie als positioneel argument mee te geven:

```bash
bolt upgrade 1.20.2
```

## De-installeren

Om Bolt van je systeem te verwijderen:

```bash
bolt uninstall
```

## Omgevingsvariabelen

| Variabele               | Beschrijving                                           |
| ---------------------- | ----------------------------------------------------- |
| `BOLT_LOG_LEVEL`       | Log-uitgebreidheid: `DEBUG`, `INFO`, `WARN` of `ERROR`    |
| `BOLT_PRINT_LOGS`      | Print logs naar stderr                                  |
| `BOLT_PURE`            | Draaien zonder externe plugins te laden                  |
| `BOLT_SERVER_PASSWORD` | Basic auth-wachtwoord voor de headless API-server       |
| `BOLT_SERVER_USERNAME` | Basic auth-gebruikersnaam voor de headless API-server       |

<Tip>
  Stel `BOLT_PURE=1` in wanneer je een schone run wilt zonder plugins van derden — handig voor debugging of gecontroleerde CI-omgevingen.
</Tip>

## Desktop-app

<Note>
  Bolt wordt ook geleverd als native desktop-applicatie met multi-window sessiebeheer, een geïntegreerde terminal en file tree, een command palette, 28 UI-talen en automatische updates. Download de nieuwste release vanaf de [releases-pagina](https://github.com/Bolt-builder/bolt-cli/releases).

  Op macOS kun je hem in één regel installeren zonder Gatekeeper-omweg:

  ```bash
  curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install-desktop | bash
  ```
</Note>
