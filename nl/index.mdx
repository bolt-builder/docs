Bolt zet een compleet AI engineering-team direct in je terminal. Het wordt geleverd als een snelle, toetsenbord-gedreven TUI en een native desktop-app, beide ondersteund door dezelfde engine: tien gespecialiseerde agents, duurzame aanhoudende sessies, MCP-serverbeheer met OAuth, een pluginsysteem en ondersteuning voor elke grote LLM-provider.

## Wat Bolt doet

Bolt leest je codebase, begrijpt wat je bouwt en levert code samen met jou op — in de terminal of als desktop-app. Elke sessie is duurzaam: koppel los, koppel opnieuw aan vanaf een andere machine, fork een tak van het gesprek, deel een link of exporteer een geschoond transcript.

## Aan de slag

<Steps>
  <Step title="Installeer Bolt">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash
    ```
    Of installeer via npm: `npm i -g @bolt-builder/bolt-cli`
  </Step>
  <Step title="Open je project">
    Navigeer naar een willekeurige projectmap en start de TUI:
    ```bash
    cd my-project
    bolt
    ```
  </Step>
  <Step title="Configureer een provider">
    Bij de eerste start vraagt Bolt je een LLM-provider toe te voegen. Je kunt ook uitvoeren:
    ```bash
    bolt providers
    ```
  </Step>
  <Step title="Ga coderen met AI">
    Typ je prompt in de TUI-voettekst, druk op Enter en laat Bolts agents aan de slag gaan. Wissel van agent met `Tab`.
  </Step>
</Steps>

<Tip>
  Gebruik `bolt run "explain this codebase"` voor een snel niet-interactief antwoord zonder de volledige TUI te openen.
</Tip>
