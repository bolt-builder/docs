De desktop-app is dezelfde Bolt-engine, verpakt in een native schil met een paar dingen die een terminal niet gemakkelijk kan.

## Wat er in zit

- **Multi-window, multi-tab sessies.** Draai meerdere agents parallel over projecten heen, elk in een eigen tabblad.
- **Prompt-composer.** Rijke invoer met bestandsbijlagen en het plakken van klembordafbeeldingen — sleep screenshots rechtstreeks in de prompt.
- **Geïntegreerde terminal \+ file tree.** Een echte shell en een projectverkenner naast de chat.
- **Command palette.** `Cmd/Ctrl+K` om tussen sessies te springen, een willekeurig Bolt-commando uit te voeren of een slash-commando te triggeren.
- **Instellingen.** Sneltoetsen, modellen, providers en geconfigureerde servers, allemaal bewerkbaar in een echte instellingen-UI.
- **Native notificaties.** Het OS meldt je wanneer een langlopende agent klaar is.
- **Deep links.** `bolt://`-URL's om vanaf overal naar sessies te springen.
- **WSL-integratie op Windows.** Draait direct tegen je WSL-omgeving.
- **28 UI-talen.**
