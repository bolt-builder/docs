Bolt biedt één `bolt`-binary met een rijke set subcommando's. Wanneer je `bolt` zonder argumenten uitvoert, opent de volledige terminal-UI. Alle andere subcommando's staan hieronder. Gebruik `bolt <command> --help` op elk moment voor inline hulp.

<Accordion title="bolt (standaard — TUI starten)">
  Opent de interactieve terminal-UI in de huidige map. Bolt ontdekt automatisch je projectcontext, laadt configuratie en verbindt met eventueel geconfigureerde providers.

  ```bash
  bolt
  bolt --mini          # minimal split-footer interactive mode
  bolt --log-level DEBUG
  ```

  **Globale flags** — beschikbaar op elk commando:

  | Flag | Type | Beschrijving |
  | --- | --- | --- |
  | `--print-logs` | boolean | Print log-output naar stderr |
  | `--log-level` | `DEBUG`\|`INFO`\|`WARN`\|`ERROR` | Stel het log-verbositeitsniveau in |
  | `--pure` | boolean | Draaien zonder externe plugins te laden |
  | `--help`, `-h` | boolean | Toon helptekst |
  | `--version`, `-v` | boolean | Print het geïnstalleerde versienummer |
</Accordion>

<Accordion title="bolt run [prompt]">
  Draai Bolt met een enkele prompt in niet-interactieve modus. Bolt start een in-process server, verstuurt de prompt naar de actieve sessie, streamt het antwoord naar stdout en sluit dan af. Pipe stdin of geef `--file` mee om context te koppelen.

  ```bash
  # Basic non-interactive prompt
  bolt run "explain the auth module"
  
  # Continue the most recent session
  bolt run --continue "now add error handling"
  
  # Use a specific model with a specific agent
  bolt run --model anthropic/claude-opus-4-5 --agent code "refactor auth.ts"
  
  # Stream raw JSON events for tooling integration
  bolt run --format json "summarize changes"
  
  # Fire the same task at multiple models and keep the best result
  bolt run --best-of "anthropic/claude-opus-4-5,openai/gpt-4o" "write unit tests"
  
  # Attach a file as context
  bolt run --file ./openapi.yaml "generate a client SDK"
  
  # Attach to a remote server and run a prompt there
  bolt run --attach http://my-server:4096 --dir /projects/api "what tests are failing?"
  
  # Skip all permission prompts (dangerous)
  bolt run --auto "delete all TODO comments"
  ```

  | Flag | Alias | Type | Beschrijving |
  | --- | --- | --- | --- |
  | `--command` |  | string | Slash-commando om uit te voeren; geef argumenten door als het bericht |
  | `--continue` | `-c` | boolean | Zet de meest recente sessie voort |
  | `--session` | `-s` | string | Sessie-ID om voort te zetten |
  | `--fork` |  | boolean | Fork de sessie voordat je voortzet (vereist `--continue` of `--session`) |
  | `--share` |  | boolean | Deel de sessie na afronding |
  | `--model` | `-m` | string | Model om te gebruiken in `provider/model` formaat |
  | `--best-of` |  | string | Door komma's gescheiden `provider/model` lijst; draait de taak parallel, ranked resultaten, behoudt de winnaar |
  | `--agent` |  | string | Agent om te gebruiken (bv. `code`, `ask`, `review`) |
  | `--format` |  | `default`\|`json` | Output-formaat; `json` streamt ruwe newline-delimited JSON-events |
  | `--file` | `-f` | string\[\] | Bestand(en) om als context te koppelen |
  | `--title` |  | string | Titel voor de sessie |
  | `--attach` |  | string | Draai tegen een remote Bolt-server (bv. `http://localhost:4096`) |
  | `--password` | `-p` | string | Basic auth-wachtwoord voor de remote server |
  | `--username` | `-u` | string | Basic auth-gebruikersnaam voor de remote server |
  | `--dir` |  | string | Werkmap; als `--attach` is ingesteld, is dit de map op de remote server |
  | `--port` |  | number | Poort voor de lokale in-process server (willekeurig indien weggelaten) |
  | `--variant` |  | string | Reasoning-effort-niveau, providerspecifiek (bv. `high`, `max`, `minimal`) |
  | `--thinking` |  | boolean | Toon reasoning/thinking-blokken in de output |
  | `--mini` |  | boolean | Start de minimal split-footer interactieve UI (verborgen) |
  | `--interactive` | `-i` | boolean | Forceer directe interactieve split-footer-modus |
  | `--auto` |  | boolean | Keur automatisch permissies goed die niet expliciet worden geweigerd |
  | `--yolo` |  | boolean | Sla alle permissieprompts over (alias voor `--auto`, verborgen) |
  | `--dangerously-skip-permissions` |  | boolean | Sla alle permissiechecks over (verborgen) |
  | `--demo` |  | boolean | Schakel directe interactieve demo-slash-commando's in (verborgen) |
</Accordion>

<Accordion title="bolt attach <url>">
  Koppel de volledige TUI aan een draaiende Bolt-server. De server kan lokaal of remote zijn. Geef `--mini` mee om de minimal split-footer-UI te gebruiken in plaats van de volledige TUI.

  ```bash
  bolt attach http://localhost:4096
  bolt attach http://remote-host:4096 --dir /projects/api
  bolt attach http://remote-host:4096 --session abc123 --mini
  bolt attach http://remote-host:4096 --password secret --username alice
  ```

  | Flag | Alias | Type | Beschrijving |
  | --- | --- | --- | --- |
  | `--dir` |  | string | Map op de remote server |
  | `--continue` | `-c` | boolean | Zet de meest recente sessie op de remote server voort |
  | `--session` | `-s` | string | Sessie-ID om voort te zetten |
  | `--fork` |  | boolean | Fork de sessie bij voortzetten |
  | `--password` | `-p` | string | Basic auth-wachtwoord |
  | `--username` | `-u` | string | Basic auth-gebruikersnaam |
  | `--mini` |  | boolean | Gebruik de minimal interactieve UI |
  | `--no-replay` |  | boolean | Schakel replay van sessiegeschiedenis uit bij hervatten en na resize (vereist `--mini`) |
  | `--replay-limit` |  | number | Beperk zichtbare replay tot de nieuwste N berichten (vereist `--mini`) |
</Accordion>

<Accordion title="bolt serve">
  Start een headless Bolt API-server. De server stelt een REST\+SSE-API bloot waar de TUI, `bolt run --attach` en `bolt attach` verbinding mee kunnen maken. Bind op `0.0.0.0` om hem bereikbaar te maken vanaf andere machines — stel dan altijd `BOLT_SERVER_PASSWORD` in.

  ```bash
  bolt serve
  bolt serve --hostname 0.0.0.0 --port 4096
  bolt serve --mdns
  ```

  | Flag | Type | Beschrijving |
  | --- | --- | --- |
  | `--hostname` | string | Adres om aan te binden (standaard: `127.0.0.1`) |
  | `--port` | number | Poort om op te luisteren (willekeurig indien weggelaten) |
  | `--mdns` | boolean | Schakel mDNS service discovery in (zet standaard hostname op `0.0.0.0`) |
  | `--mdns-domain` | string | Aangepaste domeinnaam voor mDNS service (standaard: `opencode.local`) |
  | `--cors` | string\[\] | Extra domeinen om toe te staan voor CORS |

  <Warning>
    `BOLT_SERVER_PASSWORD` is standaard niet ingesteld. De server logt een waarschuwing en accepteert alle verbindingen totdat je hem instelt.
  </Warning>
</Accordion>

<Accordion title="bolt session">
  Beheer Bolt-sessies die zijn opgeslagen in de lokale SQLite-database.

  **Subcommando's**

  ```bash
  bolt session list                         # list all root sessions
  bolt session list --format json           # machine-readable output
  bolt session list -n 20                   # show 20 most recent sessions
  bolt session delete <sessionID>           # permanently delete a session
  ```

  **`bolt session list` flags**

  | Flag | Alias | Type | Beschrijving |
  | --- | --- | --- | --- |
  | `--max-count` | `-n` | number | Beperk output tot de N meest recente sessies |
  | `--format` |  | `table`\|`json` | Output-formaat (standaard: `table`) |
</Accordion>

<Accordion title="bolt agent">
  Toon en maak custom agents. Agents zijn markdown-bestanden met YAML-frontmatter die een systeemprompt, permissies en modus definiëren.

  ```bash
  bolt agent list                           # list all available agents
  bolt agent create                         # interactive agent creation wizard
  
  # Non-interactive creation
  bolt agent create \
    --description "Audit code for security vulnerabilities" \
    --mode primary \
    --permissions "read,grep,glob" \
    --model anthropic/claude-opus-4-5 \
    --path .bolt/agents
  ```

  **`bolt agent create` flags**

  | Flag | Alias | Type | Beschrijving |
  | --- | --- | --- | --- |
  | `--path` |  | string | Map-pad om het agent-bestand te schrijven |
  | `--description` |  | string | Natuurlijke-taal-beschrijving van wat de agent moet doen |
  | `--mode` |  | `all`\|`primary`\|`subagent` | Of de agent optreedt als primaire agent, subagent of beide |
  | `--permissions` | `--tools` | string | Door komma's gescheiden lijst van toegestane permissies (standaard: alle) |
  | `--model` | `-m` | string | Model om te gebruiken in `provider/model` formaat |
</Accordion>

<Accordion title="bolt providers (alias: auth)">
  Beheer AI-provider-credentials interactief. Credentials worden opgeslagen in je OS-datamap (`~/.local/share/bolt/auth.json` op Linux, `~/Library/Application Support/bolt/auth.json` op macOS).

  ```bash
  bolt providers             # interactive credential management menu
  bolt auth                  # alias for bolt providers
  
  bolt providers list        # list stored credentials and active env vars
  bolt providers login       # add a credential for a provider
  bolt providers login --provider anthropic
  bolt providers login --provider anthropic --method "API Key"
  bolt providers logout      # remove a stored credential
  bolt providers logout --provider openai
  ```
</Accordion>

<Accordion title="bolt models [provider]">
  Toon alle modellen die beschikbaar zijn bij je geconfigureerde providers.

  ```bash
  bolt models                         # list all models from all providers
  bolt models anthropic               # filter to a single provider
  bolt models --verbose               # include cost metadata in output
  bolt models --refresh               # force-refresh the models.dev cache
  ```

  | Flag | Type | Beschrijving |
  | --- | --- | --- |
  | `--verbose` | boolean | Voeg JSON-kostenmetadata toe voor elk model |
  | `--refresh` | boolean | Vernieuw de modellencache vanaf models.dev |
</Accordion>

<Accordion title="bolt mcp">
  Beheer Model Context Protocol (MCP)-servers. Bolt ondersteunt zowel remote (HTTP/SSE)-servers met OAuth als lokale (stdio)-servers.

  ```bash
  bolt mcp add                              # interactive wizard to add a server
  bolt mcp add my-server --url https://mcp.example.com/tools
  bolt mcp add local-server -- npx @my-org/mcp-server
  bolt mcp list                             # show all configured servers and status
  bolt mcp auth <name>                      # run the OAuth flow for a server
  bolt mcp auth list                        # show OAuth status for all servers
  bolt mcp logout <name>                    # remove stored OAuth tokens
  bolt mcp debug <name>                     # probe connectivity and OAuth config
  ```

  **`bolt mcp add` flags**

  | Flag | Type | Beschrijving |
  | --- | --- | --- |
  | `--url` | string | URL voor een remote MCP-server |
  | `--env` | string\[\] | Omgevingsvariabele voor een lokale server (`KEY=VALUE`) |
  | `--header` | string\[\] | HTTP-header voor een remote server (`KEY=VALUE`) |
</Accordion>

<Accordion title="bolt plugin install <module>">
  Installeer een Bolt-plugin vanaf npm en werk het relevante configuratiebestand bij. Plugins kunnen de TUI uitbreiden, nieuwe slash-commando's toevoegen of nieuwe providers registreren.

  ```bash
  bolt plugin install @my-org/bolt-plugin
  bolt plugin install @my-org/bolt-plugin --global      # install to global config
  bolt plugin install @my-org/bolt-plugin --force        # replace existing version
  ```

  | Flag | Alias | Type | Beschrijving |
  | --- | --- | --- | --- |
  | `--global` | `-g` | boolean | Voeg de plugin toe aan de globale config in plaats van de projectconfig |
  | `--force` | `-f` | boolean | Vervang een al-geconfigureerde plugin-versie |
</Accordion>

<Accordion title="bolt github">
  Beheer de Bolt GitHub Actions-integratie, waarmee Bolt kan reageren op pull requests, issues en andere GitHub-events.

  ```bash
  bolt github install           # scaffold the GitHub Actions workflow in your repo
  bolt github run               # run the GitHub agent locally (for testing)
  bolt github run --event pull_request --token ghp_xxx
  ```

  **`bolt github run` flags**

  | Flag | Type | Beschrijving |
  | --- | --- | --- |
  | `--event` | string | GitHub-eventnaam om te simuleren (bv. `pull_request`) |
  | `--token` | string | GitHub personal access token |
</Accordion>

<Accordion title="bolt pr <number>">
  Check een GitHub pull request uit als lokale branch met de `gh` CLI en start Bolt in de uitgecheckte map. Als de PR-beschrijving een sessie-share-link bevat, importeert Bolt die sessie automatisch.

  ```bash
  bolt pr 123
  ```

  <Note>
    Dit commando vereist dat de [GitHub CLI (`gh`)](https://cli.github.com/) is geïnstalleerd en geauthenticeerd.
  </Note>
</Accordion>

<Accordion title="bolt commit">
  Genereer een commit-bericht voor staged (of alle tracked) wijzigingen met een AI-model en commit vervolgens. Het model inspecteert recente commit-geschiedenis voor stijlcontext.

  ```bash
  bolt commit                        # commit staged changes
  bolt commit --all                  # stage and commit all tracked changes
  bolt commit --dry-run              # print the generated message without committing
  bolt commit --model openai/gpt-4o  # use a specific model
  ```

  | Flag | Alias | Type | Beschrijving |
  | --- | --- | --- | --- |
  | `--all` | `-a` | boolean | Commit alle tracked wijzigingen, niet alleen staged |
  | `--dry-run` |  | boolean | Print het gegenereerde bericht zonder te committen |
  | `--model` | `-m` | string | Model om te gebruiken in `provider/model` formaat |
</Accordion>

<Accordion title="bolt review">
  Voer een AI-code-review uit op een diff en verlaat met code `0` (pass) of `1` (fail). De `code-review`-agent onderzoekt de diff op correctheid, stijl en beveiligingsproblemen, en geeft een `Verdict: PASS`- of `Verdict: FAIL`-regel uit.

  ```bash
  bolt review                          # review uncommitted changes (git diff HEAD)
  bolt review --staged                 # review only staged changes
  bolt review --branch main            # review changes since merge base with main
  bolt review --model openai/o3        # use a specific model
  ```

  | Flag | Alias | Type | Beschrijving |
  | --- | --- | --- | --- |
  | `--staged` |  | boolean | Review alleen staged wijzigingen |
  | `--branch` |  | string | Review wijzigingen sinds de merge base met deze branch |
  | `--model` | `-m` | string | Model om te gebruiken in `provider/model` formaat |

  <Note>
    Exit-codes: `0` = PASS, `1` = FAIL, `2` = verdict kon niet worden bepaald.
  </Note>
</Accordion>

<Accordion title="bolt export [sessionID]">
  Exporteer een sessie als JSON naar stdout. Handig voor archivering, delen of aanleveren aan andere tools. Geef `--sanitize` mee voordat je publiek deelt om bestandspaden, prompts en andere gevoelige transcript-inhoud te redacten.

  ```bash
  bolt export                          # interactive session picker, then write to stdout
  bolt export abc123                   # export a specific session
  bolt export abc123 --sanitize        # redact secrets and paths
  bolt export abc123 > session.json    # write to a file
  ```

  | Flag | Type | Beschrijving |
  | --- | --- | --- |
  | `--sanitize` | boolean | Redact gevoelige data (bestandspaden, prompttekst, tool-I/O) voor het exporteren |
</Accordion>

<Accordion title="bolt import <file>">
  Importeer een eerder geëxporteerde sessie in de lokale database. Accepteert ofwel een lokaal JSON-bestand ofwel een sessie-share-URL.

  ```bash
  bolt import ./session.json
  bolt import https://opncd.ai/share/abc123
  ```
</Accordion>

<Accordion title="bolt stats">
  Toon aggregaat-statistieken van tokengebruik en kosten over alle sessies. Output bevat een overzichtstabel, uitsplitsing van kosten en tokens, modelgebruik en een staafgrafiek van toolgebruik.

  ```bash
  bolt stats
  bolt stats --days 7             # last 7 days only
  bolt stats --models             # include per-model breakdown
  bolt stats --models 5           # show top 5 models
  bolt stats --tools 10           # show top 10 tools
  bolt stats --project ""         # filter to the current project only
  ```

  | Flag | Type | Beschrijving |
  | --- | --- | --- |
  | `--days` | number | Beperk tot de laatste N dagen (standaard: alle tijd) |
  | `--tools` | number | Aantal tools om te tonen in de tool-usage-grafiek |
  | `--models` | boolean\|number | Toon model-statistieken; geef een getal om de lijst te beperken |
  | `--project` | string | Filter op project-ID; lege string betekent huidig project |
</Accordion>

<Accordion title="bolt logs">
  Print het Bolt-applicatielog. Het log wordt opgeslagen in de OS-log-map (bv. `~/.local/state/bolt/opencode.log`).

  ```bash
  bolt logs                        # print the last 1000 lines
  bolt logs --tail 200             # print the last 200 lines
  bolt logs --follow               # stream new lines as they are written
  bolt logs -f                     # alias for --follow
  ```

  | Flag | Alias | Type | Beschrijving |
  | --- | --- | --- | --- |
  | `--tail` |  | number | Aantal laatste regels om te printen (standaard: 1000) |
  | `--follow` | `-f` | boolean | Stream nieuwe logregels in real time |
</Accordion>

<Accordion title="bolt db [query]">
  Bevraag of inspecteer de lokale SQLite-sessiedatabase direct.

  ```bash
  bolt db path                                  # print the database file path
  bolt db "SELECT id, title FROM sessions"      # run a SQL query (TSV output)
  bolt db "SELECT * FROM sessions" --format json
  ```

  | Flag | Type | Beschrijving |
  | --- | --- | --- |
  | `--format` | `json`\|`tsv` | Output-formaat voor query-resultaten (standaard: `tsv`) |
</Accordion>

<Accordion title="bolt upgrade [target]">
  Upgrade Bolt naar de nieuwste release of een specifieke versie. Bolt detecteert automatisch de installatiemethode en gebruikt de juiste package manager.

  ```bash
  bolt upgrade                         # upgrade to the latest version
  bolt upgrade 0.2.0                   # upgrade (or downgrade) to a specific version
  bolt upgrade --method npm            # force a specific installation method
  bolt upgrade --method curl
  ```

  | Flag | Alias | Type | Beschrijving |
  | --- | --- | --- | --- |
  | `--method` | `-m` | `curl`\|`npm`\|`pnpm`\|`bun`\|`brew`\|`choco`\|`scoop` | Te gebruiken installatiemethode |
</Accordion>

<Accordion title="bolt uninstall">
  Verwijder de Bolt-binary en alle bijbehorende data.

  ```bash
  bolt uninstall
  ```
</Accordion>

<Accordion title="bolt debug">
  Een verzameling troubleshooting- en introspectie-subcommando's. Handig bij het indienen van bugreports of het diagnosticeren van onverwacht gedrag.

  ```bash
  bolt debug info          # print version, OS, terminal, and loaded plugins
  bolt debug config        # print the fully-resolved configuration
  bolt debug paths         # print all global data/config/cache directories
  bolt debug lsp           # inspect LSP state
  bolt debug ripgrep       # test ripgrep availability
  bolt debug file          # inspect file tool behavior
  bolt debug scrap         # scratchpad for debugging
  bolt debug skill         # inspect available skills
  bolt debug snapshot      # inspect session snapshots
  bolt debug startup       # measure startup time
  bolt debug agents        # list agents and their resolved config
  bolt debug v2            # inspect V2 session core state
  bolt debug wait          # block indefinitely (for process debugging)
  ```
</Accordion>

<Accordion title="bolt acp">
  Start een ACP (Agent Client Protocol)-server. ACP is het protocol dat wordt gebruikt door editorintegraties zoals [Zed](https://zed.dev) om via stdin/stdout met Bolt te communiceren.

  ```bash
  bolt acp
  bolt acp --cwd /path/to/project
  ```

  | Flag | Type | Beschrijving |
  | --- | --- | --- |
  | `--cwd` | string | Werkmap voor de server (standaard: `process.cwd()`) |
  | `--hostname` | string | Bind-hostname (standaard: `127.0.0.1`) |
  | `--port` | number | Bind-poort |
  | `--mdns` | boolean | Schakel mDNS service discovery in |
  | `--mdns-domain` | string | Aangepaste domeinnaam voor mDNS service (standaard: `opencode.local`) |
  | `--cors` | string\[\] | Extra domeinen om toe te staan voor CORS |
</Accordion>
