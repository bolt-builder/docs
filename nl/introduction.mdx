Bolt is een terminal-first AI-codeeragent gebouwd op [Effect](https://effect.website), [OpenTUI](https://github.com/opentui/opentui) en [SolidJS](https://www.solidjs.com). Richt hem op een willekeurig project en hij pikt de context automatisch op: hij verkent je code, volgt je conventies, voert shell-commando's uit, bewerkt bestanden, draait tests en levert wijzigingen op.

Tien ingebouwde agents (`code`, `plan`, `ask`, `code-review`, `debug`, `refactor`, `docs`, `security`, `migrate`, `perf`) plus `@general`- en `@explore`-subagents dekken de hele engineering-loop. Sessies zijn duurzaam: koppel los, koppel opnieuw aan (zelfs met een remote server), fork, deel, exporteer en importeer op elk moment. Projectgeheugen behoudt wat de agent tussen sessies leert. Uitbreidbaar via MCP-servers (met OAuth), plugins, custom agents en custom tools.

Bolt is open source onder de PolyForm Noncommercial 1.0.0-licentie.

## Waarom Bolt?

Bolt is ontworpen rond de manier waarop developers daadwerkelijk werken: in de terminal, over meerdere sessies heen, op echte codebases. Dit is wat het onderscheidt:

- **Terminal-first TUI.** Een snelle, toetsenbord-gedreven interface gebouwd met [Effect](https://effect.website), [OpenTUI](https://github.com/opentui/opentui) en [SolidJS](https://www.solidjs.com). Het voelt native omdat het native is.
- **Een compleet team van agents.** Tien gespecialiseerde agents — `code`, `plan`, `ask`, `code-review`, `debug`, `refactor`, `docs`, `security`, `migrate` en `perf` — plus subagents voor onderzoek en delegatie met meerdere stappen. Wissel er tussen met `Tab`.
- **Sessies die je kunt verlaten en opnieuw kunt oppakken.** Koppel los van een sessie en koppel er later weer aan, zelfs op een remote server. Fork, deel, exporteer en importeer werk op elk moment. Sessies worden opgeslagen in SQLite en zijn volledig inspecteerbaar met `bolt db`.
- **Uitbreidbaar van ontwerp.** MCP-servers met volledige OAuth-ondersteuning, een pluginsysteem, GitHub-integratie, een ingebouwde API-server en een web-UI.
- **Desktop-app.** Dezelfde engine verpakt in een multi-window, multi-tab desktop-ervaring — met een geïntegreerde terminal, file tree, command palette, 28 UI-talen en automatische updates.

## Ingebouwde agents

Bolt levert tien gespecialiseerde agents. Elke agent heeft een gedefinieerd niveau van bestandssysteemtoegang dat past bij zijn doel.

| Agent | Toegang | Beschrijving |
| --- | --- | --- |
| `code` | Full | Standaard: leest, schrijft en voert code uit |
| `plan` | Read | Verkent de codebase en produceert een plan zonder bestanden te wijzigen |
| `ask` | Read | Vragen en onderzoek — geen bestandsbewerkingen |
| `code-review` | Read | Reviewt wijzigingen op correctheid, stijl en security |
| `debug` | Full | Debugt falende tests, crashes en logicafouten |
| `refactor` | Full | Veilig refactoren met testverificatie bij elke stap |
| `docs` | Edit | Schrijft en werkt documentatie en commentaar bij |
| `security` | Read | Security-audit: kwetsbaarheden, secrets, patronen |
| `migrate` | Full | Framework-upgrades en dependency-migraties |
| `perf` | Full | Performance-analyse en optimalisatie |

Je kunt ook je eigen agents definiëren als Markdown-bestanden of er een genereren met `bolt agent create`.

## Desktop-app

Bolt wordt ook geleverd als standalone desktop-app met multi-window en multi-tab sessiebeheer, een prompt-composer met ondersteuning voor bijlagen en het plakken van klembordafbeeldingen, een geïntegreerde terminal en file tree, een command palette, volledige instellingen voor sneltoetsen, modellen, providers en servers, native notificaties, deep links, WSL-integratie op Windows en automatische updates via de dev-, beta- en productiekanalen.

Download de desktop-app vanaf de [releases-pagina](https://github.com/Bolt-builder/bolt-cli/releases), of installeer hem in één regel op macOS zonder Gatekeeper-omweg:

```bash
curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install-desktop | bash
```
