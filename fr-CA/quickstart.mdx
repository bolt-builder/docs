Ce guide vous accompagne pour installer Bolt, le lancer dans un projet, connecter un fournisseur IA et exécuter votre première invite. L'ensemble prend moins d'une minute.

<Steps>
  <Step title="Installer Bolt">
    Le chemin le plus rapide est le script d'installation officiel, qui fonctionne sur macOS et Linux :

    ```bash
    curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install | bash
    ```

    Vous préférez un gestionnaire de paquets? Installez globalement avec npm, bun, pnpm ou yarn :

    ```bash
    npm i -g @bolt-builder/bolt-cli
    ```

    Pour l'application de bureau sur macOS (sans détour par Gatekeeper) :

    ```bash
    curl -fsSL https://raw.githubusercontent.com/bolt-builder/bolt-cli/dev/install-desktop | bash
    ```

    Consultez le [Guide d'installation](/installation) pour toutes les méthodes, y compris Homebrew, Chocolatey, Scoop et les notes propres à Windows.
  </Step>
  <Step title="Ouvrir votre projet">
    Naviguez vers n'importe quel répertoire de projet et lancez le TUI interactif :

    ```bash
    cd my-project
    bolt
    ```

    Bolt saisit automatiquement le contexte de votre projet — il lit votre arborescence de fichiers, comprend la pile technologique, et la rend disponible à tous les agents dès que vous l'ouvrez.
  </Step>
  <Step title="Configurer un fournisseur IA">
    Au premier lancement, Bolt vous invite à configurer un fournisseur si aucun n'est défini. Vous pouvez aussi exécuter ceci à tout moment :

    ```bash
    bolt providers
    ```

    Cela ouvre le flux de gestion des fournisseurs où vous pouvez ajouter des clés d'API pour OpenAI, Anthropic et d'autres fournisseurs LLM pris en charge. La configuration est enregistrée dans `.bolt/bolt.jsonc` à la racine de votre projet.

    ```jsonc
    {
      "$schema": "https://opencode.ai/config.json",
      "provider": {
        // Provider config goes here
      }
    }
    ```
  </Step>
  <Step title="Tapez une invite et explorez les agents">
    Une fois dans le TUI, tapez votre invite et appuyez sur Entrée. Utilisez **Tab** pour alterner entre les dix agents intégrés de Bolt à tout moment — l'agent courant est affiché dans la barre d'état.

    Vous pouvez aussi exécuter des invites directement en ligne de commande sans ouvrir le TUI :

    ```bash
    # Non-interactive prompt using the default agent
    bolt run "explain this codebase"
    
    # Use a specific agent
    bolt run --agent ask "what does this project do?"
    
    # Attach the TUI to a running server (local or remote)
    bolt attach <url>
    ```
  </Step>
</Steps>

## Agents intégrés

Changez d'agent avec `Tab` dans le TUI, ou passez `--agent <name>` à `bolt run`. Chaque agent a un niveau d'accès défini pour correspondre à son objectif.

| Agent | Accès | Description |
| --- | --- | --- |
| `code` | Complet | Par défaut : lit, écrit et exécute du code |
| `plan` | Lecture | Explore la base de code et produit un plan sans modifier de fichiers |
| `ask` | Lecture | Questions et recherche — aucune modification de fichier |
| `code-review` | Lecture | Examine les changements pour la justesse, le style et la sécurité |
| `debug` | Complet | Débogue les tests qui échouent, les plantages et les erreurs de logique |
| `refactor` | Complet | Refactorisation sécuritaire avec vérification par tests à chaque étape |
| `docs` | Édition | Écrit et met à jour la documentation et les commentaires |
| `security` | Lecture | Audit de sécurité : vulnérabilités, secrets, motifs |
| `migrate` | Complet | Mises à niveau de frameworks et migrations de dépendances |
| `perf` | Complet | Analyse des performances et optimisation |

Il y a aussi deux sous-agents intégrés pour la délégation : `@general` pour les tâches complexes en plusieurs étapes et `@explore` pour une recherche rapide en lecture seule dans la base de code. Vous pouvez définir vos propres agents sous forme de fichiers Markdown ou en générer un avec `bolt agent create`.

## Commandes courantes à essayer ensuite

```bash
# Review staged changes with a pass/fail exit code
bolt review --staged

# Generate a commit message for staged changes
bolt commit

# List and manage sessions
bolt session list

# View token usage and cost statistics
bolt stats

# Query the local session database
bolt db
```

<Tip>
  Passez `--mini` à `bolt` ou `bolt attach` pour une interface compacte qui occupe moins d'espace au terminal — parfaite pour de petites fenêtres ou des mises en page à panneaux divisés.

  ```bash
  bolt --mini
  bolt attach --mini <url>
  ```
</Tip>

<Warning>
  `bolt run` accepte les indicateurs `--auto`, `--yolo` et `--dangerously-skip-permissions` qui approuvent automatiquement toutes les demandes de permission sans les afficher. Utilisez-les uniquement dans des environnements de confiance — ils permettent à l'agent de lire, d'écrire et d'exécuter sans confirmation.

  ```bash
  bolt run --auto "refactor this module"
  bolt run --yolo "refactor this module"
  bolt run --dangerously-skip-permissions "refactor this module"
  ```
</Warning>

<Note>
  Bolt prend en charge la complétion shell pour bash, zsh, fish et d'autres shells. Générez et installez la complétion avec :

  ```bash
  bolt completion
  ```

  Suivez les instructions affichées pour charger le script de complétion dans la configuration de votre shell.
</Note>
