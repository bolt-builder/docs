L'application de bureau est le même moteur Bolt enveloppé dans un shell natif avec quelques éléments qu'un terminal ne peut pas facilement offrir.

## Ce qu'elle contient

- **Sessions multi-fenêtres, multi-onglets.** Faites tourner plusieurs agents en parallèle sur différents projets, chacun dans son propre onglet.
- **Compositeur d'invites.** Entrée riche avec pièces jointes de fichiers et collage d'images depuis le presse-papiers — glissez des captures d'écran directement dans l'invite.
- **Terminal intégré \+ arborescence de fichiers.** Un vrai shell et un explorateur de projet à côté du clavardage.
- **Palette de commandes.** `Cmd/Ctrl+K` pour naviguer entre les sessions, exécuter toute commande Bolt ou déclencher une commande slash.
- **Paramètres.** Raccourcis clavier, modèles, fournisseurs et serveurs configurés, tous modifiables dans une vraie interface de paramètres.
- **Notifications natives.** Le système d'exploitation vous avise quand un agent de longue durée termine.
- **Liens profonds.** Les URL `bolt://` pour sauter à des sessions depuis n'importe où.
- **Intégration WSL sur Windows.** Fonctionne d'emblée avec votre environnement WSL.
- **28 langues d'interface.**
