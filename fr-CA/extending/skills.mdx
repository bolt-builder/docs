Les compétences sont des guides nommés et réutilisables qui vivent aux côtés de votre projet et sont invoqués par l'outil `skill`. Là où un outil personnalisé est une seule action exécutable, une compétence est un flux scripté que l'agent peut suivre étape par étape : rassembler ces fichiers, exécuter ces commandes, décider quoi faire ensuite selon la sortie.

Utilisez les compétences quand :

- Vous avez un flux que vous ne cessez de réexpliquer dans les invites (« exécute d'abord le linter, puis... »).
- Vous voulez que l'agent suive un arbre de décision précis.
- Vous voulez le même flux disponible pour chaque session et chaque agent du projet.

## Où elles vivent

Les compétences sont des fichiers sous `.opencode/skill/` (ou `.opencode/skills/`) à la racine du projet. Chaque fichier décrit le nom du déclencheur, quand l'agent devrait l'utiliser et les étapes impliquées. L'[outil](/concepts/tools) `skill` les expose au modèle.
