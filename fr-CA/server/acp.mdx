Bolt implémente l'Agent Client Protocol (ACP), qui est la façon dont les éditeurs comme Zed parlent aux agents IA. Une fois configuré, l'éditeur lance `bolt acp` comme sous-processus et le pilote directement — vous obtenez les agents, outils, sessions et pile de fournisseurs de Bolt sans quitter votre éditeur.

## Activer ACP

Dans les paramètres IA de votre éditeur, ajoutez Bolt comme agent compatible ACP et pointez-le vers :

```bash
bolt acp
```

L'éditeur gérera le cycle de vie du processus. Configurez les fournisseurs, les modèles et les serveurs MCP comme vous le feriez normalement dans `.bolt/bolt.jsonc` — ils s'appliquent ici aussi.

## Ce que vous obtenez

- Chaque agent Bolt, appelable depuis le panneau IA de l'éditeur.
- Sessions partagées avec le TUI et l'interface Web (via la base de données locale).
- Le même ensemble d'outils, modèle de permissions et mémoire de projet que tout autre point d'entrée Bolt.
